I did not make `parameters` required for a non-uniform mode: the CPU twins and `raster-fractional-zonal-distribution-operation.spec.ts` construct the contributor with `cellSizeMode` and no `parameters`.

Because the per-row reference (largest row weight over the grid) can no longer be computed from compile-time edges, the fixed-point references are now constants of the mode (largest x scale, y scale and area over the whole latitude range, times 1.001) and the scale is 2^26 instead of 2^20 (a run holds at most 16 pixels or 32 faces, so a u32 contribution stays below 2^31; weights are clamped to 1). Uniform path untouched, results identical.
