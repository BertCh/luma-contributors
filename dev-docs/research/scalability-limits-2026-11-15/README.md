## Inventory conventions and coverage

The audit searched named `MAXIMUM`, `MAX_`, `LIMIT` and `CAPACITY` constants, then read `validateCapacity`/`validateMaximumCount` call sites and followed the shared validators and helper consumers. The contributor contract sections 1–3, 9–10 and the chunked time-window reference were read first. Definitions in tests/audit utilities, numeric sentinels and value ranges, predictor/variable/class/band counts, radii, solver/permutation/replicate budgets, and workgroup/private-histogram thresholds with a general fallback are outside the data-size inventory. Dorling’s maximum grid side and Mantel’s maximum partial-block count are excluded because they choose coarser/strided schedules and do not reject larger input. A bounded per-query list, per-feature path, per-track search or per-location series is included because it caps points/candidates/segments actually used in a result. Output and scratch cardinalities are included; a row limit is not always a total-input-row limit.

A route is marked default only when constructor resolution selects it or the API itself is explicitly chunked/streaming. A CPU sibling is never a hidden automatic fallback. Float64 twins may differ at ties, thresholds and overflow; see their linked “What differs” documentation. Stochastic traces, FFT versus finite spectral modes, atomic sums and minimum-spanning-forest watershed all have material numerical/semantic differences, stated in their rows. Indexing can remain quadratic in dense/adversarial neighborhoods. Recommendations are design directions, not claims that a larger constant is safe today.

Values below are inclusive unless a row says otherwise. `B` in device-derived entries means `device.limits.maxStorageBufferBindingSize`; `128 MiB = 134217728` is only the baseline. Raising requested limits requires a device that supports them and does not remove uint32 indexing or the single-buffer shape. Main tables show constants; each package’s second table covers device-derived named helpers. “No adjacent reason comment” is a finding, not an inferred rationale.
