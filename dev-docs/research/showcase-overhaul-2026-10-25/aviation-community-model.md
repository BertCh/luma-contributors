# Aviation community model comparison

The regional aviation scene compares GPU Louvain partitions on two weighted graphs built from the same 24-airport induced directed subgraph.

- **Directed observed flows** uses the source matrix `W` without changing direction.
- **Symmetric mean flow** uses `Uuv = (Wuv + Wvu) / 2` for every ordered pair. `U` is symmetric and its total weight equals `W`'s total weight, including diagonal terms. This removes orientation as an analytical assumption; it does not infer reciprocal flights.

Both partitions use the same seed, resolution, and iteration limits. Louvain is a bounded heuristic, so a converged run is not a certificate of global optimality. The matching GPU coarsening pass aggregates each partition. For symmetric Louvain it uses the symmetric mean-weight graph. For coarsening, each unique unordered pair instead carries `Wuv + Wvu` (and each self-loop carries `Wuu`), because the coarsener emits each undirected edge only once. This preserves total weight against the original directed count total. Directed coarsening counts each directed CSR slot; symmetric coarsening counts one slot for each unordered pair. Pair counts from these two topologies have different meanings and should not be compared as if they were the same measure.

The bundled BTS scheduled-count column includes cancelled flights according to the showcase dataset manifest. It is used as a source weight for this comparative analysis, not as realized operations, passengers, seats, or link capacity.

Method references: Blondel et al., [Fast unfolding of communities in large networks](https://arxiv.org/abs/0803.0476); Leicht and Newman, [Community structure in directed networks](https://arxiv.org/abs/0709.4500).

The independent verifier `scripts/check-aviation-community-coarsening.mjs` reconstructs the regional inputs from their binary columns, reads the actual GPU community membership, and independently aggregates directed rows or unique unordered pairs. It validates group membership, within/between pair counts and weights, and conservation; it does not claim to certify Louvain optimality or reproduce its chosen heuristic partition.
