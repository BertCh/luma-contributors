# Spectral texture implementation ledger

## Executable scene

- `spectral-texture` loads the registered `dixie-spectral` dataset's calibrated, unitless NIR and SWIR₂ 60 m means and strict native-pixel QA mask for the selected acquisition. QA-invalid cells remain nodata. It crops source rows 50–177 and columns 60–187 from the north-first EPSG:32610 250 × 250 grid and draws the UTM frame, crop outline and Greenville label.
- Acquisition (`date`) and filter/texture/focal/convolution recipes are compile options. A `GraphSwap` serializes bounded 128 × 128 graph rebuilds, keeps the active graph encoding until a replacement compiles, discards superseded builds, and releases replaced resources. Map layer, GLCM metric/display domain and focal output selectors reuse the graph result. While active and requested compile keys differ, the analytical raster and tooltip are hidden, dependent readouts show pending, and the stale pair chart is cleared. Readback may populate its own variant, but it publishes readouts only if that variant is still active and matches current options. `encode` dispatches only while dirty. A `SummaryReader` reads one compiled result once; clean frames do not recalculate the graph or issue repeated copies.
- Positive smoothing outputs are `GPURasterGaussianBlur`, `GPURasterBoxBlur` and a nonnegative distance-weighted `GPURasterNeighborhood`; radius 1–6, Gaussian sigma 0.5–4, clamp/reflect/nodata borders and propagate/ignore-renormalize policies are exposed. `GPURasterConvolution` exposes selectable 3 × 3 Sobel x, 5 × 1 eastward derivative, and 1 × 5 southward derivative kernels with explicit dimensions. Signed kernels propagate nodata and are never normalized. Its border can inherit the general clamp/reflect/nodata choice or use a constant reflectance value from 0 to 0.6; that value is hypothetical extrapolation outside the clipped crop, not observed data. This constant mode belongs to convolution only; focal pairs continue to use nodata/clamp/reflect.
- The selected `GPURasterGradient` x/y and `GPURasterGradientMagnitude` use the selected Sobel or Scharr recipe. `GPURasterSobel` and `GPURasterScharr` each compute and expose both named x/y outputs. `GPURasterLaplacian` uses selectable four/eight connectivity. Signed derivatives preserve strict propagation. Raster x is eastward, y southward, derivative units are reflectance response per pixel, and Laplacian units are reflectance per pixel squared.
- `GPURasterTexture` computes all seven interleaved features and pair counts for the selected acquisition. Controls select radius 1–6, E/N/NE/NW offset, 8/16 levels, symmetry, metric, and display domain. Finite input is clipped and quantized over [0, 0.6]. The default detail display clips contrast to [0, 4] and dissimilarity to [0, 2]; theoretical mode uses contrast [0, (levels−1)²] and dissimilarity [0, levels−1]. Correlation remains [−1, 1], homogeneity/ASM/energy [0, 1], and entropy [0, 2 ln(levels)] in both modes. These are color-domain choices only and do not alter measurements. The shared style helper supplies the same ramp/domain to the map and legend. The selected feature is gathered from one bounded interleaved feature readback to a display buffer; texture is therefore a GPU computation with a readback-based display selection, not wholly GPU-resident presentation. Empty feature values stay NaN.
- `GPURasterFocalPairs` uses same-date, jointly valid NIR predictor and SWIR₂ response, radius 1–6, clipped/clamp/reflect borders, ignore/propagate pair handling, optional center-pair propagation, minimum count 2–169 (default 8), and sample/population covariance. GPU outputs exposed as maps are covariance, correlation, slope, intercept, R², residual sum of squares, paired count and status. Signed covariance/correlation/slope/intercept use diverging domains; paired count has its own sequential domain. Status masks are read from the GPU unchanged; the map categorizes exact masks into supported, each individual flag, or combined flags, and clicked evidence prints the exact bit mask and its set conditions. Undefined metrics remain NaN.
- The clicked scatter uses bounded CPU source pairs at the same radius and nodata/clamp/reflect window mapping as the GPU fit. The line comes only from a status-zero GPU fit. The selected-cell evidence reports selected mapped output, valid NIR source-cell support, source-minus-Gaussian difference, six-decimal covariance/intercept/RSS and other focal metrics, pair count and status. Default probe is crop row 56, column 73 (source row 106, column 133; crop index 7,241; full source flat index 26,633).
- Source values are unitless calibrated reflectance, and QA-invalid cells are nodata. July 13, 2021 is ignition day, not a pre-season baseline. Strict QA requires the source mask; it reduces observation uncertainty but does not guarantee cloud-free measurements. Cross-date means are not a controlled impact estimate. Local windows overlap, and focal association is descriptive without inferential p-values. Texture display clipping changes color interpretation only, not computed values.
