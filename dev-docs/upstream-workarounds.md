# Upstream workarounds register

Status date: 2026-11-13. Baseline: published `@luma.gl/*@10.0.0-alpha.13`.

This register tracks gaps against [upstream-first-plan.md](./upstream-first-plan.md) and [upstream-proposals.md](./upstream-proposals.md). Analysis paths omit `modules/analysis/src/`; bare filenames share the preceding directory. Recheck symbols before retirement. The luma.gl fork that preceded this repository (commit `e0ed33791`; code public on `BertCh/luma.gl`, branch `reference/map-contributors-pre-split-code`) holds working code and tests for many of the "what luma.gl needs" entries; [research/fork-comparison-2026-11-13](./research/fork-comparison-2026-11-13/README.md) maps each to its fork path.

## How to read the table

| Status | Meaning |
| --- | --- |
| dropped | The capability is unavailable or limited. |
| workaround | Local code supplies a missing API; delete when available. |
| accepted regression | We accept published performance/scale limits. |
| local kernel | Local code overlaps a published class whose contract lacks required options (section 4); delegate when compatible. |

“What luma.gl needs” states what permits restoration/delegation; work proceeds without waiting for upstream.

## 5. Upgrade procedure for each `@luma.gl` alpha bump

1. Read release notes; compare public exports (`dist/**/index.d.ts`), not implementation files.
2. From the repository root, run [research/luma-usage-review-2026-11-11/scripts](./research/luma-usage-review-2026-11-11/scripts/): `exports.mjs <node_modules/@luma.gl> <out.json>`, `usage.mjs <exports.json> <usage.json> <report.json>` and `diff.mjs <old.json> <new.json>`. Keep the old inventory; exclude `_internal`.
3. Check requested APIs in the inventory, including awaited `GPUScatter`, `assertRasterStorageBindingFits`, `makeGPUQueryExpressionShaderPlan` and `addGPUQueryPredicatePass` (not public at alpha.13). Delegate eligible rows, remove workarounds and record release under Retired; require non-trivial parity coverage for section 4.
4. Bump all luma.gl manifest/peer pins, `.yarnrc.yml` deck-core 9.4.0 package extension and `yarn.lock` together.
5. Run `node scripts/check-upstream-first.mjs`; exported `_internal` paths remain forbidden.
6. Run `yarn vitest run --project node modules/analysis/test/analysis-core/official-wgsl-copies.node.spec.ts` and its five per-copy pin specs. Copies reading published state must follow changed upstream arithmetic; update the copy and this file together.
7. Run `yarn lint-fix`, `yarn typecheck`, `yarn typecheck-tests` (with `NODE_OPTIONS=--max-old-space-size=8192`), `yarn build`, `yarn lint`, `node scripts/verify-package-exports.mjs`, `yarn test-node` and `yarn test-headless`.
8. Investigate numerical drift; document changes without silently loosening tolerances. Re-run section 3 benchmarks (`LUMA_CONTRIBUTORS_BENCHMARKS=true`); record benchmark numbers next to each row. Add every new workaround or dropped capability to this file in the same change.

## 6. Shader-compiler behaviour that kernels work around

These are Apple/Metal compiler behaviours on headless Chromium WebGPU; see [shader-compiler-findings.md](./research/math-correctness-review-2026-11-10/shader-compiler-findings.md), [contributor-contract.md](./contributor-contract.md) section 11 and [upstream-proposals.md](./upstream-proposals.md). `modules/analysis/test/analysis-core/shader-compiler-fast-math.spec.ts` pins fast math. Re-run after browser/OS/luma upgrades; safety is shader-specific.

| Behaviour on the test GPU | Measured | Local cure | Spec that pins it |
| --- | --- | --- | --- |
| Float compensation erased | Metal fast math can erase float compensation; a compensated sum can equal the plain float32 result. | Fixed point, sorted segments or `getAdditionRoundingError` in `analysis-core/kernels/addition-rounding-error-wgsl.ts`. | `modules/analysis/test/utils/addition-rounding-error-wgsl.spec.ts` |
| Residual subtraction reassociated | Metal fast math can fold residual corrections into a large mean. GM residual reassociation lacks targeted coverage; lag-ML/2SLS high-fit residuals are covered by `math-review-lag-conditioning.spec.ts`. | Integer-bit barrier with runtime zero: `getRoundedDifference` in `gpu-spatial-analysis/spatial-regression/rounded-difference-wgsl.ts`; same technique in `dataframe-analysis/group-statistics/group-statistics-moments.ts`. | `modules/analysis/test/gpu-spatial-analysis/spatial-regression/math-review-restricted-regimes.spec.ts`, `math-review-error-ml-high-fit.spec.ts`; `modules/analysis/test/gpu-dataframe/group-statistics/gpu-group-statistics.spec.ts` |
| Constant-loop integer-table stores lost | Apple Metal can lose constant-loop integer-table stores; no size is safe across shaders. Tint emits correct Metal; fast-math settings do not cure it. Bug reports are drafted, not filed, in [shader-compiler-findings.md](./research/math-correctness-review-2026-11-10/shader-compiler-findings.md), section 5. | Use literal/constant tables, runtime fills or no table: `gpu-network/network-optimization/gpu-network-louvain.ts`: `GPUNetworkLouvain`; `gpu-spatial-analysis/spatial-interpolation/gpu-natural-neighbor.ts`: `GPUNaturalNeighbor`; `raster-analysis/raster-time-series/gpu-raster-phenology-metrics.ts`: `GPURasterPhenologyMetrics`. Safety is shader-specific. | `modules/analysis/test/analysis-core/shader-compiler-table-fill.spec.ts`, `shader-compiler-table-shapes.spec.ts`, `table-audit/*.spec.ts`; `modules/analysis/test/utils/function-scope-table-readback.spec.ts`; `modules/analysis/test/gpu-network/network-optimization/gpu-network-louvain-visit-order.spec.ts` |
