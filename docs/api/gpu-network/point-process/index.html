Network point processes

GPUNetworkKernelDensity estimates network intensity from supplied shortest-path distances and edge-length quadrature. GPUNetworkInhomogeneousK computes a distinct intensity-reweighted K statistic with optional Ang shell correction. See the point-process contracts for formulas, bounds, and status semantics.

These executable scenarios use a three-node chain with two endpoint events. Each result is a GPU readback. The intensity values and shortest-path tables are explicit inputs.
