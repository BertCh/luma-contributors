# Embedding rasters

Contributors for rasters of learned embedding vectors, such as the AlphaEarth Satellite Embedding V1
annual layers (64 bands, 10 m, unit-length vectors): decoding the int8 files, similarity search, change
between years, clustering, classification, principal components and per-polygon descriptors, and
overviews that average vectors correctly. Import from `@luma-contributors/analysis/raster-analysis`.

K-means and nearest-pixel search follow the same producer API as the other embedding contributors:
use `graph.add(contributor)` or obtain unscheduled passes with `contributor.getCommandNodes(graph)`.
Their former `addToGraph` method has been removed.
Inspecting their nodes repeatedly on the same graph reuses the materialized passes; an inspection
can be followed by `graph.add(contributor)` without consuming the producer or duplicating scratch.
The cached node lists are frozen and returned as readonly arrays; inspecting them cannot change
the passes that a later `graph.add` schedules. The same rule applies to the four spectral indices.

Layout. A raster is `pixelCount` pixels, row-major, each with `dimensions` float32 components (1–1,024 for streaming contributors; 1–128 for the reference covariance family):
`vectors[pixel * dimensions + band]`. An invalid pixel is marked by `mask` (zero) or by a non-finite
component; the decoder writes NaN for every component of a NoData pixel. int8 data is `uint32` words of four
little-endian signed bytes, pixel-major, as an `Int8Array` uploaded unchanged. Band-sequential files are
interleaved by the host adapter. The element count `pixelCount * dimensions` must stay below 2^32, and a
128-band float32 raster of 262,144 pixels fills one 128 MiB storage binding on a default device; tile larger
rasters.

Reference. NumPy in binary64, written from the documented definitions
(`test/oracles/rts03-embedding-rasters-numpy.py`). scikit-learn was not installed, so the kNN, logistic
regression and PCA semantics are written from its documentation and nothing was run or copied from it.
Additional verified TESSERA int8 and binary16 decoding, masks, and AlphaEarth int8 encoding are
described in [Embedding raster codecs](./raster-embedding-codecs.md). Model inference
(TerraMind, Prithvi, Clay) and training are outside these codecs.

## `GPURasterEmbeddingDequantize`

Aligned GraphVectorView pixel records support chunked input with 1–1,024 components; whole embedding
records stay together. Reference covariance-family dimensions remain 128.

AlphaEarth stores each component as an int8 `q` and decodes it as `sign(q) * (q / 127.5)^2`, with `q = -128`
as NoData; a pixel with NoData in any band is invalid. The decoded vector has length close to one, not
exactly one, because of the 8-bit rounding; set `normalize` to divide by the length so dot products are
exact cosines. `output.validity` is optional.

```ts
graph.add(new GPURasterEmbeddingDequantize({
  pixelCount: width * height,
  dimensions: 64,
  quantized: int8Words, // an uploaded Int8Array
  normalize: true,
  output: {vectors, validity}
}));
```

## `GPURasterEmbeddingSimilarity`

Aligned GraphVectorView pixel records support chunked input with 1–1,024 components; whole embedding
records stay together. Reference covariance-family dimensions remain 128.

Cosine (or dot) similarity of every pixel to up to 64 query vectors: `similarity` for every pixel and
query, the `maximum` over the queries, the `bestQuery` (the lowest on ties) and a `matches` mask for a
per-frame threshold. Queries come from clicked pixels or from `GPURasterEmbeddingZoneMean` (the mean of a
polygon, renormalized). Cosine follows the published `GPUSimilaritySearch`: two zero vectors have
similarity one and exactly one gives zero.

## `GPURasterEmbeddingNearestPixels`

"Find places like this one": the `resultCount` pixels most similar to each query, ranked by cosine, as pixel
indices and scores. It runs the published exact `GPUSimilaritySearch` of
`@luma.gl/graph/gpu-vector-search` on the raster's vectors, so equal scores order by pixel index and the
query-by-pixel matrix is never stored.
`output.pixelRows` contains physical zero-based raster rows, with `0xffffffff` for missing matches.
Kepler exposes these as the `pixel_row` column; these values are not caller identities.

## `GPURasterEmbeddingChange`

Aligned GraphVectorView pixel records support chunked input with 1–1,024 components; whole embedding
records stay together. Reference covariance-family dimensions remain 128.

The use Google recommends for AlphaEarth: the dot product between two years. Outputs are the cosine
similarity, the angle between the vectors (computed as `2 atan2(|u - v|, |u + v|)` of the two unit
vectors, not `acos` of the float32 cosine, so angles far below 5e-4 rad are resolved), the length of the
change vector `|after - before|` and a mask where the
cosine is below a per-frame threshold. A pixel invalid in either year is NaN. Combine the similarity with
`GPURasterFalseDiscoveryRateMask` or a percentile threshold when a map must show only significant change.

## `GPURasterEmbeddingKMeans`

Unsupervised clustering with the published `GPUKMeans` of `@luma.gl/graph/gpu-vector-search`: deterministic
evenly spaced valid rows as seeds (not k-means++), up to 64 Lloyd iterations encoded and skipped once the
labels stop changing, Euclidean centres and an optional `[iterations, changedLabels, converged]` status.
Normalize the vectors first to cluster by direction. This is a different contract from the planar
`GPUSpatialKMeans` of `gpu-spatial-analysis`. The check compares a converged run on separated blobs with NumPy's
blob means; it does not reproduce scikit-learn's seeding.
The optional status is `[executedIterations, changedLabels, converged]`, with `converged = 1` only
when labels stopped changing. Reaching the iteration budget with `converged = 0` leaves a provisional
clustering. Kepler requests this status for its fixed 32-round budget and refuses to publish the
label column if convergence was not reached; the error reports executed rounds and changed labels.

## `GPURasterEmbeddingKNearestClassifier`

Default searchStructure tiled performs exact exhaustive training in 256-row tiles. Brute-force
retains 4,096 training rows. Training count times dimensions must fit uint32 addressing, device
bindings and the command budget; aligned whole-pixel chunks support 1–1,024 dimensions.

Exact tiled k-nearest-neighbour classification against a labelled training set, with
scikit-learn's `KNeighborsClassifier` semantics: uniform votes among the `neighborCount` (at most 16)
nearest, the smallest class on a vote tie, the lower sample on equal distances. `metric` is `'euclidean'`
or `'cosine'` (distance `1 - cosine`; two zero vectors have similarity 1 and exactly one zero vector gives
0, as in the published `GPUSimilaritySearch`). Outputs are the label, the vote share of the winner and the share of
every class. The cost is `pixelCount x trainingCount x dimensions`.

## `GPURasterEmbeddingLinearProbe`

Aligned GraphVectorView pixel records support chunked input with 1–1,024 components; whole embedding
records stay together. Reference covariance-family dimensions remain 128.

Inference of a host-trained linear probe: `softmax(W x + b)`, the prediction of a multinomial
`LogisticRegression` (`coef_`, `intercept_`) with up to 64 classes, computed with the maximum subtracted so
large logits do not overflow. A binary scikit-learn model has one row; pass the two rows `[0, w]` with
intercepts `[0, b]`.

## PCA to RGB

`GPURasterEmbeddingProjection`: Aligned GraphVectorView pixel records support chunked input with
1–1,024 components; whole embedding records stay together. Reference covariance-family dimensions
remain 128.

Three steps, with only the eigenproblem on the CPU:

1. `GPURasterEmbeddingCovariance` writes the mean vector and the sample covariance (divisor `n - 1`) of the
   usable pixels. The sums are two-pass and in fixed-order partial ranges (`rangeCount` up to 256), so the
   result is reproducible.
2. `getRasterEmbeddingPrincipalComponents(covariance, dimensions, componentCount)` finds the components in
   binary64 (cyclic Jacobi, at most 128 x 128). The sign of each component makes its largest loading
   positive, scikit-learn's `svd_flip(u_based_decision=False)` convention, so maps agree with a NumPy or
   scikit-learn reference. `getRasterEmbeddingStretchRanges(eigenvalues, 2)` gives a two-sigma stretch.
3. `GPURasterEmbeddingProjection` writes the scores `(x - mean) . component` and, for three or more
   components, an RGB image stretched to `[0, 1]`.

```ts
const {components, eigenvalues} = getRasterEmbeddingPrincipalComponents(covarianceReadback, 64, 3);
const stretchRanges = getRasterEmbeddingStretchRanges(eigenvalues, 2);
const parameters = getGPURasterEmbeddingProjectionParameterValues({stretchRanges});
```

## `GPURasterEmbeddingZoneMean`

The mean embedding of each polygon, weighted by coverage and renormalized to unit length: a descriptor to
search with, or to compare zones. Pixels come from a `zoneRaster` (one id per pixel, weight one) or from
the compact tuples of `GPURasterFractionalCoverage` (`zoneIds`, `cellIds`, `fractions`, `status.count`), so a
border pixel shared by two polygons counts toward each in proportion to its overlap. Sums are 96-bit
fixed-point integers added atomically, so they do not depend on thread order; the only rounding is the
conversion to float32. `output.meanLengths` is the length of the mean before renormalization, 1 when the
zone points one way and near 0 when its pixels cancel. A zone without usable weight is NaN.

## `GPURasterEmbeddingPyramidLevel`

The unit-vector-mean overview. The generic mean overview (`GPURasterOverview`, `gdaladdo -r average`) is wrong
for these data: on raw int8 values it averages a nonlinear code, and on decoded vectors the mean of unit
vectors is shorter than one, which biases later dot products. AlphaEarth's own rule is to average the
decoded vectors and renormalize to unit length; this contributor does that for each footprint (partial
footprints at odd edges, scale 1 to 16 per axis) from either `vectors` or the packed `quantized` input.
`output.meanLength` and `validCount` say how coherent and how complete each footprint was.

Compute each overview from the original vectors, or request `output.vectorSums` and
`output.validCount` and pass that pair to the next level as
`aggregation: {vectorSums, validCount}`.

Give exactly one input mode: `vectors`, `quantized`, or `aggregation`. Aggregation sums contain
`sourceWidth * sourceHeight * dimensions` float32 components; counts contain one uint32 per child
pixel. Original-pixel counts must total at most 2^32 - 1 in each output footprint. Every level
retains the 1–16 scale limit per axis and 1–128 dimensions; sums/counts allow arbitrarily many
levels within the count and storage limits. Chaining preserves original-pixel weights up to
float32 summation rounding. Feeding normalized overview vectors into `vectors` gives each child
equal weight and loses both support size and concentration: `[east, east, north]` becomes
`(east + north) / sqrt(2)` after two scale-two reductions, instead of `(2 east + north) / sqrt(5)`.

An empty footprint has sums zero, count zero, mean length NaN and vector validity 0. An exactly
cancelling footprint has sums zero, a positive count, mean length zero and vector validity 0.
Its normalized vector is NaN, but its sums/counts remain usable for the next level. Do not use
the child's vector validity as the aggregation mask: that would discard cancellation support.
An explicit aggregation mask excludes whole child footprints.
Normalization scales by the largest absolute sum component before computing the squared norm.
For sums `[1, 0]` and `[-1, 2^-80]` with one supporting pixel each, the result retains count 2,
sum `[0, 2^-80]`, valid north direction `[0, 1]` and mean length `2^-81`; squaring that mean
directly in float32 would incorrectly classify it as cancellation. Sizes and nested aggregation/output
port maps are captured at construction, while GPU views retain their per-frame contents.

Writing an overview back as int8 needs the inverse of the decoder,
`q = sign(v) round(127.5 sqrt|v|)`, provided by `GPURasterEmbeddingQuantize` (nearest-even rounding with saturation).
