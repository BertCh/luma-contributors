Adaptive-bandwidth kernel density

Kernel density whose bandwidth narrows where points are dense and widens where sparse.

USGS ComCat M4+ earthquakes around Japan, 2020–2024: adaptive kernel density; each event’s bandwidth narrows where events are dense. 35% of the sample is drawn from sparse cells, which adds to the contrast.

Reading the result

Keeps dense clusters sharp without breaking scattered points into speckles. A fixed-bandwidth pilot sets each point bandwidth by Abramson’s square-root law, clamped to [h / L, h L].

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Packed point positions in grid units.
weightsGraphDataView<"float32"> | undefined-Optional non-negative point weights.
parameters*GraphDataView<"float32">-getGPUAdaptiveBandwidthKernelDensityParameterValues: h, sensitivity.
grid*GPURasterMetadata-Output raster grid.
bandwidthFactorLimitnumber | undefined4Clamp L of each point bandwidth; sets the search radius.
output*GPUAdaptiveBandwidthKernelDensityOutput-Density and optional per-point views.
and 2 more required: indexGridSize, indexBounds

Returns

FieldTypeDescription
valuesGraphDataView<"float32">Density per output cell.
pointBandwidthsGraphDataView<"float32">Optional bandwidth of each point.
pilotDensitiesGraphDataView<"float32">Optional fixed-bandwidth pilot density at each point.

Example

import {
  GPUAdaptiveBandwidthKernelDensity,
  getGPUAdaptiveBandwidthKernelDensityParameterValues
} from '@luma-contributors/analysis/gpu-spatial-analysis';

graph.add(new GPUAdaptiveBandwidthKernelDensity({
  positions, grid, indexGridSize: [64, 40], indexBounds,
  bandwidthFactorLimit: 4,
  parameters: graph.importBuffer(parameterBuffer, 'float32'),
  output: {values: density, pointBandwidths}
}));
parameterBuffer.write(getGPUAdaptiveBandwidthKernelDensityParameterValues(
  {bandwidth: 5000, sensitivity: 0.5},
  grid
));
