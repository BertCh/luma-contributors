Bivariate Classification

Classifies two columns into an n by n grid and colors rows from a bivariate palette.

Reading the result

Best for bivariate choropleths, such as income against transit access. Each axis has its own breaks; an optional third column fades the alpha.

Parameters

PropTypeDescription
valuesX*GraphDataView<'float32'>Packed float32 X value per row.
valuesY*GraphDataView<'float32'>Packed float32 Y value per row.
breaksX*GraphDataView<'float32'>X class edges.
breaksY*GraphDataView<'float32'>Y class edges.
palette*GraphDataView<'uint32'>Row-major rgba8 palette, y class by x class.
parameters*GraphDataView<'float32'>Class counts from getGPUBivariateClassificationParameterValues.
maximumClassCount*numberLargest class count per axis, 1 to 16.
alphaValuesGraphDataView<'float32'>Optional value-by-alpha variable.

Returns

FieldTypeDescription
classIdsGraphDataView<'uint32'>Combined class id per row.
colorsGraphDataView<'uint32'>Packed rgba8 color per row.
classCountsGraphDataView<'uint32'>Rows per class cell.

Example

import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUBivariateClassification, getGPUBivariateClassificationParameterValues} from '@luma-contributors/analysis/dataframe-analysis';

// valuesX, valuesY, breaksX, breaksY, palette, colors: views on graph
const classes = new GPUParameterBuffer(device, {id: 'bivariate', format: 'float32', length: 8});
graph.add(new GPUBivariateClassification({
  valuesX, valuesY, breaksX, breaksY, palette,
  parameters: classes.importToGraph(graph),
  maximumClassCount: 3,
  output: {colors}
}));
classes.write(getGPUBivariateClassificationParameterValues({classCountX: 3, classCountY: 3}));
