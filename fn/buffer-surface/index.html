Buffer surface

Grows a polygon buffer of a given distance around lines and polygons.

Buffer polygons of a given distance around lines or polygons (input muted).

Lake shorelines are sampled radially and placed in constructed geometry.

Reading the result

Best for proximity zones, setbacks and exclusion areas. Offset curves are generated per side, then merged by a nonzero polygon overlay into one clean surface. Distance is a per-frame parameter, so the buffer can animate without recompiling.

Parameters

PropTypeDefaultDescription
geometry*GPUPackedGeometryPort<GPUPolygonGeometryPort | GPULineGeometryPort>-Lines or polygons to buffer.
parameters*GraphDataView<'float32'>-Packed distance and mitre limit, rewritten per frame.
joinStyleGPUOffsetCurveJoinStyle'round'Corner join: 'round', 'mitre' or 'bevel'.
capStyleGPUBufferCapStyle'round'Line end cap: 'round', 'flat' or 'square'.
quadSegmentsnumber8Arc segments per quarter circle on round joins.
vertexTolerance*number-Snap tolerance for the overlay, in position units.
capacity*GPUPolygonOverlayCapacity-Upper bounds for intersections and noded segments.
output*GPUPolygonOverlayOutput-Caller-owned views that receive the buffer polygons.

Returns

FieldTypeDescription
geometryGPUPackedGeometryPort<GPUPolygonGeometryPort>Packed polygon rings of the buffer surface.
statusGPUPolygonOverlayOutput['status']count is polygons; requiredRingCount sizes the ring capacity; overflow flags.
boundaryGPUPolygonOverlayBoundaryPortBoundary rings of the buffer, for downstream assembly.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUBufferSurface, getGPUOffsetCurveParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'buffer'});
const parameters = new GPUParameterBuffer(device, {id: 'buffer-parameters', format: 'float32', length: 4});
// `roads` (packed lines) and `output` are graph views imported on `graph`.
graph.add(new GPUBufferSurface({
  geometry: roads,
  parameters: parameters.importToGraph(graph),
  joinStyle: 'round',
  vertexTolerance: 1e-3,
  capacity: {intersections: 20000, nodedSegments: 40000},
  output
}));
const compiled = await graph.compileAsync();
parameters.write(getGPUOffsetCurveParameterValues({distance: 50}));
compiled.encode(device.commandEncoder, {parameters: undefined});
