Reading the result

Best for urban-form studies of terraces, blocks and contiguity. It consumes shared-path runs, pairs buildings, and measures the wall lengths and orientation agreement. Components group connected buildings.

Parameters

PropTypeDefaultDescription
sharedPaths*GPUSharedPathsOutput-Shared-wall runs from GPUSharedPaths.
lineBuildingIds*GraphDataView<'uint32'>-Building id of every wall line.
orientations*GraphDataView<'float32'>-Axial orientation per building, radians.
contiguityGraphDataView<'uint32x2'>-Optional precomputed building pairs.
structuresGPUBuildingStructureGeometry-Optional structure geometry for extra measures.
idstring'building-adjacency'Prefix for graph resources.

Returns

FieldTypeDescription
outputs{pairs, lengths, morphology, components}Adjacent building pairs, shared wall lengths, morphology and components.
structures{perimeters, overlays}Intermediate perimeters and overlay results.
status{complete}1 when every stage finished within capacity.
provenance{sharedPaths, lineBuildingIds}Source ids tying outputs back to buildings.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {addBuildingAdjacencyRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'adjacency'});
// `sharedPaths` comes from a GPUSharedPaths node added to the same graph; the
// other inputs are graph views imported on `graph`.
const {outputs, status} = addBuildingAdjacencyRecipe(graph, {
  sharedPaths,
  lineBuildingIds,
  orientations
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// read outputs.pairs, outputs.morphology and outputs.components
