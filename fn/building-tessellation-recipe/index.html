Building tessellation

Divides the space around buildings into one cell per building, clipped to an enclosure.

Reading the result

Best for morphological tessellation: the plot of land each building would claim. Building boundaries are sampled, Voronoi fragments are clipped to the enclosure, then dissolved by owner. Sample and fragment capacities are explicit.

Parameters

PropTypeDefaultDescription
segments*GraphDataView<'float32x4'>-Building wall segments as (x0, y0, x1, y1).
segmentBuildingIds*GraphDataView<'uint32'>-Building id of every wall segment.
buildingCount*number-Number of buildings.
enclosure*GraphDataView<'float32x2'>-Outer boundary vertices.
enclosureMode"convex" | "simple"'convex'How the enclosure is clipped.
sampleSpacing*number-Distance between sampled wall points.
sampleCapacity*number-Upper bound on sampled points.
vertexTolerance*number-Snap tolerance in position units.
and 1 more required: capacity

Returns

FieldTypeDescription
outputsGPUPolygonOverlayOutput-like polygonsOne tessellation polygon per building.
intermediates{samples, owners, fragments, fragmentCounts}Sampled points and Voronoi fragments.
status{sampling, complete}Sampling status and a completion flag.
provenance{segments, segmentBuildingIds}Boundary segments and their owning buildings.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {addBuildingTessellationRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'tessellation'});
// Wall `segments`, `segmentBuildingIds` and `enclosure` are graph views on `graph`.
const {outputs, status} = addBuildingTessellationRecipe(graph, {
  segments,
  segmentBuildingIds,
  buildingCount: 480,
  enclosure,
  sampleSpacing: 2,
  sampleCapacity: 100000,
  vertexTolerance: 1e-3,
  capacity: {intersections: 200000, nodedSegments: 400000, vertices: 400000, rings: 200000}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
