Structural equality of normalized geometry trees, including nested empty collections.

Reading the result

Compares any normalized geometry, not only polygons. Give it root node pairs from two GPUNormalizeGeometry trees and read one flag per pair.

Parameters

PropTypeDescription
left*GPUCanonicalGeometryTreeNormalized tree, left side.
right*GPUCanonicalGeometryTreeNormalized tree, right side.
pairs*GraphDataView<"uint32x2">Root node ids in the left and right trees.
tolerancenumber | undefinedAbsolute per-coordinate tolerance.
output*GraphDataView<"uint32">Per pair: equal 1, unequal 0, invalid 2.

Returns

FieldTypeDescription
outputGraphDataView<"uint32">Equal 1, unequal 0, invalid 2.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCanonicalGeometryEquality} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUCanonicalGeometryEquality({
  left: treeA, right: treeB, // GPUNormalizeGeometry outputs
  pairs, // [leftRoot, rightRoot] per comparison
  output: equalFlags
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
