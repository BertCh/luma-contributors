Bins rows into grid cells and reduces them to a compact, sorted per-cell table.

Reading the result

Turns millions of points into a heat grid. Rows are keyed, sorted and reduced with integer atomics, so counts and sums are exact and repeatable. Output capacity is fixed; on overflow the smallest keys are kept and a flag is set.

Parameters

PropTypeDefaultDescription
family*GPUCellAggregationFamily-'quadbin' or 'h3'.
resolution*number-Output resolution; finer keys are truncated.
positionsGraphDataView<"float32x2">-Longitude/latitude rows (Quadbin).
cellsGraphDataView<"uint32x2">-Pre-keyed rows instead of positions.
valuesGraphDataView<"float32">-Optional values to sum, min and max per cell.
maskGraphDataView<"uint32">-Per-frame 0/1 row filter.
sumScalenumber65536Fixed-point scale of the exact sums.
output*GPUCellTable-Table views; capacity is cells.length.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">Occupied cell keys, ascending.
countsGraphDataView<"uint32">Rows per cell.
sumValuesGraphDataView<"float32">Sum of values per cell.
minimumsGraphDataView<"float32">Smallest value per cell.
maximumsGraphDataView<"float32">Largest value per cell.
statusGPUCardinalityPort & GPUOverflowStatusPortOccupied count, final overflow; candidateOverflow is zero for raw inputs.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCellAggregation} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'heat-grid'});
const positions = graph.importGPUData('positions', lonLatData); // GPUData<'float32x2'>
const values = graph.importGPUData('values', valueData); // GPUData<'float32'>
const table = importCellTable(graph, 4096); // your helper: cells, counts, sumValues, status views

graph.add(new GPUCellAggregation({
  family: 'quadbin', resolution: 14, positions, values, output: table
}));

const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
