Cell compaction

Compacts a cell set to its minimal mixed-resolution cover, or expands it to one resolution.

Reading the result

Use compact to store a region with the fewest cells, and uncompact to bring it back to one resolution for joins. Complete sibling groups merge into their parent. Works on Quadbin, H3 and S2.

Parameters

PropTypeDescription
family*GPUCellTopologyFamily'quadbin', 'h3' or 's2'.
operation*GPUCellCompactOperation | GPUCellUncompactOperation{type: 'compact' | 'uncompact', resolution}.
cells*GraphDataView<"uint32x2">Input cell keys.
maskGraphDataView<"uint32">Per-row 0/1 filter.
countGraphDataView<"uint32">GPU-side row count when the input is partly filled.
output*GPUCellCompactionOutputCells plus count and overflow status.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">Compacted or expanded keys.
status{count, requiredCount?, overflow, droppedCount?}Written count and overflow flag.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCellCompaction} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'compact'});
const cells = graph.importGPUData('cells', cellData); // GPUData<'uint32x2'>, all res 9
const compact = graph.importGPUData('compact', outputData); // GPUData<'uint32x2'>
const count = graph.importGPUData('count', countWord); // GPUData<'uint32'>
const overflow = graph.importGPUData('overflow', overflowWord); // GPUData<'uint32'>

graph.add(new GPUCellCompaction({
  family: 'h3', operation: {type: 'compact', resolution: 9}, cells,
  output: {cells: compact, status: {count, overflow}}
}));
const compiled = await graph.compileAsync();
