Cell flow topology

Splits origin-destination flows into cell totals and flows between neighboring H3 cells.

Reading the result

Shows which flows travel across shared cell borders. Totals use every pair; only actual neighbors become edges, with their shared boundary geometry. The original pair table is kept as is.

Parameters

PropTypeDescription
cells*GraphDataView<"uint32x2">Distinct H3 cells (little-endian) at one resolution.
origins*GraphDataView<"uint32">Origin row into cells, per pair.
destinations*GraphDataView<"uint32">Destination row into cells, per pair.
values*GraphDataView<"float32">Nonnegative finite flow per pair.
idstring | undefinedPrefix for every node and transient ID; set it when composing recipes.
outputsPartial<GPUCellFlowTopologyOutput> | undefinedCaller-owned views to keep.

Returns

FieldTypeDescription
outputs.outgoingTotalsGraphDataView<"float32">Total flow leaving each cell.
outputs.incomingTotalsGraphDataView<"float32">Total flow entering each cell.
outputs.neighboringCellsGraphDataView<"uint32x2">Canonical neighbor cell pairs.
outputs.edgeFlowsGraphDataView<"float32">Flow across each neighbor edge.
outputs.boundariesGraphDataView<"float32x2">Shared boundary vertices.
contributorsGPUCommandNodeProducer<Parameters>[]Graph nodes the recipe added, in execution order.
pairTable{pairs, counts}Origin and destination views per flow pair.
intermediates, statusmixed viewsFurther result fields; see the reference.

Example

import {addCellFlowTopologyRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; cells are H3 indices as uint32x2 words
const topology = addCellFlowTopologyRecipe(graph, {
  cells,
  origins, destinations, // pair rows into cells
  values                 // flow per pair
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// topology.outputs.edgeFlows only counts pairs of neighboring cells
