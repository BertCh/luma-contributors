Reading the result

Best for zoomable heat maps: every zoom level is ready before the user pans. List resolutions finest first. Pair it with level selection to switch levels without recomputing.

Parameters

PropTypeDescription
family*GPUCellAggregationFamily'quadbin' or 'h3'.
resolutions*readonly number[]Levels to build, finest first.
positionsGraphDataView<"float32x2">Longitude/latitude rows (Quadbin).
cellsGraphDataView<"uint32x2">Pre-keyed rows instead of positions.
valuesGraphDataView<"float32">Optional values summed per cell.
maskGraphDataView<"uint32">Per-frame 0/1 row filter.
output*GPUCellPyramidOutputTables with count, overflow and candidateOverflow; optional level counts.

Returns

FieldTypeDescription
levelsreadonly GPUCellTable[]Tables per resolution; overflow or candidateOverflow means incomplete.
levelCountsGraphDataView<"uint32">Occupied cells per level.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCellPyramid} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'pyramid'});
const positions = graph.importGPUData('positions', lonLatData);
const levels = [18, 14, 10, 6].map(() => importCellTable(graph, 8192));
// Each table supplies status: {count, overflow, candidateOverflow}; retain and read both loss flags.
const levelCounts = graph.importGPUData('level-counts', countData); // GPUData<'uint32'>

graph.add(new GPUCellPyramid({
  family: 'quadbin', positions, resolutions: [18, 14, 10, 6],
  output: {levels, levelCounts}
}));
const compiled = await graph.compileAsync();
