Cell rollup

Rolls a sorted cell table up to a coarser resolution without re-reading the source rows.

family
4
drawn

Fine cell table rolled up into parent cells: sums add up exactly.

Reading the result

Zooms out a grid you already aggregated. Parent keys truncate the cell path, which keeps key order, so no sort is needed. Counts and sums are integer sums and match direct aggregation bit for bit.

Parameters

PropTypeDescription
family*GPUCellAggregationFamily'quadbin' or 'h3'.
sourceResolution*numberResolution of the source table.
resolution*numberCoarser target resolution.
source*GPUCellTableSorted table from aggregation or another rollup.
sumScalenumberFixed-point scale; must match the source.
output*GPUCellTableParent table views, including status.candidateOverflow.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">Parent keys, ascending.
countsGraphDataView<"uint32">Summed child counts.
statusGPUCardinalityPort & GPUOverflowStatusPort & GPUCandidateStatusPortParent count, final/input loss; requiredCount is a lower bound after input loss.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCellAggregation, GPUCellRollup} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'rollup'});
const positions = graph.importGPUData('positions', lonLatData);
const fine = importCellTable(graph, 4096); // your helper: table views on this graph
const coarse = importCellTable(graph, 1024);

graph.add(new GPUCellAggregation({family: 'quadbin', resolution: 16, positions, output: fine}));
graph.add(new GPUCellRollup({
  family: 'quadbin', sourceResolution: 16, resolution: 12, source: fine, output: coarse
}));
const compiled = await graph.compileAsync();
