Reading the result

Draws the outline of a region made of cells, as cellsToMultiPolygon does, without ring assembly. Edges shared by two cells in the set drop out. Add rings to stitch the edges into closed rings.

Parameters

PropTypeDescription
family*GPUCellSetOutlineFamily'h3', 'quadbin' or 's2'; S2 cells must all be at one level.
cells*GraphDataView<"uint32x2">Cell keys of the region.
countGraphDataView<"uint32">GPU-side number of valid rows.
groupsGraphDataView<"uint32">Group id per cell; outlines are per group.
ringsGPUCellSetOutlineRingsAlso assemble edges into rings.
output*GPUCellSetOutlineOutputEdge endpoints and status.

Returns

FieldTypeDescription
rowsGraphDataView<'uint32'>Input row of the cell owning each edge.
endpointsGraphDataView<"float32x4">Boundary edge as start and end lon/lat.
cellsGraphDataView<"uint32x2">Owning cell of each edge.
edgeIndicesGraphDataView<"uint32">Edge index within its cell.
status{count, overflow, requiredCount?}Edge count and overflow flag.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUCellSetOutline} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'outline'});
const cells = graph.importGPUData('cells', cellData); // GPUData<'uint32x2'>
const {rows, cells: edgeCells, edgeIndices, endpoints, status} = edgeViews; // output views

graph.add(new GPUCellSetOutline({
  family: 'h3', cells,
  output: {rows, cells: edgeCells, edgeIndices, endpoints, status}
}));
const compiled = await graph.compileAsync();
