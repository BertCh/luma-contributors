Reading the result

The same operations as the weights transform, applied per chunk for large matrices. Pass one destination per chunk, in order. Chunk boundaries are preserved.

Parameters

PropTypeDescription
operation*GPUSpatialWeightsTransformOperationrow, binary, kernel, symmetrize, double or variance.
weights*GPUChunkedSpatialWeightsChunked weights to transform.
outputreadonly (GraphDataView<'float32'> | undefined)[] | undefinedDestination per chunk, same order.
kernelGPUSpatialWeightsKernel | undefinedKernel profile for the kernel operation.
bandwidthnumber | 'adaptive' | undefinedBandwidth of the kernel operation.
doubleSum'one' | 'rows' | undefinedTotal of the double transform.
spatialContextGPUSpatialContext | undefinedContext of a numeric bandwidth.

Returns

FieldTypeDescription
outputreadonly GraphDataView<'float32'>[]Transformed weights per chunk.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUChunkedSpatialWeightsTransform} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUChunkedSpatialWeightsTransform({
    operation: 'row',
    weights: chunkedWeights,
    output: chunkOutputs // one view per chunk
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
