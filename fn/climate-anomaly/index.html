Reading the result

Reads the means and sample standard deviations a GPURasterStreamingAccumulator holds per cell and calendar slot, and returns value - mean or, with standardized, a z-score. The state is unchanged, so one climatology serves any number of chunks.

Parameters

PropTypeDefaultDescription
cellCount*number-Cells per slice.
slotCount*number-Calendar slots per cell, in `[1, 366]`.
state*GPURasterStreamingState-counts, sums and moments of the accumulator.
accumulatorParameters*GraphDataView<"float32">-The accumulator's parameters (fixed-point units).
chunkSliceCountnumber-Slices of the chunk to express as anomalies.
valuesGraphDataView<"float32">-The chunk, cell-major; with `output.anomaly`.
slotIndicesGraphDataView<"uint32">-Slot of each chunk slice.
standardizedbooleanfalseDivide by the slot standard deviation.

Returns

FieldTypeDescription
anomalyGraphDataView<"float32">Anomaly or z-score per cell and chunk slice.
climatologyMeanGraphDataView<"float32">Mean per cell and slot.
standardDeviationGraphDataView<"float32">Sample standard deviation per cell and slot.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterClimateAnomaly} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const cellCount = 256 * 256;
const slotCount = 12;
const state = {counts: view('counts', 'uint32', cellCount * slotCount), sums: view('sums', 'uint32', cellCount * slotCount * 3), moments: view('moments', 'uint32', cellCount * slotCount * 3)}; // from GPURasterStreamingAccumulator
graph.add(new GPURasterClimateAnomaly({
  cellCount, slotCount, state, standardized: true,
  accumulatorParameters: view('accumulator-parameters', 'float32', 5),
  chunkSliceCount: 12,
  values: view('year', 'float32', cellCount * 12), slotIndices: view('slots', 'uint32', 12),
  output: {anomaly: view('anomaly', 'float32', cellCount * 12)}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
