Reading the result

Best for a dataset statistics panel that recomputes every frame as filters change. Up to 16 columns share one mask; distinct counts use HyperLogLog and categories come from dictionary codes.

Parameters

PropTypeDescription
columns*readonly GPUColumnProfileColumn[]One to 16 numeric or category columns of one table.
maskGraphDataView<'uint32'>Nonzero rows are profiled.
parametersGraphDataView<'float32'>Optional per-frame histogram domains; NaN means automatic.
histogramBinCount*numberEqual-width histogram bins per column.
hyperLogLogPrecisionnumberRegisters per column are 2^p; higher is more exact.
topCategoryCountnumberTop-category slots per column.

Returns

FieldTypeDescription
statisticsGraphDataView<'float32'>Minimum, maximum, mean, variance and more, per column.
countsGraphDataView<'uint32'>Valid and null counts per column.
histogramsGraphDataView<'uint32'>Histogram bins per column.
topCategoriesGraphDataView<'uint32'>Most frequent category codes and their counts.

Example

import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUColumnProfile} from '@luma-contributors/analysis/dataframe-analysis';

// fare, vendorCodes, mask, statistics, counts, histograms: views on graph
graph.add(new GPUColumnProfile({
  columns: [
    {values: fare},
    {values: vendorCodes, kind: 'category', categoryCount: 500}
  ],
  mask,
  histogramBinCount: 64,
  topCategoryCount: 10,
  output: {statistics, counts, histograms}
}));
