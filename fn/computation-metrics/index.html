Reading the result

Attaches GPU and CPU timings to a record so a lens page can animate the run. Timestamps disable pass coalescing, which the encoding flags record.

Parameters

PropTypeDescription
runId*stringComparison id shared with the record.
executionIdstringCopy record.executionId; omit only for legacy /1 sidecars.
graph*stringId of the timed graph.
timing*GPUComputationTimingInputPer-node CPU encode and GPU begin and end times.
encoding*GPUComputationEncodingFlagsFlags: coalesced, timestamped, taps, lensTwin.
adapterGPUComputationAdapterAdapter description.
seriesreadonly GPUComputationSeries[]Optional per-iteration series.
countersReadonly<Record<string, Readonly<Record<string, number>>>>Optional counters per node.

Returns

FieldTypeDescription
schemastringSchema identifier.
runIdstringRun the metrics measure.
executionIdstringExecution the metrics measure.
graphstringId of the measured graph.
timebase"ns" | "ms"Unit of GPU begin and end times.
adapterGPUComputationAdapterOptional adapter description.
encodingGPUComputationEncodingFlagsObserver effects in force.
nodesRecord<string, GPUComputationNodeMetrics>Timings and counters keyed by node id.

Example

import {createGPUComputationMetrics} from '@luma-contributors/analysis/computation-record';

const metrics = createGPUComputationMetrics({
  runId: record.runId,
  executionId: record.executionId,
  graph: 'compiled',
  encoding: {coalesced: false, timestamped: true, taps: 0, lensTwin: true},
  timing: {nodes: [{
    id: 'init', cpuEncodeTimeMilliseconds: 0.1,
    gpuBeginNanoseconds: 2000, gpuEndNanoseconds: 9000
  }]}
});
