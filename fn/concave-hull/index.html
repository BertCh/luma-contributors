Concave hull

Wraps a point set in an alpha-shape footprint that follows its real outline, holes included.

Reading the result

Best for building footprints from points, habitat extents and service areas. Delaunay triangles with a circumradius above maximumCircumradius are dropped, and the oriented boundary of the rest is returned. It is radius-based alpha-shape, not the ratio-based GEOS hull.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Input points.
maximumCircumradius*numberLargest kept triangle circumradius, in position units.
spatialContextGPUSpatialContextPlanar coordinates only.
output*GPUConcaveHull outputBoundary edges, triangles, their validity masks, and status.

Returns

FieldTypeDescription
boundaryEdgesGraphDataView<'uint32x2'>Oriented hull edges as point index pairs.
edgeValidityGraphDataView<'uint32'>Mask for real edges versus padding.
trianglesGraphDataView<'uint32x3'>Retained Delaunay triangles.
status{converged: GraphDataView<'uint32'>}Zero if tessellation did not finish.
triangleValidityGraphDataView<'uint32'>1 for each triangle kept in the hull.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUConcaveHull} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'concave-hull'});
// `positions` and the four output views are graph views imported on `graph`.
graph.add(new GPUConcaveHull({
  positions,
  maximumCircumradius: 150,
  output: {boundaryEdges, edgeValidity, triangles, triangleValidity, status: {converged}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// feed `boundaryEdges` to GPUSegmentRingAssembly for polygon rings
