Reading the result

Wraps any model: the interval half-width is the residual quantile of held-out calibration rows at 1 - miscoverage. With scales the intervals are normalized; with folds it is CV+. Miscoverage changes per frame.

Parameters

PropTypeDefaultDescription
calibration*GPUConformalCalibration-Held-out observations and predictions of the calibration rows.
query*GPUConformalQuery-Predictions (and scales) of the query rows.
foldCountnumber | undefined11 is split conformal; more is CV+.
parameters*GraphDataView<'float32'>-Per-frame miscoverage, from getGPUConformalPredictionParameterValues.

Returns

FieldTypeDescription
intervalsGraphDataView<'float32'>Lower and upper bound per query row.
statusGraphDataView<'uint32'>Status bits per query row.
calibrationCountGraphDataView<'uint32'>Calibration rows used.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUConformalPredictionIntervals, getGPUConformalPredictionParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length): caller-owned storage views
parameterBuffer.write(getGPUConformalPredictionParameterValues({miscoverage: 0.1}));
graph.add(
  new GPUConformalPredictionIntervals({
    calibration: {observations: heldOut, predictions: heldOutPredictions},
    query: {predictions},
    parameters: parameterBuffer.importToGraph(graph),
    output: {
      intervals: output('intervals', 'float32', 2 * queryCount),
      status: output('status', 'uint32', queryCount),
      calibrationCount: output('count', 'uint32', 1)
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
