Reading the result

The starting point for most areal statistics. queen joins polygons sharing a vertex; rook needs a shared edge. Multipart features and holes count, one row per feature.

Parameters

PropTypeDefaultDescription
criterion*GPUContiguityCriterion-'queen' shares a vertex; 'rook' shares an edge.
polygons*GPUPolygonGeometryPort-Polygons in the four-level layout.
output*GPUSpatialWeightsOutput-Caller-owned CSR with an overflow flag.
snapTolerancenumber | undefined0Vertex snap tolerance in coordinate units.
pairCapacitynumber | undefined-Capacity of the intermediate pair list.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>CSR row offsets, featureCount + 1.
neighborsGraphDataView<'uint32'>Neighbor feature ids, ascending per row.
weightsGraphDataView<'float32'>Binary weights, 1 per link.
status.overflowGraphDataView<'uint32'>1 if capacity was too small.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUContiguityWeights} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
const weights = csr(featureCount, 8 * featureCount);
graph.add(
  new GPUContiguityWeights({
    criterion: 'queen',
    polygons: {
      kind: 'polygons',
      positions, ringOffsets, polygonOffsets, featureOffsets // graph views
    },
    output: weights
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
