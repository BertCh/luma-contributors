Cube layout transpose

Moves a cell-by-period cube between cell-major and period-major layouts, bit for bit.

Props
values
cellCount
Sample data
0 fJ
drawn

Flash counts and mean energy per cell and hour: the same cube stored cell-major (left, row per cell) and period-major (right, row per period). The lines trace the stored row of the hovered bin.

Reading the result

Use it to hand one cube to operators that expect different layouts: cell-major for hot spots, period-major for Markov chains and panels. Works on uint32 or float32. Transposing twice returns the original.

Parameters

PropTypeDescription
values*GraphDataView<'uint32'> | GraphDataView<'float32'>Packed cube in the from layout.
from*'cell-major' | 'period-major'Layout of values; the output holds the other.
cellCount*numberNumber of cells.
periodCount*numberNumber of periods.
output*GraphDataView<'uint32'> | GraphDataView<'float32'>Cube of the same format and length.

Returns

FieldTypeDescription
outputGraphDataView<'uint32'> | GraphDataView<'float32'>The cube in the other layout.

Example

import {GPUCubeLayoutTranspose} from '@luma-contributors/analysis/dataframe-analysis';

// responseMeans (cell-major, from GPUValueCube), responsePeriodMajor: views on graph
graph.add(new GPUCubeLayoutTranspose({
  values: responseMeans, // cell * periodCount + period
  from: 'cell-major',
  cellCount: 36,
  periodCount: 12,
  output: responsePeriodMajor // period * cellCount + cell
}));
