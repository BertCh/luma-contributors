Dasymetric redistribution

Redistributes source totals to target zones using an ancillary raster, with a mass ledger.

Props
denominator
Sample data
0.80
1.0

Zone totals pushed down to target zones where the ancillary raster is bright.

Population weights are modeled from built-up coverage and redistributed across constructed zones.

Reading the result

Best when a total must follow where people actually are, such as population following built-up land. Eligible cells receive weight from the ancillary band, each source total is spread over its cells, and the ledger shows what was left unallocated.

Example

import {addDasymetricRedistributionRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; ancillary is a calibrated raster band, e.g. built-up density
const redistribution = addDasymetricRedistributionRecipe(graph, {
  grid,
  // tractRasterization: {tupleCapacity, parameters}; parameters is packed with
  // getGPURasterFractionalCoverageParameterValues(grid)
  source: {kind: 'polygons', zones: tractPolygons, ...tractRasterization},
  sourceTotals: tractPopulation,
  targetZones: districtPerCell,
  targetZoneCount: districtCount,
  ancillary: builtUpDensity,
  pairCapacity: 1 << 18
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// redistribution.outputs.targetTotals, and the unallocated ledger beside it
