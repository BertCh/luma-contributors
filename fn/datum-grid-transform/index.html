Reading the result

Moves positions between datums or vertical references, as NADCON or geoid grids define. The first grid covering a point wins, nodata fails the row, and inverse runs a bounded iteration.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x3'>-float32x3: longitude, latitude (degrees), height.
samples*GraphDataView<'float32x3'>-float32x3 shifts: longitude, latitude, height.
mask*GraphDataView<'uint32'>-Zero marks nodata.
grids*readonly GPUDatumGrid[]-Ordered regular grids; the first covering grid wins.
operation*'horizontal' | 'vertical' | 'combined'-'horizontal', 'vertical' or 'combined'.
direction'forward' | 'inverse'-'forward' or 'inverse'.
maximumIterationsnumber-Inverse iteration bound.
tolerancenumber5e-9Inverse residual tolerance in degrees.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x3'>Shifted positions.
positionsLowGraphDataView<'float32x3'>Optional residual words keeping sub-float32 detail.
statusGraphDataView<'uint32'>success, invalid, noCoverage, nodata or inverseExhausted.

Example

import {GPUDatumGridTransform} from '@luma-contributors/analysis/geospatial-analysis';

// positions, samples, mask, shiftedPositions, statusWords: views on graph
graph.add(new GPUDatumGridTransform({
  positions, samples, mask,
  grids: [{width: 65, height: 31, sampleOffset: 0, origin: [-96, 35.5], spacing: [0.25, 0.25]}],
  operation: 'horizontal', direction: 'forward',
  output: {positions: shiftedPositions, status: statusWords}
}));
