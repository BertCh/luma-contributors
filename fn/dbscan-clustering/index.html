DBSCAN clustering

Groups nearby points into density-based clusters of any shape and labels the rest as noise.

Reading the result

Best for clusters of unknown number, such as incident hot zones or stop locations. A point is core when it has enough neighbors within epsilon; clusters are connected core points.

  • Radius and minimum points define density groups; noise points are not assigned to a cluster.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar point coordinates, one float32x2 per point.
parameters*GraphDataView<"float32">Bounds, epsilon and minimumPoints from the packer.
gridSize*readonly [number, number]Neighbor-search lattice size in cells.
sourceIdsGraphDataView<"uint32"> | undefinedIds reported as cluster roots.
sumOrder"sorted" | "atomic" | undefinedCentroid sum order: deterministic or fast.
output*GPUSpatialClusteringOutputLabels plus optional core flags and clusters.

Returns

FieldTypeDescription
labelsGraphDataView<"uint32">Cluster id per point, or 0xffffffff for noise.
coreFlagsGraphDataView<"uint32">1 for core points.
clusterCountGraphDataView<"uint32">Number of clusters k.

Example

import {GPUSpatialClustering, getGPUSpatialClusteringParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

// The demo above: bounds spanning 1 unit, epsilon 2.6% of it, 6 points
const values = getGPUSpatialClusteringParameterValues({bounds, epsilon: 0.026, minimumPoints: 6});
const parameters = new GPUParameterBuffer(device, {
  id: 'dbscan', format: 'float32', length: values.length, values
});
graph.add(new GPUSpatialClustering({
  positions, gridSize: [256, 256],
  parameters: parameters.importToGraph(graph),
  output: {labels, clusterCount}
}));
