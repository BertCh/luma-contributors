Distance field

Computes Euclidean distance and nearest-seed allocation (Voronoi zones) on a raster from seed points or a mask.

Reading the result

Best for proximity surfaces, buffers-as-rasters and straight-line catchments. exact mode is an exact distance transform; jump-flood trades exactness for speed.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Raster grid: width, height, cell size and extent.
parameters*GraphDataView<"float32">-Packed maximumDistance and localOrigin from the packer.
seedPositionsGraphDataView<"float32x2"> | undefined-Seed points in ground coordinates, snapped to cells.
seedIdsGraphDataView<"uint32"> | undefinedrow indexSeed id per point.
seedMaskGraphDataView<"uint32"> | undefined-Per-cell seed raster; nonzero cells are seeds.
modeGPUDistanceFieldMode | undefined-'exact' or 'jump-flood'.
output*GPUDistanceFieldOutput-Caller-owned output views.

Returns

FieldTypeDescription
distancesGraphDataView<"float32">Ground distance to the nearest seed; Infinity if none.
allocationGraphDataView<"uint32">Id of the nearest seed (Voronoi zones).
nearestCellsGraphDataView<"uint32">Cell index of the nearest seed.
withinDistanceGraphDataView<"uint32">1 when a seed lies within maximumDistance.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUDistanceField, getGPUDistanceFieldParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'distance'});
const parameters = new GPUParameterBuffer(device, {id: 'df-parameters', format: 'float32', length: 8});

// seedPositions: float32x2 view of stations in ground coordinates
graph.add(new GPUDistanceField({
  grid, parameters: parameters.importToGraph(graph), seedPositions, seedCount,
  output: {distances, allocation, withinDistance}
}));
const compiled = await graph.compileAsync();
parameters.write(getGPUDistanceFieldParameterValues({maximumDistance: 500}, grid));
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
