Reading the result

Shows a count or rate without large empty regions dominating the map. Circle area follows the value, and circles are pushed apart while a weak pull keeps them near their true location. Iterations are bounded and reported.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>True location of every area.
values*GraphDataView<'float32'>Value that sets circle area.
areaScalenumberScale from value to circle area.
maximumIterationsnumberRelaxation rounds before stopping.
overlapTolerancenumberOverlap accepted as converged.
attractionnumberPull back toward the true location.
neighborGridboolean | "auto"Use a grid for neighbor search on large inputs.
output*GPUDorlingCartogramOutputCaller-owned circle views.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x2'>Circle centers after relaxation.
radiiGraphDataView<'float32'>Circle radius per area.
metricsGraphDataView<'float32x2'>Overlap and displacement diagnostics.
statusGraphDataView<'uint32'>Converged flag and iteration count.
sourceIdsGraphDataView<'uint32'>Source feature id of each circle.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUDorlingCartogram} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'dorling'});
// `centroids`, `population` and `output` are graph views imported on `graph`.
graph.add(new GPUDorlingCartogram({
  positions: centroids,
  values: population,
  areaScale: 0.5,
  maximumIterations: 200,
  attraction: 0.05,
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
