Reading the result

Goes from a DEM to catchments and a drawable river network in one graph. Depression filling and flat resolution stay explicit flow options, and a live parameter sets the stream threshold. Add pour points to key catchments by outlet.

  • Pits and flat cells can interrupt drainage; depression filling and stream threshold change the network.

Parameters

PropTypeDefaultDescription
flow*Omit<GPUTerrainFlowProps, "id" | "output" | "flowRouting">-Terrain flow inputs: grid, elevations, stream threshold.
pourPointsGraphDataView<"uint32"> | undefined-Outlet cell IDs; catchments are keyed by pour point.
maximumStepsnumber | undefined-Bound on downstream tracing.
reachCapacitynumber | undefinedcellCountCapacity of the stream reach list.
vertexCapacitynumber | undefined2 * cellCountCapacity of the reach vertex list.
idstring | undefined-Prefix for every node and transient ID; set it when composing recipes.

Returns

FieldTypeDescription
outputs.flowDirectionsGraphDataView<"uint32">D8 direction per cell.
outputs.accumulationGraphDataView<"float32">Upstream cell count per cell.
outputs.streamOrderGraphDataView<"uint32">Strahler order of stream cells.
outputs.catchmentsGraphDataView<"uint32">Watershed label per cell.
outputs.networkGPUDrainageNetworkOutputReaches: source/target cells, vertices, lengths.
contributorsGPUCommandNodeProducer<Parameters>[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, GraphDataView>Named stage ports; graph-owned, not for readback.
statusRecord<string, GraphDataView>GPU status words; zero means complete.

Example

import {addDrainageNetworkRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; flow takes the GPUTerrainFlow inputs
const drainage = addDrainageNetworkRecipe(graph, {
  flow: {grid, elevation: filledDem, fillDepressions: true, maximumFillIterations: 64, parameters: flowParameters},
  pourPoints: outletCells
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// drainage.outputs.network: reach polylines you can draw directly
// drainage.outputs.catchments: watershed id per cell
