Exposure by zone

Sums the population at or above a hazard threshold per zone, with observed coverage kept apart.

Modeled flood exposure weighted by the built-up fraction in Hyde Park.

The hazard and population weights are modeled using observed built-up coverage.

Reading the result

Best for flood, heat or smoke exposure by district. Missing hazard cells stay in the denominator and are reported as coverage, never as safe. The threshold is a live one-row view, so you can scrub it.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height and affine transform.
hazard*GPURasterBufferBandHazard band; missing cells are unknown.
population*GPURasterBufferBandPopulation count or density band.
weightMeaning*"count" | "density"Whether population is per cell or per area.
cellAreasGraphDataView<"float32"> | undefinedRequired for density populations.
zones*GraphDataView<"uint32">Whole-cell zone ID per cell.
zoneCount*numberNumber of zones.
threshold*GraphDataView<"float32">One-row hazard cutoff; values >= it are exposed.

Returns

FieldTypeDescription
outputs.totalPopulationGraphDataView<"float32">Known population per zone.
outputs.exposedPopulationGraphDataView<"float32">Population at or above the cutoff.
outputs.coverageGraphDataView<"float32">Share of population with an observed hazard.
outputs.exposedShareGraphDataView<"float32">Exposed share among observed population.
contributorsGPUCommandNodeProducer<Parameters>[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, GraphDataView>Named stage ports; graph-owned, not for readback.
statusRecord<string, GraphDataView>GPU status words; zero means complete.

Example

import {addExposureByZoneRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; hazard and population are aligned buffer bands
const exposure = addExposureByZoneRecipe(graph, {
  grid,
  hazard: floodDepthBand,
  population: populationBand,
  weightMeaning: 'count',
  zones: districtPerCell,
  zoneCount: districtCount,
  threshold: thresholdView // one float32 row, rewritten per frame
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// exposure.outputs.exposedShare beside exposure.outputs.coverage
