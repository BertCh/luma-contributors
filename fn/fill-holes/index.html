Fill holes

Fills background regions of a binary mask that do not connect to the raster edge.

Reading the result

Closes lakes inside land, gaps inside footprints or voids in classified patches. Background connectivity decides what counts as enclosed.

Parameters

PropTypeDescription
grid*GPURasterMetadataGrid of the mask.
input*GraphDataView<"uint32">Binary mask; nonzero is foreground.
connectivity4 | 8Background connectivity.
maximumIterationsnumberBounded number of rounds.
output*{values}values and a converged status.

Returns

FieldTypeDescription
valuesGraphDataView<"uint32">Mask with enclosed holes filled.
status.convergedGraphDataView<"uint32">1 when the flood reached a fixpoint.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterFillHoles, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `mask` is a uint32 graph view, one row per pixel.
graph.add(new GPURasterFillHoles({
  grid,
  input: mask,
  connectivity: 4,
  output: {values: view('filled', 'uint32', 512 * 512), status: {converged: view('converged', 'uint32', 1)}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
