Fleet dwell from zone events

Enter and exit events per zone, dwell per track and zone, and a per-zone roll-up.

Crossings per zone (small dots; exits ringed) and the dwell they add up to.

The vessel tracks are observed. Zone boundaries are constructed.

Reading the result

Best when dwell should mean time inside a zone, not time stopped. It runs zone-event detection, then sums dwell into one dense row per zone. Planar only.

Example

import {addFleetDwellZoneEventsRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; float32-relative or Int64 timestamps, plus the same zones as the stops variant
const dwell = addFleetDwellZoneEventsRecipe(graph, {
  trajectories: {kind: 'trajectories', positions, timestamps, trackOffsets},
  zones,
  candidateCapacity: 65536,
  trackEventCapacity: 16
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// dwell.table: visits and dwell per zone; dwell.events: each enter and exit
