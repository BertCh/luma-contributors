Computes mean center, median center, standard distance and directional ellipse per group.

Reading the result

Summarizes where a set of events sits and how it is stretched, such as crime by type or species by year. Weights and group ids allow many groups in one pass. Ellipse vertices are ready to draw.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Point locations.
parameters*GraphDataView<'float32'>-Origin and ellipse deviations.
weightsGraphDataView<'float32'>-Per-point weight.
groupIdsGraphDataView<'uint32'>-Group id per point.
groupCountnumber-Number of groups.
maskGraphDataView<'uint32'>-Zero excludes a point.
maximumMedianIterationsnumber-Weiszfeld iteration cap.
reduction'auto' | 'chunked' | 'sorted''auto'Group reduction strategy.

Returns

FieldTypeDescription
meanCentersGraphDataView<'float32x2'>Weighted mean center per group.
medianCentersGraphDataView<'float32x2'>Geometric median per group.
standardDistancesGraphDataView<'float32'>Standard distance per group.
ellipsesGraphDataView<'float32'>Directional ellipse parameters.
ellipseVerticesGraphDataView<'float32x2'>Outline vertices for drawing.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGeographicDistribution, GPU_GEOGRAPHIC_DISTRIBUTION_PARAMETER_LENGTH, getGPUGeographicDistributionParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'distribution'});
const parameters = new GPUParameterBuffer(device, {
  id: 'distribution-parameters', format: 'float32', length: GPU_GEOGRAPHIC_DISTRIBUTION_PARAMETER_LENGTH,
  values: getGPUGeographicDistributionParameterValues({origin: [x0, y0], standardDeviations: 2})
});
// positions, weights, groupIds, outputs: graph views
graph.add(new GPUGeographicDistribution({
  positions, weights, groupIds, groupCount: 8,
  parameters: parameters.importToGraph(graph),
  output: {meanCenters, standardDistances, ellipses, ellipseVertices}
}));
graph.compile().encode(device.commandEncoder, {parameters: undefined});
