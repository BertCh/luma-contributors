Geometry cleanup

Snaps coordinates to a grid and drops repeated vertices from points, lines or polygons.

Reading the result

Sheds redundant vertices and noise before storage or rendering. Grid size and repeat tolerance are per-frame parameters, so you can scrub them live.

Parameters

PropTypeDescription
geometryType*"points"Feature kind: points, lines or polygons.
positions*GraphDataView<"float32x2">Packed planar vertex positions.
parameters*GraphDataView<"float32">From getGPUGeometryCleanupParameterValues.
output*GPUGeometryCleanupPointOutputOutput views for the geometry kind.
lineOffsetsGraphDataView<"uint32">Feature-to-vertex offsets for lines.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x2'>Snapped, deduplicated vertices.
lineOffsetsGraphDataView<'uint32'> | undefinedOptional line start offsets.
ringOffsetsGraphDataView<'uint32'> | undefinedOptional ring start offsets.
statusGPUGeometryCleanupStatusWritten counts and overflow flags.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGeometryCleanup} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
// parameters: getGPUGeometryCleanupParameterValues({gridSize: 0.01, tolerance: 0.001})
graph.add(new GPUGeometryCleanup({
  geometryType: 'lines', positions, lineOffsets, parameters, output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
