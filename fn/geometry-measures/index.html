Geometry measures

Length, area, centroid, bounds and vertex count of every line or polygon at once.

Reading the result

Sizes, ranks or filters features without leaving the GPU. Polygon area is shell minus holes, never negative. Planar, spherical and ellipsoidal metrics come from spatialContext.

Parameters

PropTypeDescription
geometryType*"polygons"Feature kind: lines or polygons.
positions*GraphDataView<"float32x2">Packed planar vertex positions.
featureOffsets*GraphDataView<"uint32">Feature-to-polygon offsets with one terminal entry.
spatialContextGPUSpatialContext | undefinedCoordinate and metric contract; omitted means native planar.
outputGPUGeometryMeasuresOutput | undefinedPer-feature columns to write.
groupIdsGraphDataView<"uint32"> | undefinedOptional per-feature group ids for grouped totals.
groupCountnumber | undefinedNumber of groups.
ellipsoidalEdgeModel"coordinate-linear" | "geodesic" | undefinedEdge interpretation for ellipsoidal polygon areas.

Returns

FieldTypeDescription
lengthsGraphDataView<"float32">Line length or polygon perimeter.
areasGraphDataView<"float32">Polygon area, shell minus holes.
centroidsGraphDataView<"float32x2">Area or length weighted centroid.
boundsGraphDataView<"float32x4">[minX, minY, maxX, maxY] per feature.
vertexCountsGraphDataView<"uint32">Vertex rows per feature.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGeometryMeasures} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUGeometryMeasures({
  geometryType: 'polygons',
  positions, featureOffsets, polygonOffsets, ringOffsets,
  output: {areas, lengths, centroids, bounds}
  // longitude/latitude: spatialContext with metric ellipsoidal
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
