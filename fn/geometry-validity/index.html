Reading the result

The GPU analog of ST_IsValidReason. Issue codes name observed defects and advisories; use the separate nonzero-usable validity output to filter rows. Incomplete intersection checks suppress usability.

Parameters

PropTypeDescription
polygonsGPUPackedGeometryPort<GPUPolygonGeometryPort> | undefinedPolygon features.
linesGPUPackedGeometryPort<GPULineGeometryPort> | undefinedLinestring features.
pointsGPUPackedGeometryPort<GPUPointGeometryPort> | undefinedPoint features.
output*GPUGeometryValidityOutputissueCode, optional validity, and status.overflow required for polygons.
ringClosureGPUGeometryValidityRingClosure | undefinedRing closure convention.
orientationGPUGeometryValidityOrientation | undefinedRing orientation convention.
intersectionCapacitynumber | undefinedCapacity of the self-intersection list.

Returns

FieldTypeDescription
issueCodeGraphDataView<"uint32">Observed issue bits per feature; decode with decodeGPUGeometryValidityIssueCode.
validityGraphDataView<"uint32"> | undefinedNonzero when implemented structural checks pass with complete evidence.
status{overflow, intersectionCount?}Intersection capacity status; scalar outputs are zero for points and lines.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGeometryValidity} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUGeometryValidity({
  polygons: {kind: 'polygons', positions, featureOffsets, polygonOffsets, ringOffsets},
  intersectionCapacity: 1024,
  output: {issueCode, validity, status: {overflow}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
