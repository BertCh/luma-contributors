Global permutation test

Gets a pseudo p-value for a global statistic by shuffling values across the map.

Reading the result

Best when normal assumptions are doubtful. It reshuffles values, recomputes Moran's I, Geary's C, G, bivariate Moran or Lee's L each time, and ranks the observed value in that reference distribution.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GPUFloat32OrUint32Values-One value per row; non-finite rows are excluded.
statistic*GPUGlobalPermutationStatistic-'moran', 'geary', 'getisOrdG', 'bivariateMoran' or 'leesL'.
parameters*GraphDataView<"uint32">-Per-frame seed and permutation count from getGPUPermutationParameterValues.
maximumPermutations*number-Compile-time cap on permutations; the per-frame count may not exceed it.
alternativeGPUInferenceAlternative | undefined'two-sided'Tail of the test: 'two-sided', 'greater' or 'lesser'.
stopAfterExceedancesnumber | undefined-Stop early once this many permutations exceed the observed value.
output*GPUGlobalPermutationTestOutput-Summary, optional distribution and histogram.

Returns

FieldTypeDescription
summaryGraphDataView<"float32">Observed, pseudo p, simulated z, laid out by GPU_GLOBAL_PERMUTATION_SUMMARY.
referenceDistributionGraphDataView<"float32">Statistic of each permutation.
histogramGraphDataView<"uint32">Binned reference distribution.

Example

import {GPUGlobalPermutationTest, GPU_PERMUTATION_PARAMETER_LENGTH, getGPUPermutationParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const permutation = new GPUParameterBuffer(device, {
  id: 'permutation', format: 'uint32', length: GPU_PERMUTATION_PARAMETER_LENGTH,
  values: getGPUPermutationParameterValues({seed: 3, permutationCount: 999})
});
graph.add(new GPUGlobalPermutationTest({
  weights, values, statistic: 'moran',
  parameters: permutation.importToGraph(graph),
  maximumPermutations: 999,
  output: {summary, histogram}
}));
