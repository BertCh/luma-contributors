Global autocorrelation

Computes Moran's I, Geary's C, Getis-Ord G, bivariate Moran and join counts in one pass.

Global Moran, Geary and Getis-Ord G: signed significance of each against its expectation.

The noise control perturbs station observations.

Reading the result

Tests whether a whole map is clustered, dispersed or random before mapping local statistics. Each statistic has an analytic z and p.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GPUFloat32OrUint32Values-One value per row; non-finite rows are excluded.
statistics*readonly GPUGlobalSpatialStatistic[]-Any of 'moran', 'geary', 'getisOrdG', 'bivariateMoran', 'joinCount'.
secondValuesGPUFloat32OrUint32Values | undefined-Second variable for bivariate Moran.
alternativeGPUInferenceAlternative | undefined'two-sided'Tail of the test: 'two-sided', 'greater' or 'lesser'.
islandsGPUIslandPolicy | undefined'exclude'Rows without neighbors: 'exclude' them or 'keep' (esda convention).
maskGraphDataView<"uint32"> | undefined-Nonzero rows take part in the analysis.
output*GPUGlobalSpatialStatisticsOutput-Summary block laid out by GPU_GLOBAL_SPATIAL_STATISTICS_LAYOUT.

Returns

FieldTypeDescription
summaryGraphDataView<"float32">Statistic, expectation, variance, z and p per requested block.
joinCountsGraphDataView<"uint32">Ordered-pair [BB, BW, WW] join counts.

Example

import {GPUGlobalSpatialStatistics} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPUGlobalSpatialStatistics({
  weights, values,
  statistics: ['moran', 'geary', 'getisOrdG'],
  alternative: 'greater',
  output: {summary}
}));
// read summary with GPU_GLOBAL_SPATIAL_STATISTICS_LAYOUT
