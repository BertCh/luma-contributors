Reading the result

Best for fishnets, hex bins and sampling lattices (turf squareGrid, GeoPandas make_grid). Origin and cell size are per-frame parameters, so a grid can pan and zoom without recompiling. Optionally clip to an extent.

Parameters

PropTypeDescription
gridType*GPUGridType'square', 'hex', 'triangle' or 'point'.
columns*numberCells across.
rows*numberCells down.
hexOrientation"pointy" | "flat"Hexagon orientation.
parameters*GraphDataView<'float32'>Packed origin and cell size.
extentGPUPolygonGeometryPortClip cells to this polygon extent.
spatialContextGPUSpatialContextPlanar by default.
output*GPUGridGeneratorOutputChoose centers, corners or positions.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x2'>Optional grid polygon vertices.
centersGraphDataView<'float32x2'>Optional cell centers.
cornersGraphDataView<'float32x2'>Optional cell corner positions.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGridGenerator, getGPUGridGeneratorParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'grid'});
const parameters = new GPUParameterBuffer(device, {id: 'grid-parameters', format: 'float32', length: 4});
// `centers`, `positions` and the output views are graph views imported on `graph`.
graph.add(new GPUGridGenerator({
  gridType: 'hex',
  columns: 64,
  rows: 48,
  parameters: parameters.importToGraph(graph),
  output: {centers, positions}
}));
const compiled = await graph.compileAsync();
parameters.write(getGPUGridGeneratorParameterValues({minX: -122.5, minY: 37.7, cellWidth: 0.01, cellHeight: 0.01}));
compiled.encode(device.commandEncoder, {parameters: undefined});
