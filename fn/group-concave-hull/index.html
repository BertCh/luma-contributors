Reading the result

Outlines clusters from DBSCAN-style labels or any group ID column with one group-aware Delaunay build. Fixed layout reserves T=max(0,2*n-5) triangles and 3*T edges per group; packed layout reserves those totals across all groups. Both layouts publish groupCount convergence rows and preserve oriented boundaries for ring assembly.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Input points.
groupIds*GraphDataView<'uint32'>-Group id of every point.
groupCount*number-Number of groups.
layout'fixed' | 'packed''fixed'Fixed group slots, or compact group-major triangle and edge lists.
maximumCircumradius*number-Largest kept triangle circumradius, in position units.
spatialContextGPUSpatialContext-Planar coordinates only.
output*GPUGroupConcaveHull output-Geometry, validity, convergence and packed ranges/status when selected.

Returns

FieldTypeDescription
boundaryEdgesGraphDataView<'uint32x2'>Oriented hull edges across all groups.
edgeValidityGraphDataView<'uint32'>Mask for real edges versus padding.
trianglesGraphDataView<'uint32x3'>Retained triangles across groups.
triangleValidityGraphDataView<'uint32'>1 for each triangle kept in the hull.
status.convergedGraphDataView<'uint32'>groupCount rows in both layouts; 0 suppresses that group’s geometry.
groups{triangleOffsets, triangleCounts, edgeOffsets, edgeCounts} | undefinedPacked only: per-group starts and counts in triangle and boundary lists.
status.count, status.requiredCount, status.overflowGraphDataView<'uint32'>Packed only: written/required edge counts; overflow zero with full reservation.

Example

import {createTransientView} from '@luma.gl/graph/gpu-core';
import {GPUGroupConcaveHull, getDelaunayMaximumTriangleCount} from '@luma-contributors/analysis/gpu-spatial-analysis';
// positions and labels are already imported on graph; allocate for two groups.
const groupCount = 2;
const triangleCapacity = getDelaunayMaximumTriangleCount(positions.length);
const scalar = (name: string, length = 1) => createTransientView(graph, name, 'uint32', length);
graph.add(new GPUGroupConcaveHull({
  positions, groupIds: labels, groupCount, layout: 'packed',
  maximumCircumradius: 80,
  output: {
    triangles: createTransientView(graph, 'triangles', 'uint32x3', triangleCapacity),
    triangleValidity: scalar('triangle-validity', triangleCapacity),
    boundaryEdges: createTransientView(graph, 'edges', 'uint32x2', 3 * triangleCapacity),
    edgeValidity: scalar('edge-validity', 3 * triangleCapacity),
    status: {converged: scalar('converged', groupCount), count: scalar('count'),
      requiredCount: scalar('required'), overflow: scalar('overflow')},
    groups: {triangleOffsets: scalar('triangle-offsets', groupCount),
      triangleCounts: scalar('triangle-counts', groupCount),
      edgeOffsets: scalar('edge-offsets', groupCount), edgeCounts: scalar('edge-counts', groupCount)}
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
