Group convex hull

Finds the convex hull of every labeled group of points, with exact orientation tests.

Reading the result

Best for quick cluster outlines, extents and minimum bounds. It runs Andrew's monotone chain per label after an optional extreme-point prefilter. Noise labels can be skipped.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Input points.
labels*GraphDataView<'uint32'>Group label of every point.
groupCount*numberNumber of groups.
noiseLabelnumberLabel to skip, such as DBSCAN noise.
maximumVerticesPerGroup*numberHull vertex cap per group.
vertexCapacity*numberTotal hull vertex capacity.
prefilterLevelsnumberExtreme-point prefilter depth.
output*GPUGroupConvexHullOutputCaller-owned hull views.

Returns

FieldTypeDescription
vertexIndicesGraphDataView<'uint32'>Hull vertices as source point indices.
vertexPositionsGraphDataView<'float32x2'>Optional hull vertex coordinates.
offsetsGraphDataView<'uint32'>Start of every group hull.
countsGraphDataView<'uint32'>Vertex count per group hull.
status{overflow}Nonzero when the output capacity was too small.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGroupConvexHull} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'convex-hulls'});
// `positions`, `labels` and `output` are graph views imported on `graph`.
graph.add(new GPUGroupConvexHull({
  positions,
  labels,
  groupCount: 12,
  noiseLabel: 0xffffffff,
  maximumVerticesPerGroup: 64,
  vertexCapacity: 12 * 64,
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
