Group geometry

Summarizes each labeled point group: bounds, centers, medoid and standard-distance ellipse.

1.0
4
drawn

Per-group bounds, mean center, medoid and standard distance of labeled points.

Reading the result

Describes clusters: where they are, how big and which way they lean. All requested summaries come from one pass over the label column. Weights give weighted centers.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Input points.
labels*GraphDataView<'uint32'>Group label of every point.
groupCount*numberNumber of groups.
weightsGraphDataView<'float32'>Point weights for weighted centers.
noiseLabelnumberLabel to skip, such as DBSCAN noise.
parameters*GraphDataView<'float32'>Packed per-frame settings.
medoidMaximumGroupSizenumberLargest group for exact medoids.
output*GPUGroupGeometryOutputChoose the summaries to compute.

Returns

FieldTypeDescription
countsGraphDataView<'uint32'>Points per group.
boundsGraphDataView<'float32x4'>Bounding box per group.
meanCentersGraphDataView<'float32x2'>Mean center per group.
medoidIndicesGraphDataView<'uint32'>Point index of each group medoid.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGroupGeometry} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'group-geometry'});
const parameters = new GPUParameterBuffer(device, {id: 'group-parameters', format: 'float32', length: 4});
// `positions`, `labels` and the output views are graph views imported on `graph`.
graph.add(new GPUGroupGeometry({
  positions,
  labels,
  groupCount: 12,
  parameters: parameters.importToGraph(graph),
  output: {counts, bounds, meanCenters, medoidIndices}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
