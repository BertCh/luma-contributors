Reading the result

Answers: is the map of a coefficient signal or noise? Permutes locations and refits, comparing the spread of local estimates with the observed one. Pass the inputs and outputs of the GWR under test.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Positions given to the GWR.
predictors*GraphDataView<'float32'>Predictors given to the GWR.
predictorCount*numberPredictor columns.
response*GraphDataView<'float32'>Response given to the GWR.
bandwidthParameters*GraphDataView<'float32'>Per-frame parameters of the GWR.
selectedBandwidth*GraphDataView<'float32'>The GWR output.selectedBandwidth.
coefficients*GraphDataView<'float32'>The GWR output.coefficients.
maximumPermutations*numberUpper bound of permutations, 1 to 2^20.
and 1 more required: parameters

Returns

FieldTypeDescription
tableGraphDataView<'float32'>Per coefficient: spread, p-value.
summaryGraphDataView<'float32'>Run summary.
standardDeviationsGraphDataView<'float32'> | undefinedSpread per run and coefficient.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUGeographicallyWeightedRegressionNonstationarityTest} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUGeographicallyWeightedRegressionNonstationarityTest({
    positions, predictors, response, predictorCount: 2, // as given to the GWR
    bandwidthParameters: gwrParameters,
    selectedBandwidth: gwrOutput.selectedBandwidth,
    coefficients: gwrOutput.coefficients,
    parameters, // uint32 permutation parameters
    maximumPermutations: 99,
    output // table, summary, standardDeviations
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
