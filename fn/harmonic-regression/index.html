Harmonic regression

Fits trend and harmonics of a chosen period to every pixel series by least squares.

Reading the result

Use it to describe seasonality and trend per pixel, the model inside CCDC and BFAST without the monitoring. Time is centred fractional years on the real dates, so irregular acquisitions need no resampling. Residual rmse shows where the model fits.

Parameters

PropTypeDescription
cellCount*numberNumber of pixels.
sliceCount*numberObservations per pixel.
values*GraphDataView<"float32">Series per pixel, cell-major; non-finite is missing.
parameters*GraphDataView<"float32">Packed period in fractional years.
harmonicCount*numberHarmonics; coefficients are 2 + 2 * count.
dateAxis*GPURasterIrregularDateAxisAcquisition dates as Int64 words with a temporal context.
maskGraphDataView<"uint32">Per-observation QA; zero rejects the sample.

Returns

FieldTypeDescription
coefficientsGraphDataView<"float32">Intercept, slope per year, then cosine and sine pairs.
summaryGraphDataView<"uint32">Per pixel status and valid observation count.
fittedGraphDataView<"float32">Optional fitted curve at every slice.
rmseGraphDataView<"float32">Optional residual standard deviation per pixel.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPURasterHarmonicRegression, getGPURasterHarmonicRegressionParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'uint32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const cellCount = 256 * 256;
const sliceCount = 64;
const dateAxis = {acquisitionTimes: view('dates', 'uint32x2', sliceCount), temporalContext: {unit: 'second', epoch: 0n, encoding: 'int64-words', axis: {kind: 'irregular'}} as const};
const values = getGPURasterHarmonicRegressionParameterValues({period: 1});
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPURasterHarmonicRegression({
  parameters: parameters.importToGraph(graph),
  cellCount,
  sliceCount,
  values: view('series', 'float32', cellCount * sliceCount),
  harmonicCount: 2,
  dateAxis,
  output // coefficients, summary, fitted, rmse
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
