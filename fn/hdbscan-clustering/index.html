HDBSCAN clustering

Finds clusters of varying density without choosing a distance, matching scikit-learn HDBSCAN.

Reading the result

Best when clusters have different densities and one epsilon would fail. It keeps the most stable clusters of a mutual-reachability tree.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar point coordinates, one float32x2 per point.
minimumClusterSize*numberSmallest group that counts as a cluster.
minimumSamplesnumber | undefinedNeighbors for core distance; defaults to minimumClusterSize.
spatialContextGPUSpatialContext | undefinedUnits and frame of the positions.
output*GPUHierarchicalDensityClusteringOutputLabels plus optional core distances.

Returns

FieldTypeDescription
labelsGraphDataView<"uint32">Cluster id per point, or 0xffffffff for noise.
coreDistancesGraphDataView<"float32">Distance to the minimumSamples-th neighbor.
statusPartial<GPUCardinalityPort>Optional; count is the number of selected clusters.

Example

import {GPUHierarchicalDensityClustering} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPUHierarchicalDensityClustering({
  positions,
  minimumClusterSize: 15,
  minimumSamples: 5,
  output: {labels, coreDistances}
}));
