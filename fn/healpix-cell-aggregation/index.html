HEALPix cell aggregation

Groups keyed points into HEALPix cells with row counts, sums, minima and maxima.

Reading the result

The step after GPUHealpixPointToCell. Distinct cells come out in key order, which is also the order along the HEALPix curve. Sums add in row order inside each cell, so results are bitwise reproducible.

Parameters

PropTypeDefaultDescription
order*number-HEALPix order of the keys.
cells*GraphDataView<"uint32x2">-One 64-bit key per row.
valuesGraphDataView<"float32">-Optional values to sum and take extremes of.
maskGraphDataView<"uint32">-Optional per-row selection; nonzero keeps the row.
schemeGPUHealpixIndexScheme'nested'Key scheme, as written by GPUHealpixPointToCell.
cellCapacity*number-Number of distinct cells the outputs can hold.
output*GPUHealpixCellAggregationOutput-Cell table columns and status scalars.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">Distinct cell keys in ascending order.
countsGraphDataView<"uint32">Rows per cell.
sumsGraphDataView<"float32">Optional per-cell sum of values.
statusGPUCardinalityPort & GPUOverflowStatusPortCell count, required count and overflow flag.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUHealpixCellAggregation, GPUHealpixPointToCell} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'healpix-table'});
graph.add(new GPUHealpixPointToCell({order: 3, positions, output: {cells: keys}}));
graph.add(
  new GPUHealpixCellAggregation({
    order: 3,
    cells: keys,
    values, // optional float32 column
    cellCapacity: 768,
    output: {cells, counts, sums, status: {count, requiredCount, overflow}}
  })
);
// cells[0 .. count) are the occupied cells; counts[i] their rows
