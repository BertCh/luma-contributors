HEALPix point to cell

Converts longitude/latitude points to HEALPix nested or UNIQ cell keys, one key per row.

3
1.0
drawn

Natural Earth coastline vertices keyed by HEALPix cell; the pointer is one more point.

Reading the result

HEALPix cells have equal area, which suits global statistics. Keys are uint32x2 words like GPUPointToCell. The projection is spherical and float32, so a point near a cell edge may land in the neighboring cell.

Parameters

PropTypeDefaultDescription
order*number-HEALPix order 0 to 29; 12 * 4^order cells.
schemeGPUHealpixIndexScheme'nested''nested' or 'uniq' keys.
positions*GraphDataView<"float32x2">-Longitude/latitude in degrees.
maskGraphDataView<"uint32">-Per-row mask; zero produces a zero key.
output*GPUHealpixPointToCellOutput-Destination views for cells and optional validity.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">One 64-bit key per row; zero when masked (a real cell in nested).
validityGraphDataView<"uint32">Optional 1 for rows that received a key.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUHealpixPointToCell} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'healpix-keys'});
const positions = graph.importGPUData('positions', lonLatData); // GPUData<'float32x2'>
const cells = graph.importGPUData('cells', cellData); // GPUData<'uint32x2'>, caller-owned

graph.add(new GPUHealpixPointToCell({order: 3, positions, output: {cells}}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
