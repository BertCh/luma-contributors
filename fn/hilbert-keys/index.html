Hilbert keys

Computes 2D Hilbert curve indices for points or box centers, optionally sorting rows along the curve.

Reading the result

Orders data so neighbors in space are neighbors in memory, which speeds up joins, indexes and tile building. Hilbert order clusters better than Morton. Orders 1 to 16; invalid rows get a sentinel key and sort last.

Parameters

PropTypeDefaultDescription
positionsGraphDataView<"float32x2">-Points to key.
minimaGraphDataView<"float32x2">-Box minima, with maxima, to key box centers.
maximaGraphDataView<"float32x2">-Box maxima.
boundsGraphDataView<"float32">-Per-frame [minX, minY, maxX, maxY]; reduced from data if omitted.
ordernumberGPU_HILBERT_DEFAULT_ORDERCurve order, 1 to 16 (default 15).
output*GPUHilbertKeysOutput-keys, plus optional sortedRows and sortedKeys.

Returns

FieldTypeDescription
keysGraphDataView<"uint32">Hilbert index per item.
sortedRowsGraphDataView<"uint32">Stable curve-order permutation of rows.
sortedKeysGraphDataView<"uint32">Keys in curve order.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUHilbertKeys} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'hilbert'});
const positions = graph.importGPUData('positions', pointData); // GPUData<'float32x2'>
const keys = graph.importGPUData('keys', keyData); // GPUData<'uint32'>
const sortedRows = graph.importGPUData('sorted-rows', rowData); // GPUData<'uint32'>

graph.add(new GPUHilbertKeys({positions, order: 10, output: {keys, sortedRows}}));
const compiled = await graph.compileAsync();
