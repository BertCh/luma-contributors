Hot spots (Getis-Ord Gi*)

Marks statistically significant hot and cold spots with z-scores and 90, 95 and 99% confidence bins.

Reading the result

Shows where high or low values cluster, as in the ArcGIS Hot Spot Analysis tool. Gi* compares the sum of values in each neighborhood (including the row itself) with what chance would give.

  • Read the neighbourhood and minimum-neighbour settings before comparing scores; apply a multiple-testing correction when testing many locations.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GPUFloat32OrUint32Values-One value per row; non-finite rows are excluded.
parameters*GraphDataView<"float32">-Per-frame settings from getGPUSpatialAutocorrelationParameterValues.
selfWeightnumber | undefined-Weight of the focal row itself; 1 gives Gi*, 0 gives Gi.
minimumNeighborsnumber | undefined1Esri recommends 8 for Gi*.
multipleTestingGPUMultipleTestingMethod | undefined'none'Bonferroni, Holm, Benjamini-Hochberg or Benjamini-Yekutieli.
islandsGPUIslandPolicy | undefined'exclude'Rows without neighbors: 'exclude' them or 'keep' (esda convention).
output*GPUHotSpotAnalysisOutput-Caller-owned result views.

Returns

FieldTypeDescription
zScoresGraphDataView<"float32">Analytic z-score per row; NaN where undefined.
binsGraphDataView<"sint32">+/-3, 2, 1 for 99, 95, 90% hot or cold; 0 otherwise.
adjustedPValuesGraphDataView<"float32">p-values after multiple-testing correction.

Example

import {GPUHotSpotAnalysis} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPUHotSpotAnalysis({
  weights, values,
  parameters: parameters.importToGraph(graph),
  selfWeight: 1,
  minimumNeighbors: 8,
  multipleTesting: 'benjamini-hochberg',
  output: {zScores, bins}
}));
