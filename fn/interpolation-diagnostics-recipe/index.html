Reading the result

Shows not just a kriged surface but how far to trust it. Each sample is predicted from the others, residuals are summarized, and masked samples are excluded. You supply the variogram; nothing is fitted behind your back.

Parameters

PropTypeDescription
kriging*Omit<GPUKrigingProps, "id" | "output">Samples, values, variogram, neighborhood and target grid.
idstring | undefinedPrefix for every node and transient ID; set it when composing recipes.
outputsPartial<Output> | undefinedCaller-owned views to keep; every other result is a graph transient.

Returns

FieldTypeDescription
outputs.valuesGraphDataView<"float32">Predicted surface.
outputs.varianceGraphDataView<"float32">Kriging variance of the surface.
outputs.residualsGraphDataView<"float32">Leave-one-out residual per sample.
outputs.standardizedResidualsGraphDataView<"float32">Residual over kriging deviation.
outputs.rootMeanSquaredErrorGraphDataView<"float32">RMSE of the held-out predictions.
contributorsreadonly GPUCommandNodeProducer<never>[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, unknown>Named stage ports; graph-owned, not for readback.
statusGPURecipeStatusPortGPU status words; zero means complete.

Example

import {addInterpolationDiagnosticsRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; kriging takes the same inputs as GPUKriging; the variogram is packed in parameters
const interpolation = addInterpolationDiagnosticsRecipe(graph, {
  kriging: {positions: samplePositions, values: sampleValues, parameters: variogramParameters, grid, indexGridSize, indexBounds}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// interpolation.outputs.values (surface), .bias and .rootMeanSquaredError (trust)
