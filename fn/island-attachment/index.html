Reading the result

Contiguity leaves islands without neighbors, which many models cannot use. Each empty row links to the nearest finite point representative, ties to the lowest id. Original rows keep their weights.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights-Weights with empty rows.
positions*GraphDataView<'float32x2'>-Planar point representative per row.
reciprocalboolean | undefinedtrueAlso add the reverse edge.
output*GPUSpatialWeightsPort & {spatialContext?: GPUSpatialContext}-Caller-owned CSR weights.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>CSR row offsets.
neighborsGraphDataView<'uint32'>Neighbor ids including attachments.
weightsGraphDataView<'float32'>Original weights plus binary attachments.
statusGPUBoundedResultStatusPortGPU status words; zero means complete.
attachmentGraphDataView<"uint32">Selected nearest row, or 0xffffffff when none.
addedGraphDataView<"uint32">1 for edges added by this operation, 0 for copied.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUIslandAttachment} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUIslandAttachment({
    weights, // contiguity weights with islands
    positions: graph.importGPUData('centroids', centroidData),
    output: csr(featureCount, 10 * featureCount)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
