Reading the result

Carves points into k service areas or zones when you know k. Seeded k-means++ with several restarts; the best run is kept.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Planar point coordinates, one float32x2 per point.
k*number-Number of clusters.
maximumIterations*number-Compile-time cap on Lloyd iterations.
parameters*GraphDataView<"uint32">-Seed and tolerance from getGPUSpatialKMeansParameterValues.
initializationGPUSpatialKMeansInitialization | undefined'kmeans++''kmeans++' or 'first-valid'.
restartCountnumber | undefined1Restarts; the lowest inertia wins.
centerCoordinatesboolean | undefinedfalseCenter coordinates first for precision.
output*GPUSpatialKMeansOutput-Labels, centers and optional diagnostics.

Returns

FieldTypeDescription
labelsGraphDataView<"uint32">Cluster id per point, or 0xffffffff for noise.
centersGraphDataView<"float32x2">Cluster centers, k rows.
inertiaGraphDataView<"float32">Total within-cluster squared distance.

Example

import {GPUSpatialKMeans, GPU_SPATIAL_KMEANS_PARAMETER_LENGTH, getGPUSpatialKMeansParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const parameters = new GPUParameterBuffer(device, {
  id: 'kmeans', format: 'uint32', length: GPU_SPATIAL_KMEANS_PARAMETER_LENGTH,
  values: getGPUSpatialKMeansParameterValues({seed: 5})
});
graph.add(new GPUSpatialKMeans({
  positions, k: 8, maximumIterations: 50, restartCount: 4,
  parameters: parameters.importToGraph(graph),
  output: {labels, centers, inertia}
}));
