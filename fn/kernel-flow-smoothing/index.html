Kernel flow smoothing

Smooths origin-destination flows by borrowing from neighboring origins and destinations.

12
0.50
drawn

Flows out of one Chicago tract after kernel smoothing of the 1,200 largest tract-to-tract flows (LODES, 2021): each is re-estimated from neighboring origins and destinations, and pairs not listed count as zero.

Reading the result

Use it to see the regional pattern under noisy zone-to-zone flows. Each flow is re-estimated as a Gaussian-weighted mean of flows between nearby origins and nearby destinations. Reads the pairs that GPUFlowAggregation writes.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Zone centroids, one row per zone.
locationWeights*GraphDataView<'float32'>Weight of each zone in the neighborhood size.
flows*GPUKernelFlowSmoothingFlowsA zone matrix, or the OD pairs of GPUFlowAggregation.
parameters*GraphDataView<'float32'>Per frame: neighborhoodSize and bandwidthRatio.
spatialContextGPUSpatialContextPlanar, or longitude and latitude great-circle.

Returns

FieldTypeDescription
smoothedGraphDataView<'float32'>Smoothed flows, zoneCount * zoneCount rows.
radiiGraphDataView<'float32'> | undefinedNeighborhood radius of each zone.

Example

import {
  GPUKernelFlowSmoothing,
  getGPUKernelFlowSmoothingParameterValues
} from '@luma-contributors/analysis/gpu-network';

// zoneCenters, ones, parametersView, aggregation outputs, smoothed: views on graph
parametersView.write(getGPUKernelFlowSmoothingParameterValues({neighborhoodSize: 5}));
graph.add(new GPUKernelFlowSmoothing({
  positions: zoneCenters,
  locationWeights: ones,
  flows: {kind: 'pairs', originZoneIds, destinationZoneIds, weights, validPairCount},
  parameters: parametersView,
  output: {smoothed}
}));
