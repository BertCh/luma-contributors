Finite-time Lyapunov exponent

FTLE of a flow map on a seed grid: how fast neighbouring particles separate over time T.

1.20
drawn

FTLE of the Helene wind: left of centre integrates backward (attracting ridges), right forward (repelling). Steady wind; time units are uncalibrated (1 m/s = 0.01 field heights per unit).

Reading the result

Ridges of the forward FTLE are repelling Lagrangian coherent structures; a backward flow map gives attracting ones. Feed it the final positions of a regular seed grid from GPULagrangianFlowMap.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Final positions of a row-major seed grid.
seedWidth*numberSeed grid width, 2 to 65535.
seedHeight*numberSeed grid height, 2 to 65535.
parameters*GraphDataView<"float32">Packed seed spacing and `integrationTime`.

Returns

FieldTypeDescription
ftleGraphDataView<"float32">FTLE per seed; NaN where a neighbour was lost.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUFiniteTimeLyapunovExponent, getGPUFiniteTimeLyapunovExponentParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const seedWidth = 256; const seedHeight = 256; const seedCount = seedWidth * seedHeight;
const values = getGPUFiniteTimeLyapunovExponentParameterValues({seedSpacingX: 0.25, seedSpacingY: 0.25, integrationTime: -6});
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPUFiniteTimeLyapunovExponent({
  parameters: parameters.importToGraph(graph),
  seedWidth, seedHeight,
  positions: view('flow-map', 'float32x2', seedCount),
  output: {ftle: view('ftle', 'float32', seedCount)}
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
