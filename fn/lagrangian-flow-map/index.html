Lagrangian flow map

Carries every seed through a time-varying vector field and writes where it ends up.

0.0150
stepCount
drawn

Seeds carried through the Helene wind (steady: one snapshot); lines join start to end. Place a ring of seeds and see the patch it becomes. Time units are uncalibrated (1 m/s = 0.01 field heights per unit).

Reading the result

The input of FTLE, connectivity matrices and residence times. RK2 steps with bilinear sampling and linear time interpolation between two slices; a negative timeStep integrates backward.

Parameters

PropTypeDescription
seeds*GraphDataView<"float32x2">Seed positions in the field frame.
velocitiesStart*GraphDataView<"float32x2">Field at `sliceStartTime`, row-major.
velocitiesEnd*GraphDataView<"float32x2">Field at `sliceEndTime`, same layout.
fieldWidth*numberField width in cells.
fieldHeight*numberField height in cells.
stepCount*numberRK2 steps per particle, 1 to 8192.
parameters*GraphDataView<"float32">Packed extent, start time, `timeStep`, slice times.
regionsGraphDataView<"uint32">Region per field cell, for region classes and residence.

Returns

FieldTypeDescription
positionsGraphDataView<"float32x2">Final position per seed; NaN once a particle is lost.
regionClassesGraphDataView<"uint32">Start then end region per seed (needs `regions`).
residenceTimesGraphDataView<"float32">Time in the start region before the first exit.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPULagrangianFlowMap, getGPULagrangianFlowMapParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const seedCount = 256 * 256; const cellCount = 360 * 180;
const values = getGPULagrangianFlowMapParameterValues({fieldExtent: [0, 0, 1, 1], startTime: 0, timeStep: -0.1, sliceStartTime: 0, sliceEndTime: 6});
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPULagrangianFlowMap({
  parameters: parameters.importToGraph(graph),
  fieldWidth: 360, fieldHeight: 180, stepCount: 60,
  seeds: view('seeds', 'float32x2', seedCount),
  velocitiesStart: view('field-0', 'float32x2', cellCount),
  velocitiesEnd: view('field-6', 'float32x2', cellCount),
  output: {positions: view('ends', 'float32x2', seedCount)}
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
