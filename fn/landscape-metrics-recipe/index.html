Reading the result

Quantifies habitat fragmentation as landscapemetrics does. Give it patch IDs and a class per patch; it returns area, perimeter, effective mesh size, cohesion, aggregation and contagion. Perimeter and background rules are explicit options.

Parameters

PropTypeDefaultDescription
patches*GraphDataView<"uint32">-Connected-patch ID per cell over the complete raster.
patchClasses*GraphDataView<"uint32">-Class ID per patch.
width*number-Raster width in cells.
height*number-Raster height in cells.
classCount*number-Number of land-cover classes.
cellSize*readonly [number, number]-Positive planar cell width and height.
connectivity*4 | 8-Connectivity used to label patches; kept as provenance.
contagionWeighting"area" | "adjacency" | undefined'area'Area-weighted, or landscapemetrics 2.2.1 joint adjacency.

Returns

FieldTypeDescription
outputs.patchMetricsGraphDataView<"float32">[area, perimeter, cellCount, sameClassSides] per patch.
outputs.classMetricsGraphDataView<"float32">[area, perimeter sum, mesh size, cohesion] per class.
outputs.classAdjacencyGraphDataView<"uint32">Class by class side counts.
outputs.landscapeGraphDataView<"float32">[contagion %, mesh size, valid area, class count].
provenanceRecord<string, GraphDataView>Stage ports that show how the result was built.

Example

import {addLandscapeMetricsRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; patches are connected-component labels over the whole raster
const metrics = addLandscapeMetricsRecipe(graph, {
  patches, patchClasses,
  width: 512, height: 512,
  classCount: 6,
  cellSize: [30, 30],
  connectivity: 8,
  countBoundary: false
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// metrics.outputs.landscape: contagion, mesh size, valid area, class count
