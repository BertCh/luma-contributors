Reading the result

The cheap way to get weights for rasters and grid cells; the PySAL lat2W equivalent. rook is Manhattan distance, queen is Chebyshev distance, up to radius cells. A mask removes cells.

Parameters

PropTypeDefaultDescription
width*number-Lattice columns.
height*number-Lattice rows.
criterion*GPULatticeCriterion-'rook' or 'queen' neighborhood.
radiusnumber | undefined1Neighborhood radius in cells, 1 to 32.
maskGraphDataView<'uint32'> | undefined-Per-cell selection; zero removes the cell.
cellSizereadonly [number, number] | undefined-Cell size; also writes distances.
output*GPUSpatialWeightsOutput-Caller-owned CSR, width * height + 1 offsets.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>CSR row offsets.
neighborsGraphDataView<'uint32'>Neighbor cell ids, y * width + x.
weightsGraphDataView<'float32'>Binary weights.
statusGPUBoundedResultStatusPortGPU status words; zero means complete.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULatticeWeights} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPULatticeWeights({
    width: 32,
    height: 32,
    criterion: 'queen',
    output: csr(32 * 32, 8 * 32 * 32)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
