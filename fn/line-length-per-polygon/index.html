Sums the length of lines that fall inside each polygon, optionally weighted.

Reading the result

Best for road length per tract or river length per watershed. Each line is split at polygon edges and measured exactly. Weights give length-weighted attributes such as lanes.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Packed line vertices.
lineOffsets*GraphDataView<'uint32'>Vertex offsets per line.
polygons*GPUPackedGeometryPort<GPUPolygonGeometryPort>Packed polygon geometry.
lineWeightsGraphDataView<'float32'>Per-line weight for weightedLengths.
pairCapacitynumberUpper bound on line-polygon candidate pairs.
maximumCrossingCountnumberUpper bound on edge crossings per segment.
spatialContextGPUSpatialContextFrame of the lines.

Returns

FieldTypeDescription
lengthsGraphDataView<'float32'>Line length per polygon.
weightedLengthsGraphDataView<'float32'>Optional weight-multiplied length.
segmentCountsGraphDataView<'uint32'>Optional segments counted per polygon.
statusGPUOverflowStatusPortOverflow flag; lengths can be low when 1.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULineLengthPerPolygon} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'road-length'});
// roads: positions + lineOffsets; tracts: packed polygon geometry (graph views)
graph.add(
  new GPULineLengthPerPolygon({
    positions: roadPositions,
    lineOffsets: roadOffsets,
    polygons: {kind: 'polygons', positions: tractPositions,
      featureOffsets, polygonOffsets, ringOffsets},
    output: {lengths, status: {overflow}}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
