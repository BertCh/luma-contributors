Line simplification

Simplifies many polylines or tracks with Douglas-Peucker, TD-TR or Visvalingam.

Reading the result

Thins tracks and boundaries for drawing or storage. It scores every vertex by importance once, then keeps the vertices above the tolerance, so changing the tolerance is cheap. With timestamps and the time-ratio metric it becomes TD-TR for trajectories.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Packed vertices, sorted by line.
lineOffsets*GraphDataView<'uint32'>-Start row of every line plus a terminal row.
importance*GraphDataView<'float32'>-Per-vertex importance, filled by the operator.
methodGPULineSimplificationMethod'douglas-peucker''douglas-peucker' or 'visvalingam'.
metricGPULineSimplificationMetric'segment''segment' or 'time-ratio' (TD-TR).
timestampsGraphDataView<'float32'>-Vertex times, for the time-ratio metric.
parametersGraphDataView<'float32'>-Packed tolerance, rewritten per frame.
outputGPULineSimplificationOutput-Kept vertex ids, mask and per-line counts.

Returns

FieldTypeDescription
idsGraphDataView<'uint32'>Kept vertex rows in line order.
outputMaskGraphDataView<'uint32'>Optional 1/0 kept flag per vertex.
lineCountsGraphDataView<'uint32'>Optional kept vertices per line.
statusGPULineSimplificationStatus & GPUCardinalityPort & GPUOverflowStatusPortKept-row count, overflow and convergence diagnostics.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULineSimplification, getGPULineSimplificationParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'simplify'});
const parameters = new GPUParameterBuffer(device, {id: 'tolerance', format: 'float32', length: 4});
// `positions`, `lineOffsets`, `importance` and `output` are graph views on `graph`.
graph.add(new GPULineSimplification({
  positions, lineOffsets, importance,
  parameters: parameters.importToGraph(graph),
  output
}));
const compiled = await graph.compileAsync();
parameters.write(getGPULineSimplificationParameterValues({tolerance: 15}));
compiled.encode(device.commandEncoder, {parameters: undefined});
