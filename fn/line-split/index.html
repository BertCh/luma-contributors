Line split

Splits lines at every crossing, touch or overlap with each other or themselves.

0.30
0.40
drawn

Lines cut at every crossing; each piece gets its own color.

River reaches are resampled and rotated into local comparison panels.

Reading the result

Nodes a street layer so each piece runs between intersections (turf lineSplit, PostGIS ST_Node). It is the first step of building a routable network from raw centerlines. Capacity must cover the intersection count.

Parameters

PropTypeDescription
lines*GPULineGeometryPortPacked positions, line offsets and ids.
intersectionCapacity*numberUpper bound on found intersections.
spatialSortbooleanSort segments spatially; speeds large inputs.
leafCapacitynumberSegments per BVH leaf.
spatialContextGPUSpatialContextPlanar by default.
output*GPULineSplitOutputCaller-owned piece views and status.

Returns

FieldTypeDescription
piecesGPULineSplitPiecesSplit lines with source ids and bounded-result status.
statusGPUBoundedResultStatusPortOptional counts, overflow and uncertain pairs.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULineSplit} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'split'});
// `streets` (a packed line port) and `output` are graph views imported on `graph`.
graph.add(new GPULineSplit({
  lines: streets,
  intersectionCapacity: 50000,
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// `output.pieces.geometry` holds the noded lines, `pieces.sourceIds` the origin line
