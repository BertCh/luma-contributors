Reading the result

Local models fail quietly where predictors move together. Computes weighted, centered VIF per row and predictor, plus condition numbers. Use the same weights as the local fit.

Parameters

PropTypeDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeightsLocal estimation weights, self included.
predictors*GraphDataView<'float32'>Row-major predictors.
predictorCount*numberPredictor columns.
maskGraphDataView<'uint32'> | undefinedZero excludes the row.
output*{varianceInflationFactors}Caller-owned results.

Returns

FieldTypeDescription
varianceInflationFactorsGraphDataView<'float32'>Local VIF per row and predictor.
conditionNumbersGraphDataView<'float32'>Local condition number per row.
statusGraphDataView<'uint32'>Per-row fit status.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULocalCollinearity} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPULocalCollinearity({
    weights, // kernel weights with self slots
    predictors: graph.importGPUData('x', predictorData),
    predictorCount: 3,
    output // varianceInflationFactors and the remaining views
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
