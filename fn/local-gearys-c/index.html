Reading the result

Finds places that resemble their surroundings (low c) or contrast with them (high c). It sums squared differences to neighbors, standardized by the population variance.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GPUFloat32OrUint32Values-One value per row; non-finite rows are excluded.
parameters*GraphDataView<"float32">-Per-frame settings from getGPUSpatialAutocorrelationParameterValues.
maskGraphDataView<"uint32"> | undefined-Nonzero rows take part in the analysis.
islandsGPUIslandPolicy | undefined'exclude'Rows without neighbors: 'exclude' them or 'keep' (esda convention).
output*GPULocalGearyOutput-Caller-owned result views.

Returns

FieldTypeDescription
statisticGraphDataView<"float32">Local Geary value per row.
globalStatisticsGraphDataView<"float32">[n, mean, variance, sd, islandCount] used.

Example

import {GPULocalGeary} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPULocalGeary({
  weights, values,
  parameters: parameters.importToGraph(graph),
  islands: 'keep',
  output: {statistic}
}));
