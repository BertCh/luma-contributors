Local outlier factor

Scores how much sparser each point is than its neighbors, to flag local outliers.

Reading the result

Finds anomalies relative to their local density, such as a lone sensor in a dense area. A score near 1 is as dense as the neighbors and well above 1 is an outlier.

Parameters

PropTypeDescription
neighbors*GPUSpatialWeightsk nearest neighbors with distances.
parameters*GraphDataView<"float32">Threshold and densityFloor from the packer.
spatialContextGPUSpatialContext | undefinedUnits of densityFloor.
output*GPULocalOutlierFactorOutputLOF scores plus optional outlier mask.

Returns

FieldTypeDescription
kDistanceGraphDataView<"float32">k-distance per row.
localReachabilityDensityGraphDataView<"float32">Local reachability density per row.
lofGraphDataView<"float32">Local outlier factor per row.
outlierGraphDataView<"uint32">1 where lof exceeds the threshold.
outlierCountGraphDataView<"uint32">Number of flagged rows.

Example

import {GPULocalOutlierFactor, getGPULocalOutlierFactorParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const values = getGPULocalOutlierFactorParameterValues({threshold: 1.5});
const parameters = new GPUParameterBuffer(device, {
  id: 'lof', format: 'float32', length: values.length, values
});
// neighbors: 20-nearest-neighbor search with distances
graph.add(new GPULocalOutlierFactor({
  neighbors, parameters: parameters.importToGraph(graph),
  output: {kDistance, localReachabilityDensity, lof, outlier, outlierCount}
}));
