Local permutation test

Gives each row a conditional-permutation pseudo p-value for local Moran, Geary, G and join counts.

Reading the result

Best for esda-style significance of LISA clusters without normality assumptions. For each row it holds the value fixed and resamples its neighbors' values.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GPUFloat32OrUint32Values-One value per row; non-finite rows are excluded.
statistic*GPULocalPermutationStatistic-For example 'localMoran', 'localGeary', 'localG', 'localGStar'.
parameters*GraphDataView<"uint32">-Per-frame seed and permutation count from getGPUPermutationParameterValues.
maximumPermutations*number-Compile-time cap on permutations; the per-frame count may not exceed it.
alternativeGPUInferenceAlternative | undefined'two-sided'Tail of the test: 'two-sided', 'greater' or 'lesser'.
multipleTestingGPUMultipleTestingMethod | undefined'none'Bonferroni, Holm, Benjamini-Hochberg or Benjamini-Yekutieli.
output*GPULocalPermutationTestOutput-Exceedances and pseudo p-values, plus optional extras.

Returns

FieldTypeDescription
pseudoPValuesGraphDataView<"float32">Pseudo p-value per row; NaN if not tested.
exceedancesGraphDataView<"uint32">Permutations at least as extreme as observed.
significantGraphDataView<"uint32">1 where the pseudo p-value is significant.
status{overflow: GraphDataView<"uint32">}Completeness status; overflow is nonzero on truncation.

Example

import {GPULocalPermutationTest} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
// permutation: GPUParameterBuffer as in the global permutation test
graph.add(new GPULocalPermutationTest({
  weights, values, statistic: 'localMoran',
  parameters: permutation.importToGraph(graph),
  maximumPermutations: 999,
  multipleTesting: 'benjamini-hochberg',
  output: {exceedances, pseudoPValues, significant, status: {overflow}}
}));
