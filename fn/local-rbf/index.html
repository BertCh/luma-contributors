Reading the result

Best for smooth surfaces through exact or lightly smoothed samples when no variogram is available. Each query fits a small RBF system with a gaussian, thin-plate or polynomial kernel. Smoothing relaxes the exact fit.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Sample locations.
values*GraphDataView<'float32'>Sample values.
queries*GraphDataView<'float32x2'>Prediction locations.
kernel'gaussian' | 'thin-plate-spline' | 'cubic' | 'linear' | 'quintic'Basis function.
degree-1 | 0 | 1 | 2Polynomial trend degree.
epsilonnumberKernel shape parameter.
smoothingnumberRegularization; 0 interpolates exactly.
neighborCountnumberNearest samples per query.

Returns

FieldTypeDescription
valuesGraphDataView<'float32x4'>Prediction and related terms per query.
statusGraphDataView<'uint32'>Per-query solve status.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPULocalRBF} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'rbf'});
// positions, values, queries, outputs: graph views
graph.add(
  new GPULocalRBF({
    positions,
    values,
    queries,
    kernel: 'thin-plate-spline',
    degree: 1,
    smoothing: 0.01,
    neighborCount: 24,
    output: {values: predictions, status}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
