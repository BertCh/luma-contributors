LOSH (local variability)

Measures how variable values are within each neighborhood, to find unstable or heterogeneous areas.

Reading the result

Complements local Moran: LOSH says where the spread of neighbors is unusually high or low, not where values are high. It is the neighbor-weighted mean of absolute deviations over the global mean residual.

Parameters

PropTypeDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeightsNeighbor structure (CSR) from queen, KNN or distance weights.
values*GraphDataView<"float32">One float32 value per row.
residualPower2 | 1 | undefinedExponent a of the absolute deviations: 2 (variance-like) or 1.
maskGraphDataView<"uint32"> | undefinedNonzero rows take part in the analysis.
output*{ statistic: GraphDataView<"float32">; status: GraphDataView<"uint32"> }Result views.

Returns

FieldTypeDescription
statisticGraphDataView<"float32">LOSH H_i per row.
statusGraphDataView<"uint32">Status code word.
normalizedResidualsGraphDataView<"float32">Optional normalized residual powers for permutation.

Example

import {GPULocalSpatialHeteroscedasticity} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPULocalSpatialHeteroscedasticity({
  weights, values,
  residualPower: 2,
  output: {statistic, status}
}));
