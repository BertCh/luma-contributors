Reading the result

Separates places whose neighbors agree on average from places whose neighbors are erratic. Both statistics share one weights graph, values and mask. Corrections apply to the Moran family only; LOSH stays descriptive.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsSquare CSR neighbor structure.
values*GraphDataView<"float32">One value per row.
parameters*GraphDataView<"float32">Spatial-autocorrelation parameter view.
maskGraphDataView<"uint32"> | undefinedNonzero rows take part.
residualPower2 | 1 | undefinedPower of the LOSH residuals.
minimumNeighborsnumber | undefinedRows with fewer neighbors are not scored.
multipleTestingGPUMultipleTestingMethod | undefinedCorrection for the Moran p-values only.
outputsPartial<Output> | undefinedCaller-owned views to keep; every other result is a graph transient.

Returns

FieldTypeDescription

outputs.localIGraphDataView<"float32">Local Moran's I.
outputs.zScoresGraphDataView<"float32">Analytic Moran z-score.
outputs.quadrantsGraphDataView<"uint32">Moran quadrant, 0 if not significant.
contributorsreadonly GPUCommandNodeProducer<never>[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, GraphDataView>Named stage ports; graph-owned, not for readback.
statusGPURecipeStatusPortGPU status words; zero means complete.
inferenceGPUInferenceMetadataHow p-values and bins were produced, for legends.

Example

import {addLocalVariabilityRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; weights, values, mask and parameters are graph views
const variability = addLocalVariabilityRecipe(graph, {
  weights, values, mask,
  parameters: autocorrelationParameters.importToGraph(graph),
  multipleTesting: 'benjamini-hochberg'
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// variability.outputs.losh next to variability.outputs.quadrants
