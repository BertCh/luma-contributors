Reading the result

Finds which high-LOSH areas are more variable than chance. It computes LOSH and resamples the fixed residual field without replacement.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Neighbor structure (CSR) from queen, KNN or distance weights.
values*GraphDataView<"float32">-One float32 value per row.
alternative*"two-sided" | "greater" | "lesser"-Tail of the test.
parameters*GraphDataView<"uint32">-Seed and permutation count.
maximumPermutations*number-Compile-time cap on permutations; the per-frame count may not exceed it.
residualPower2 | 1 | undefined-Exponent of the absolute residuals.
multipleTestingGPUMultipleTestingMethod | undefined'none'Bonferroni, Holm, Benjamini-Hochberg or Benjamini-Yekutieli.
output*{statistic, status, inference}-Result views plus the inference views that hold the p-values.

Returns

FieldTypeDescription
statisticGraphDataView<"float32">LOSH per row.
statusGraphDataView<"uint32">Per-row completion evidence bitmask.
inferenceGPULocalPermutationTestOutputRequired: exceedances, pseudoPValues, adjustedPValues, significant, status.

Example

import {GPULOSHResidualPermutationTest} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPULOSHResidualPermutationTest({
  weights, values,
  alternative: 'greater',
  parameters: permutation.importToGraph(graph),
  maximumPermutations: 499,
  output: {
    statistic, status,
    inference: {exceedances, pseudoPValues, adjustedPValues, significant, status: inferenceStatus}
  }
}));
