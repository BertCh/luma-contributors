Make raster band

Wraps one value per pixel as a band, with optional validity, nodata and calibration.

Reading the result

Feeds the output of one operation into the next without a hand-written band literal. Calibration (scale, offset) and raw noDataValue travel with the band, so downstream operations read reflectance, not digital numbers.

Parameters

PropTypeDefaultDescription
values*GraphDataView<Format>-One value per grid pixel.
grid*GPURasterMetadata-The grid the band lives on.
options.validityGraphDataView<"uint32">-Per-pixel flags; zero rejects a sample.
options.noDataValuenumber-Raw nodata value, compared before calibration.
options.scalenumber1Calibration multiplier.
options.offsetnumber0Calibration offset.

Returns

FieldTypeDescription
bandGPURasterBufferBand<Format>Buffer-backed band ready for any raster operation.

Example

import {makeGPURasterBand, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `reflectance` and `validity` are graph views with one row per pixel.
const nearInfrared = makeGPURasterBand(reflectance, grid, {
  id: 'nir',
  validity,
  noDataValue: 0,
  scale: 0.0000275, // Landsat Collection 2 surface reflectance
  offset: -0.2
});
