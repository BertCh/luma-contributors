Make raster grid

Describes an axis-aligned raster grid: size, cell size, origin and row direction.

Reading the result

Every raster operation takes its shape from this one grid object, so cell size and extent are never typed twice. Use cellSize in meters, EPSG:3857 meters or degrees to match your cellSizeMode.

Parameters

PropTypeDefaultDescription
width*number-Grid width in pixels.
height*number-Grid height in pixels.
cellSizenumber | readonly [number, number]1Cell size in world units.
originreadonly [number, number][0, 0]World [x, y] of the top-left pixel corner.
rowDirection"south" | "north""south"Direction rows advance in world y.

Returns

FieldTypeDescription
affine[number, number, number, number, number, number]Pixel-to-world transform.
GPURasterMetadataGPURasterMetadataWidth, height, affine and pixel interpretation.

Example

import {makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const grid = makeGPURasterMetadata({
  width: 1024,
  height: 1024,
  cellSize: 30,
  origin: [500000, 4650000]
});
// grid.affine === [30, 0, 500000, 0, -30, 4650000]
// Pass `grid` to any raster operation.
