Reading the result

Best for space-time clustering when you do not want to pick close-in-space and close-in-time cutoffs. It is the Pearson r between d_ij and |t_i - t_j|, with a permutation p-value.

Parameters

PropTypeDescription
pairs*GPUSpatialWeightsEvent pairs with their distances.
times*GraphDataView<"float32">Relative event times.
parameters*GraphDataView<"uint32">Seed and permutation count.
maximumPermutations*numberCompile-time cap on permutations; the per-frame count may not exceed it.
stopAfterExceedancesnumber | undefinedStop early after this many exceedances.
output*GPUMantelTestOutputStatistics and summary views.

Returns

FieldTypeDescription
statisticsGraphDataView<"float32">Observed r, then one per permutation.
summaryGraphDataView<"float32">r and p-values (GPU_SPACE_TIME_SUMMARY).
permutationCountGraphDataView<"uint32">Optional permutations actually used.

Example

import {GPUMantelTest} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
// parameters: GPUParameterBuffer as in the Knox example
graph.add(new GPUMantelTest({
  pairs, times,
  parameters: parameters.importToGraph(graph),
  maximumPermutations: 999,
  output: {statistics, summary}
}));
