Map-matched edge volumes

Counts how many matched tracks traversed each network edge, and the busiest turns.

Traversals per street direction from GPS tracks matched to the network. Tracks are simulated trips toward three hubs, with added GPS noise, on a San Francisco TIGER/Line extract of about 350 intersections.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Use it after GPUMapMatching to turn vehicle tracks into traffic volumes. Every edge in a track route counts once, including edges between fixes, with integer atomics. Optional turning movements come from edge-to-edge pairs.

Parameters

Example

import {GPUMapMatching, GPUMapMatchedEdgeVolumes} from '@luma-contributors/analysis/gpu-network';

// Forward the matching traversal output, including its two status words.
graph.add(new GPUMapMatchedEdgeVolumes({
  traversedEdges: {edges: routeEdges, counts: routeCounts, status: {overflow: routeOverflow, candidateOverflow: routeCandidateOverflow}},
  trackCount: 200,
  traversedEdgeCapacity: 64,
  edgeCount: network.slotCount, // directed CSR rows, not undirected roads
  output: {edgeVolumes, status: {candidateOverflow}} // one row per directed edge
}));
