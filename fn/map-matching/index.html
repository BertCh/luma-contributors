Map matching

Matches noisy GPS tracks to the road network with a hidden Markov model (Newson and Krumm).

Reading the result

Turns raw GPS traces into the roads that were driven. Each fix keeps candidate edges; the HMM balances GPS distance against route plausibility. Optional route tables speed up the transition step.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-GPS fixes, concatenated across tracks.
trackOffsets*GraphDataView<"uint32">-Row offsets of each track in positions.
topology*GPUNetworkTopology & {weights?}-CSR network with node positions.
parameters*GraphDataView<"float32">-Per-frame noise and route-slack settings.
candidateCountnumber | undefined8Candidate edges kept per fix.
cellSize*number-Spatial grid cell size for candidate search.
bounds*{minimum, maximum}-Extent of the network.
output*GPUMapMatchingOutput-matchedEdges plus fractions, snapped positions and breaks.

Returns

FieldTypeDescription
matchedEdgesGraphDataView<'uint32'>Matched edge per fix.
matchedFractionsGraphDataView<'float32'>Position along the matched edge (optional).
snappedPositionsGraphDataView<'float32x2'>Matched coordinates (optional).
trackLogLikelihoodsGraphDataView<'float32'>Log-likelihood per track (optional).
breaksGraphDataView<'uint32'>Fixes where the match broke (optional).

Example

import {GPUMapMatching} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUMapMatching({
  positions: fixes.importToGraph(graph),
  trackOffsets: trackOffsets.importToGraph(graph),
  topology,
  parameters: parameters.importToGraph(graph),
  cellSize: 100,
  bounds: {minimum: [0, 0], maximum: [10000, 10000]},
  output: {matchedEdges, matchedFractions, snappedPositions}
}));
