Marked Point Statistics

Cross-type K and L, inhomogeneous K and annular pair and mark correlation on a rectangle.

Cross K (cyan), pair correlation (orange) and mark correlation (white) of two flash size classes; the faint rule is 1, no interaction.

Reading the result

Best when points carry a type or a mark, such as two species or trees with sizes. It tests whether types attract each other or whether marks are spatially correlated.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Packed planar points, one row per event.
typesGraphDataView<'uint32'>-Optional uint32 categories.
typePairreadonly [number, number]-The two types compared in the cross-type statistic.
marksGraphDataView<'float32'>-Optional finite scalar mark per point.
intensitiesGraphDataView<'float32'>-Optional positive point intensity.
parameters*GraphDataView<'float32'>-Bounds, maximumRadius and minimum intensity.
radiusCount*number-Number of radii.
edgeCorrection'none' | 'translation''translation'Rectangle translation correction or none.

Returns

FieldTypeDescription
statisticsGraphDataView<'float32'>Four statistics per radius.
pairCountsGraphDataView<'uint32'>Pairs counted per radius.
statusGraphDataView<'uint32'>Per radius: 0 valid, 1 invalid, 2 nonfinite.

Example

import {GPUMarkedPointStatistics} from '@luma-contributors/analysis/dataframe-analysis';

// positions, types, parameters, statistics, pairCounts, status: views on graph
graph.add(new GPUMarkedPointStatistics({
  positions, types, typePair: [0, 1],
  parameters, radiusCount: 32,
  output: {statistics, pairCounts, status}
}));
