Reading the result

Best when regions must reach a floor, such as 10,000 people, and you want the most regions. It grows regions from several random starts, then improves them. The best start wins.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsContiguity graph.
values*GraphDataView<'float32'>Similarity attribute columns.
extensiveValues*GraphDataView<'float32'>Attribute that must reach the threshold.
threshold*GraphDataView<'float32'>Minimum extensive total per region.
parameters*GraphDataView<'uint32'>Seed, from getGPUMaxPRegionsParameterValues.

maximumGrowthStepsnumberRegion growth cap.

Returns

FieldTypeDescription

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUMaxPRegions, getGPUMaxPRegionsParameterValues, GPU_MAX_P_REGIONS_PARAMETER_LENGTH} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'max-p'});
const parameters = new GPUParameterBuffer(device, {
  id: 'max-p-parameters', format: 'uint32', length: GPU_MAX_P_REGIONS_PARAMETER_LENGTH,
  values: getGPUMaxPRegionsParameterValues({seed: 4})
});
// weights, values, population, threshold (one row), outputs: graph views
graph.add(new GPUMaxPRegions({
  weights, values, columnCount: 2, extensiveValues: population, threshold,
  startCount: 16, parameters: parameters.importToGraph(graph),
  output: {labels, objective, status}
}));
graph.compile().encode(device.commandEncoder, {parameters: undefined});
