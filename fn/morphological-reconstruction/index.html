Morphological reconstruction

Geodesic dilation or erosion of a marker under a mask, run in bounded GPU rounds.

0.25
method
120
drawn

A mask and a marker in; the marker reconstructed under the mask out.

Reading the result

Keeps only the features that touch your markers, or floods basins and fills pits. Dilation grows the marker up to the mask; erosion shrinks it down to the mask.

Parameters

PropTypeDescription
grid*GPURasterMetadataShared grid.
marker*GraphDataView<"float32">Starting values that propagate.
mask*GraphDataView<"float32">Values that bound the propagation.
method"dilation" | "erosion"Growth direction.
connectivity4 | 8Neighbor connectivity.
maximumIterationsnumberBounded number of rounds.
output*{values}values, validity and a converged status.

Returns

FieldTypeDescription
valuesGraphDataView<"float32">Reconstructed raster.
validityGraphDataView<"uint32">1 where the result is valid.
status.convergedGraphDataView<"uint32">1 when a fixpoint was reached.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterReconstruction, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `marker` and `mask` are float32 graph views, one row per pixel.
graph.add(new GPURasterReconstruction({
  grid,
  marker,
  mask,
  method: 'dilation',
  connectivity: 8,
  maximumIterations: 128,
  output: {values: view('values', 'float32', 512 * 512), validity: view('valid', 'uint32', 512 * 512),
    status: {converged: view('converged', 'uint32', 1)}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
