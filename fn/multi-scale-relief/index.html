Reading the result

Isolates features within a size band, such as house platforms or field banks. Choose featureMinimum, featureMaximum and a scalingFactor; the filters use exact summed-area tables.

Parameters

PropTypeDescription
grid*GPURasterMetadataWidth, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBandFloat32 elevation band; invalid or no-data cells are skipped.
parameters*GraphDataView<"float32">Per-frame settings, packed by the matching getGPU...ParameterValues.
resolution*numberCell size used to convert feature sizes to radii.
featureMinimum*numberSmallest feature size, in ground units.
featureMaximum*numberLargest feature size, in ground units.
scalingFactor*numberStep between successive filter radii.
output*GPUMultiScaleReliefOutputViews for relief and validity.

Returns

FieldTypeDescription
reliefGraphDataView<"float32">Signed multi-scale relief.
outputValidityGraphDataView<"uint32">Nonzero where the cell has a valid result.

Example

import {
  GPUMultiScaleRelief,
  getGPUMultiScaleReliefParameterValues
} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUMultiScaleRelief({
  grid, elevation,
  resolution: 1, featureMinimum: 2, featureMaximum: 20, scalingFactor: 2,
  parameters: parameters.importToGraph(graph),
  output: {relief}
}));
parameters.write(getGPUMultiScaleReliefParameterValues({verticalExaggeration: 1}));
