Reading the result

Feeds k-nearest-neighbor weights into spatial statistics such as Moran or Getis-Ord, as libpysal KNN does. It reads the neighbor columns of a nearest join. Exclude self-matches for point sets joined to themselves.

Parameters

PropTypeDefaultDescription
neighborRows*GraphDataView<"uint32">-Neighbor feature row indices from the nearest join.
neighborCounts*GraphDataView<"uint32">-Valid neighbors per query.
neighborStatus{overflow, candidateOverflow?}-Join loss; requires output.status.candidateOverflow to propagate it.
neighborDistancesGraphDataView<"float32">-Distances; needed for inverse-distance.
slotCapacity*number-Neighbor slots per query.
weightType"binary" | "inverse-distance"'binary'Weight kind.
excludeSelfboolean-Drop each row from its own neighbors.
output*GPUSpatialWeightsOutput-CSR weights views plus status.

Returns

FieldTypeDescription
offsetsGraphDataView<"uint32">CSR row offsets.
neighborsGraphDataView<"uint32">CSR neighbor row indices.
weightsGraphDataView<"float32">CSR weight per neighbor.
status{overflow, candidateOverflow?}Final CSR capacity loss and upstream nearest-join loss, separately.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUNearestFeatureWeights} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'knn-weights'});
// Request neighborRows alongside neighborIds on GPUNearestFeatureJoin (k = 8).
const {neighborRows, neighborCounts, neighborDistances, status: neighborStatus} = nearestViews;
const weights = weightViews; // GPUSpatialWeights output views plus status.overflow and status.candidateOverflow

graph.add(new GPUNearestFeatureWeights({
  neighborRows, neighborCounts, neighborDistances, neighborStatus, slotCapacity: 8,
  excludeSelf: true, weightType: 'inverse-distance', output: weights
}));
const compiled = await graph.compileAsync();
