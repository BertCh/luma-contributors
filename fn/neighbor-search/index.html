Reading the result

The weights builder for point data and the PySAL KNN and DistanceBand equivalent. Search runs on a GPU grid; weights can be binary, inverse distance or a kernel. Pass queryPositions for a cross join.

Parameters

PropTypeDescription
mode*'knn' | 'radius'k nearest targets, or all within the radius.
positions*GraphDataView<'float32x2'>Target points.
knumber | undefinedNeighbors per query in knn mode, 1 to 32.
gridSize*readonly [number, number]Maximum columns and rows of the search lattice.
parameters*GraphDataView<'float32'>Per-frame bounds, radius and weight function.
queryPositionsGraphDataView<'float32x2'> | undefinedSeparate query points (cross join).
rowStandardizeboolean | undefinedRow-standardize the weights while writing.
output*GPUNeighborSearchOutputCaller-owned CSR with an overflow flag.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>CSR row offsets, queryRows + 1.
neighborsGraphDataView<'uint32'>Neighbor ids, ascending per row.
weightsGraphDataView<'float32'>Weights per link.
distancesGraphDataView<'float32'> | undefinedOptional link distances.
statusGPUBoundedResultStatusPortGPU status words; zero means complete.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUNeighborSearch, GPUParameterBuffer, getGPUNeighborSearchParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
const parameters = new GPUParameterBuffer(device, {id: 'search', format: 'float32', length: 12});
parameters.write(getGPUNeighborSearchParameterValues({bounds: [0, 0, 100, 100]}));
graph.add(
  new GPUNeighborSearch({
    mode: 'knn',
    k: 4,
    positions: graph.importGPUData('positions', positionData),
    gridSize: [64, 64],
    parameters: parameters.importToGraph(graph),
    output: csr(pointCount, 4 * pointCount)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
