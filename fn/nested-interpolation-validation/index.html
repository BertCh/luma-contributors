Reading the result

Chooses a kernel, degree or smoothing without optimistic bias. An inner buffered search picks the best candidate, then the outer test blocks score it; all on the GPU.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar point coordinates, one float32x2 per point.
response*GraphDataView<"float32">Observed value per point.
training*GraphDataView<"uint32">Outer training masks from spatial cross-validation.
testing*GraphDataView<"uint32">Outer testing masks.
foldCount*numberNumber of outer folds.
innerBlocks*GraphDataView<"uint32">Block ids for the inner folds.
candidates*readonly GPUNestedInterpolationCandidate[]Kriging covariance or RBF kernel, epsilon and smoothing options.
output*{selected, scores}Selected candidate, scores and metrics.

Returns

FieldTypeDescription
selectedGraphDataView<"uint32">Winning candidate per outer fold.
scoresGraphDataView<"float32">Inner score per candidate.
predictionsGraphDataView<"float32">Outer predictions per point.
metricsGraphDataView<"float32">Per fold: scored, missing, MSE, MAE, bias, R2.
statusGraphDataView<"uint32">Bitmask: 1 overlapping outer masks, 2 no selected candidate.

Example

import {GPUNestedInterpolationValidation} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
// training and testing come from GPUSpatialCrossValidation
graph.add(new GPUNestedInterpolationValidation({
  positions, response, training, testing, foldCount: 5,
  innerBlocks, innerFoldCount: 3,
  candidates: [
    {mode: 'rbf', kernel: 'gaussian', epsilon: 0.5},
    {mode: 'rbf', kernel: 'gaussian', epsilon: 1, smoothing: 0.1}
  ],
  output: {selected, scores, predictions, metrics, status}
}));
