Network coarsening

Collapses a network by group label into a summary graph of compound nodes, centroids and weighted edges.

Props
0.30
Sample data
0.10
drawn

Group centroids and superedges after labelling nodes by spatial cell.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best for zoomed-out views of huge networks: one node per community or tile. Group nodes counts, centroids, bounds and value sums are computed on the GPU. Edges between groups are merged with counts and weights.

Parameters

PropTypeDescription
topology*GPUNetworkAdjacencyCSR network with node positions.
labels*GraphDataView<"uint32">Group label per node.
groupCapacity*numberMaximum number of groups.
nodeValuesGraphDataView<"float32"> | undefinedOptional node value to sum per group.
nodeMaskGraphDataView<"uint32"> | undefinedNonzero entries are live nodes.
directedboolean | undefinedTreat edge slots as directed.
fixedPointScalenumber | undefinedOptional fixed sum unit (power of two); left out, it follows the data.
output*GPUNetworkCoarseningOutputPer-group stats and merged group edges.

Returns

FieldTypeDescription
groupNodeCountGraphDataView<'uint32'>Nodes per group.
groupCentroidGraphDataView<'float32x2'>Group centroid (optional).
groupBoundsGraphDataView<'float32x4'>Group bounding box (optional).
edgeTargetGroupsGraphDataView<'uint32'>Target group of each merged edge.
edgeCountsGraphDataView<'uint32'>Original edges merged into each group edge.
edgesGPUCompactOutputSuperedge list; `ids` is the source group.

Example

import {GPUNetworkCoarsening} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkCoarsening({
  topology,
  labels: communities.importToGraph(graph),
  groupCapacity: 256,
  output: {groupNodeCount, groupCentroid, edges, edgeTargetGroups, edgeCounts}
}));
