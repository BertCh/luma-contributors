Network cost table

Precomputes a bounded all-pairs cost table of a static network, as a sparse CSR of reachable pairs.

Props
0.22
Sample data
0.6
drawn

The cost table row of one origin, drawn as the cost to each intersection within the radius.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

A fast lookup for map matching and repeated routing on a fixed network. Every node searches out to the cost limit. Reachable targets are stored sparsely, with overflow reported on the GPU.

Parameters

PropTypeDefaultDescription
topology*GPUNetworkTopology-CSR network: offsets, neighbors, per-edge cost.
costLimit*GraphDataView<"float32">-Radius of every search (one-row view).
laneCountnumber | undefined-Searches run concurrently.
maximumIterationsnumber | undefined-Round budget per batch.
localIterationsnumber | undefined16Hops chained per round.
output*GPUNetworkCostTableOutput-offsets, targets, costs and overflow status.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>Row offsets into targets and costs.
targetsGraphDataView<'uint32'>Reachable target node per entry.
costsGraphDataView<'float32'>Cost per entry.
status.overflowGraphDataView<'uint32'>1 when the table capacity was exceeded.

Example

import {GPUNetworkCostTable} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkCostTable({
  topology,
  costLimit: radius.importToGraph(graph),
  maximumIterations: 48,
  output: {offsets, targets, costs, status: {overflow, converged}}
}));
