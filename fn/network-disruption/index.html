Network disruption

Compares baseline and disrupted routing: cost change, newly unreachable nodes and lost accessibility.

0.10
0.70
drawn

Closed roads, and the accessibility each origin loses (diverging).

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Shows what a closed bridge or flooded road does to travel and access. It runs the cost matrix twice, with and without the edge mask, and differences them without Infinity arithmetic. Opportunity weights give the accessibility change.

Parameters

PropTypeDescription
search*Omit<GPUNetworkCostMatrixProps, "id" | "output">Cost-matrix settings: topology, starts, limits.
rowCount*numberNumber of origin rows.
edgeMaskGraphDataView<"uint32"> | undefinedZero marks closed edge slots.
replacementCostsGraphDataView<"float32"> | undefinedCosts to use instead of closing edges.
opportunityWeights*GraphDataView<"float32">Opportunities per destination.
parameters*GraphDataView<"float32">Per-frame threshold and decay.
outputsPartial<GPUNetworkDisruptionOutput> | undefinedAny of the disruption output views.

Returns

FieldTypeDescription
outputsGPUNetworkDisruptionOutputBaseline and scenario costs, differences, newlyUnreachable, accessibility.
contributorsGPUCommandNodeProducer[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, unknown>Named ports between stages.
statusGPURecipeStatusPortCompleteness and convergence views per stage.

Example

import {addNetworkDisruptionRecipe} from '@luma-contributors/analysis/gpu-network';

const recipe = addNetworkDisruptionRecipe(graph, {
  search: {topology, startNodes: origins, costLimit, maximumIterations: 64},
  rowCount: originCount,
  edgeMask: openEdges.importToGraph(graph),
  opportunityWeights: jobs.importToGraph(graph),
  parameters: parameters.importToGraph(graph),
  outputs: {costDifferences, newlyUnreachable, accessibilityDifferences}
});
