Inhomogeneous network K

Inhomogeneous network K: clustering of events beyond what a varying intensity already explains.

Inhomogeneous K(r): pair counts weighted by inverse intensity, per radius.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best when event density varies (more crashes on busy roads) and you want clustering beyond that. Each pair is weighted by the inverse intensities at both ends. Choose Ang edge correction and a normalization.

Parameters

PropTypeDefaultDescription
eventNodeIds*GraphDataView<"uint32">-Network node of each event.
intensity*GraphDataView<"float32">-Estimated intensity per event.
nodeDistances*GraphDataView<"float32">-Event-major shortest-path distances to every node.
edgeNodes*GraphDataView<"uint32x2">-Edge endpoints.
edgeLengths*GraphDataView<"float32">-Edge lengths.
radii*GraphDataView<"float32">-Distances at which K is evaluated.
correction"none" | "ang" | undefined'ang'Edge correction: 'none' or 'ang'.
normalization"network-length" | "inverse-intensity"'network-length'Denominator: 'network-length' or 'inverse-intensity'.
and 1 more required: nodeCount

Returns

FieldTypeDescription
kGraphDataView<'float32'>Inhomogeneous K per radius.
numeratorGraphDataView<'float32'>Weighted pair sum per radius.
normalizationGraphDataView<'float32'>Denominator per radius.
statusGraphDataView<'uint32'>Overflow and pair-count status.

Example

import {GPUNetworkInhomogeneousK} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkInhomogeneousK({
  eventNodeIds: eventNodes.importToGraph(graph),
  intensity: intensity.importToGraph(graph),
  nodeDistances: distances.importToGraph(graph),
  nodeCount,
  edgeNodes: edgeNodes.importToGraph(graph),
  edgeLengths: edgeLengths.importToGraph(graph),
  radii: radii.importToGraph(graph),
  output: {k, numerator, normalization, status}
}));
