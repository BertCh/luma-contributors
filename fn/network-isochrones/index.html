Network isochrones

Turns network travel costs into contoured isochrone polygons, or the outline of reached cells.

Travel-time bands around the origin, from the isoband triangles.

Reading the result

Best when you need drawable travel-time areas, not per-node costs. Edge-interpolated costs are splatted to a raster and contoured into bands. Feed it costs from reachability or service areas.

Parameters

PropTypeDescription
topology*GPUNetworkTopology & {nodePositions}CSR network with node positions.
costs*GraphDataView<"float32">Per-node costs from reachability.
costBreaks*GraphDataView<"float32">Band edges for the contours.
parameters*GraphDataView<"float32">Per-frame extent, break count and buffer radius.
rasterGPUNetworkIsochronesRaster | undefinedSplat raster size and its triangle outputs.
cellOutlineGPUNetworkIsochronesCellOutline | undefinedOutline rings of reached cells instead of a raster.
assignmentsGraphDataView<"uint32"> | undefinedOptional facility labels to isolate per-facility areas.
outputGPUNetworkIsochronesOutput | undefinedConvergence status.

Returns

FieldTypeDescription
raster.output.trianglesGraphDataView<"float32x2">Isoband triangle vertices, three per triangle.
raster.output.triangleBandsGraphDataView<"uint32">Cost band of each triangle.
cellOutlineGPUNetworkIsochronesCellOutlineOutline of the reached cells, when requested instead of a raster.
status{converged?}Optional flag: 1 when label propagation finished.

Example

import {
  GPUNetworkIsochrones, getGPUNetworkIsochronesParameterValues
} from '@luma-contributors/analysis/gpu-network';

// topology, costs (from GPUNetworkReachability) and output views live on `graph`
graph.add(new GPUNetworkIsochrones({
  topology, costs,
  costBreaks: costBreaks.importToGraph(graph),
  parameters: parameters.importToGraph(graph),
  raster: {width: 256, height: 256, output: {triangles, triangleBands, status: {count, overflow}}}
}));
// parameters: getGPUNetworkIsochronesParameterValues({breakCount: 4, extent, bufferRadius: 50})
