Network K function

Network-constrained Ripley K of events on a road network, with a Monte Carlo envelope.

Observed K(d) against the envelope of random patterns on the same network.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Tests whether crashes or crimes cluster along roads, not just in the plane. Events snap to the network; pairs are counted by shortest-path distance per band. Simulated events give the envelope.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Event coordinates.
topology*GPUNetworkTopology & {nodePositions}-CSR network with node positions.
maximumDistance*GraphDataView<"float32">-Largest distance band (one-row view).
networkLength*GraphDataView<"float32">-Total network length (one-row view).
parameters*GraphDataView<"uint32">-Per-frame seed and simulation settings.
bandCountnumber | undefined32Number of distance bands.
simulationCountnumber | undefined0Monte Carlo simulations for the envelope.
output*GPUNetworkKFunctionOutput-kValues, pairCounts, envelope, status.

Returns

FieldTypeDescription
kValuesGraphDataView<'float32'>K per distance band.
pairCountsGraphDataView<'uint32'>Event pairs per band (optional).
envelopeGraphDataView<'float32'>Simulation envelope per band (optional).
status.convergedGraphDataView<'uint32'>1 when every search finished.

Example

import {GPUNetworkKFunction} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkKFunction({
  positions: events.importToGraph(graph),
  topology,
  maximumDistance: maximumDistance.importToGraph(graph),
  networkLength: networkLength.importToGraph(graph),
  parameters: parameters.importToGraph(graph),
  bandCount: 32,
  simulationCount: 99,
  output: {kValues, envelope}
}));
