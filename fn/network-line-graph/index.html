Turn-aware line graph

Builds the edge-based line graph of a road network so turn costs and bans become ordinary edge weights.

0.12
0.15
0.00
drawn

Cost to arrive along each directed road, with turn penalties from the line graph.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best before routing when turns matter: left-turn penalties, U-turn bans, signals. Each road edge becomes a node; each legal turn becomes an arc with a cost. The output is a topology you feed straight to reachability.

Parameters

PropTypeDescription
topology*GPUNetworkTopology & {nodePositions}CSR road network with node positions.
parameters*GraphDataView<"float32">Per-frame turn penalty settings.
bannedTurnsGraphDataView<"uint32"> | undefinedOptional turns to remove.
output*GPUNetworkLineGraphOutputLine-graph topology, arc count and overflow.

Returns

FieldTypeDescription
topology.offsetsGraphDataView<'uint32'>CSR offsets of the line graph.
topology.neighborsGraphDataView<'uint32'>Next edge per arc.
topology.weightsGraphDataView<'float32'>Turn-aware cost per arc.
status.overflowGraphDataView<'uint32'>1 when arc capacity was exceeded.
arcCountGraphDataView<'uint32'> | undefinedOptional one-row arc count.

Example

import {GPUNetworkLineGraph} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkLineGraph({
  topology,
  parameters: turnParameters.importToGraph(graph),
  bannedTurns: bans.importToGraph(graph),
  output: {topology: {offsets, neighbors, weights}, status: {overflow}}
}));
// feed the output topology to GPUNetworkReachability
