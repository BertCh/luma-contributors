Network neighborhood

The k-hop ego network around start nodes: hop distances, node and edge masks, compact id lists.

7
2
drawn

Hop distance from the start nodes, out to the hops limit.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best for click-to-explore in a graph view: show what is within a few hops of a node. Hop counts are computed breadth-first from per-frame starts. Masks drive highlighting; compact lists feed draw calls.

Parameters

PropTypeDescription
topology*GPUNetworkAdjacencyCSR network, connectivity only.
startNodes*GraphDataView<"uint32">Ego nodes, rewritten every frame.
startCountnumber | GraphDataView<"uint32"> | undefinedNumber of starts, compiled in or per frame.
hops*GraphDataView<"uint32">Hop limit as a one-row view.
maximumHopsnumber | undefinedCompile-time cap on hops.
output*GPUNetworkNeighborhoodOutputhopDistances, nodeMask, edgeMask, compact node and edge lists.

Returns

FieldTypeDescription
hopDistancesGraphDataView<'uint32'>Hops from the nearest start per node.
nodeMaskGraphDataView<'uint32'>1 for nodes inside the neighborhood (optional).
edgeMaskGraphDataView<'uint32'>1 for induced edge slots (optional).
nodesGPUCompactOutputCompact list of neighborhood nodes (optional).

Example

import {GPUNetworkNeighborhood} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkNeighborhood({
  topology,
  startNodes: picked.importToGraph(graph),
  hops: hops.importToGraph(graph),
  maximumHops: 6,
  output: {hopDistances, nodeMask, edgeMask}
}));
