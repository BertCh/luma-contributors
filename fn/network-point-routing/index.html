Point routing with turns

Batched static routing between positions on directed edges, with explicit incoming turn state.

Cost to reach each directed road from a point on the source road, turns included.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best for many origin-destination queries where turn penalties or restrictions matter. Queries are edge positions plus fractions along them. Pair it with the line graph for turn-aware networks.

Parameters

PropTypeDescription
turns*GraphDataView<"uint32x2">Allowed [incomingEdge, outgoingEdge] turns.
costs*GraphDataView<"float32">Cost per turn transition.
queries*GraphDataView<"uint32x2">[sourceEdge, targetEdge] per query.
fractions*GraphDataView<"float32x2">Position along the source and target edges.
maximumRelaxationsnumber | undefinedRelaxation rounds.
output*{costs, status}costs, status and predecessor edges.

Returns

FieldTypeDescription
costsGraphDataView<'float32'>Route cost per query.
statusGraphDataView<'uint32'>Query status codes.
predecessorEdgesGraphDataView<'uint32'>Predecessor edge per state, for path recovery.

Example

import {GPUNetworkPointRouting} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkPointRouting({
  turns: turns.importToGraph(graph),
  costs: turnCosts.importToGraph(graph),
  queries: queries.importToGraph(graph),
  fractions: fractions.importToGraph(graph),
  output: {costs, status, predecessorEdges}
}));
