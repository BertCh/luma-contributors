Network statistics

Reduces a network to a compact summary: counts, components, degree histogram and community sizes.

Props
degreeBinning
Sample data
0.25
drawn

Histogram of node degree from the packed network summary, linked to the intersections.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best for a stats panel that updates as filters change. One GPU pass counts live nodes and edges, finds weak components and bins degrees. All results are packed in a single uint32 view.

Parameters

PropTypeDefaultDescription
topology*GPUNetworkAdjacency-CSR network, connectivity only.
directedboolean | undefined-Treat edge slots as directed.
nodeMaskGraphDataView<"uint32"> | undefined-Nonzero entries are live nodes.
edgeMaskGraphDataView<"uint32"> | undefined-Nonzero entries are live edge slots.
communitiesGraphDataView<"uint32"> | undefined-Optional community labels to summarize.
degreeBinCountnumber | undefined32Number of degree histogram bins.
degreeBinning"linear" | "log2" | undefined-'linear' or 'log2' degree bins.
output*GraphDataView<"uint32">-Packed summary words.

Returns

FieldTypeDescription
outputGraphDataView<'uint32'>Counts, component stats and degree histogram, packed.

Example

import {GPUNetworkStatistics} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkStatistics({
  topology,
  nodeMask: liveNodes.importToGraph(graph),
  degreeBinCount: 16,
  degreeBinning: 'log2',
  output: summary
}));
// decode `summary` with the statistics layout helpers on the CPU
