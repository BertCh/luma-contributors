Time-dependent routing

FIFO earliest-arrival routing on time-varying travel times over prepared restriction states.

Props
0.50
Sample data

drawn

Earliest arrival time at each intersection; later departures meet slower roads.

Intersections follow TIGER/Line geometry. Bidirectional links and travel costs are modeled.

Reading the result

Best for rush-hour routing and schedules where edge cost depends on departure time. Costs are affine durations or piecewise arrival samples. Results are earliest arrival times per state.

Parameters

PropTypeDescription
stateVertices*GraphDataView<"uint32">Vertex of each routing state.
transitions*GraphDataView<"uint32x2">State transitions as pairs.
costModel"affine-duration" | "piecewise-arrival" | undefined'affine-duration' or 'piecewise-arrival'.
costs*GraphDataView<"float32x2">[base duration, slope] per transition, or piecewise samples.
endpoints*GraphDataView<"uint32">[initial state, destination vertex] per query.
departure*GraphDataView<"float32">Departure time per query.
maximumRelaxationsnumber | undefinedRelaxation rounds.
output*{arrivals}arrivals, predecessor transitions and summary.

Returns

FieldTypeDescription
arrivalsGraphDataView<'float32'>Earliest arrival time per state.
predecessorTransitionsGraphDataView<'uint32'>Transition used to reach each state.
summaryGraphDataView<'uint32'>Convergence summary words.

Example

import {GPUNetworkTimeRouting} from '@luma-contributors/analysis/gpu-network';

graph.add(new GPUNetworkTimeRouting({
  stateVertices: vertices.importToGraph(graph),
  transitions: transitions.importToGraph(graph),
  costModel: 'affine-duration',
  costs: durations.importToGraph(graph),
  endpoints: endpoints.importToGraph(graph),
  departure: departureTimes.importToGraph(graph),
  output: {arrivals, predecessorTransitions, summary}
}));
