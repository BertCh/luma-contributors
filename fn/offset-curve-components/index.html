Offset curve components

Turns raw one-sided offsets into clean multipart curves at the requested distance.

0.090
joinStyle
drawn

The raw offset of a river reach, cleaned into valid components.

Data · Natural Earth cartography
  • Made with Natural Earth · Public domain · Natural Earth cartography
LinesLinesTables
How do I get my data ready?UseTransform geometryDomainGeometry and cartographyTransport networks

Reading the result

Use it to finish an offset: node the raw curve, discard parts closer to the source than distance, keep the requested side and compact the components.

Parameters

PropTypeDescription
original*GPULineGeometryFieldsSource lines.
raw*GPULineGeometryFieldsRaw offset of each source line, same order.
distance*numberOffset distance.
tolerance*numberAbsolute geometric slack, including chord error.
intersectionCapacity*numberCapacity of the intersection event list.
segmentCapacity*numberCapacity of kept segments.
output*{positions, components}Compacted components.

Returns

FieldTypeDescription
positionsGraphDataView<"float32x2">Vertices of the kept components.
componentsGraphDataView<"uint32">Component offsets per source line.
sourceEdgesGraphDataView<'uint32'>Source edge of each output vertex.
statusGraphDataView<'uint32x4'>Written and required component and vertex counts.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUOffsetCurveComponents} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUOffsetCurveComponents({
  original, raw, // GPULineGeometryFields
  distance: 20, tolerance: 0.5,
  intersectionCapacity: 4096, segmentCapacity: 4096,
  output // positions, components, ...
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
