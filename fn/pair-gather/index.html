Join attributes by pairs

Turns matched pairs from a spatial join into attribute rows, like GeoPandas sjoin.

Reading the result

A join gives pairs of row indices or dense nearest-neighbor lists; this gathers columns for both sides into aligned outputs. inner keeps matches only; left keeps every left row, unmatched marked with a sentinel. Final capacity loss and input candidate loss are reported separately.

Parameters

PropTypeDefaultDescription
howGPUPairGatherHow | undefined'inner''inner' or 'left'.
pairsGPUCompactPairPort | undefined-Matched pairs of a predicate join.
neighborsGPUPairGatherNeighbors | undefined-Dense neighbor lists of a nearest join.
unmatchedLeftGPUCompactOutput | undefined-Unmatched left rows, for how left.
leftColumnsreadonly GPUPairGatherColumn[] | undefined-Left columns, gathered by leftRows.
rightColumnsreadonly GPUPairGatherColumn[] | undefined-Right columns, gathered by rightRows.
output*GPUPairGatherOutput-Caller-owned bounded row outputs.

Returns

FieldTypeDescription
leftRowsGraphDataView<'uint32'>Left input row index per output row.
rightRowsGraphDataView<'uint32'>Right input row index, sentinel when unmatched.
rowCountGraphDataView<'uint32'>Number of valid output rows.
status.overflowGraphDataView<'uint32'>Final gathered or input output-capacity loss.
status.candidateOverflowGraphDataView<'uint32'>Input candidate loss, separate from final output capacity.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPairGather} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUPairGather({
    how: 'inner',
    pairs, // matched pairs from a spatial join
    rightColumns: [{source: incomeData, output: output('income', 'float32', capacity)}],
    output: {
      leftRows: output('left', 'uint32', capacity),
      rightRows: output('right', 'uint32', capacity),
      rowCount: output('count', 'uint32', 1),
      status: {overflow: output('overflow', 'uint32', 1), candidateOverflow: output('candidate-overflow', 'uint32', 1)}
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
