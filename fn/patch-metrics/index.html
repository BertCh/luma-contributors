Patch metrics

Per-patch area, perimeter and bounding box of a labeled raster, for landscape metrics.

Props
countRasterBorder
Sample data
18
drawn

Patch labels in (graph-coloured); area and perimeter of every patch out.

Data · Grand Canyon elevation
  • U.S. Geological Survey, 3D Elevation Program · Public domain · Grand Canyon elevation
RastersTerrainTablesTables
How much is there in each area?UseMeasureDomainEcology and environmentRemote sensing

Reading the result

Best after connected-component labeling to measure habitat patches, burn scars or lakes. Perimeter is an exact count of exposed pixel faces.

Parameters

PropTypeDescription
grid*GPURasterMetadataGrid of the label raster.
labels*GraphDataView<"uint32">Patch label per pixel; 0 is background.
maskGraphDataView<"uint32">Per-pixel validity flags.
statusGPURasterPatchLabelsStatusStatus from the labeling step.
countRasterBorderbooleanCount faces on the raster edge as perimeter.
output*GPURasterPatchMetricsOutputRequested per-patch columns.

Returns

FieldTypeDescription
pixelCountsGraphDataView<"uint32">Area in pixels per patch.
areasGraphDataView<"float32">Area in CRS units squared (optional).
perimeterFaceCountsGraphDataView<"uint32">Exposed pixel faces per patch.
perimetersGraphDataView<"float32">Perimeter in CRS units (optional).

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterPatchMetrics, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `labels` is a uint32 graph view from connected-component labeling.
graph.add(new GPURasterPatchMetrics({
  grid,
  labels,
  output: {
    pixelCounts: view('pixels', 'uint32', 1024),
    areas: view('areas', 'float32', 1024)
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
