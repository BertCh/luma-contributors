Patch core area: cells deeper than edgeDepth inside their patch.

What is nearby, or what can be reached?UseMeasureDomainEcology and environment

Reading the result

Judges how isolated patches are and how much is interior habitat. Distances are exact between cell rectangles, and edge depth is physical. Background counts as a core barrier.

Parameters

PropTypeDefaultDescription
patches*GraphDataView<"uint32">-Connected-patch ID per cell over the complete raster.
patchClasses*GraphDataView<"uint32">-Class ID per patch.
width*number-Raster width in cells.
height*number-Raster height in cells.
cellSize*readonly [number, number]-Positive planar cell width and height.
edgeDepth*number-Core cells lie deeper than this from the patch edge.
searchRadius*number-Radius for proximity neighbors, in cell units.
distanceModel"cell-boundary" | "cell-center" | undefined'cell-boundary'Rectangle separation, or landscapemetrics center ENN.

Returns

FieldTypeDescription
outputs.coreGraphDataView<"uint32">Core-cell mask per cell.
outputs.distancesGraphDataView<"float32">Pairwise patch boundary distances.
outputs.metricsGraphDataView<"float32">[area, core area, nearest distance, proximity].
intermediatesRecord<string, GraphDataView>Named stage ports; graph-owned, not for readback.
provenanceRecord<string, GraphDataView>Stage ports that show how the result was built.

Example

import {addPatchProximityRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; patch labels cover the complete raster
const proximity = addPatchProximityRecipe(graph, {
  patches, patchClasses,
  width: 512, height: 512,
  cellSize: [30, 30],
  edgeDepth: 60,
  searchRadius: 500
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// proximity.outputs.metrics: one [area, coreArea, nearest, proximity] row per patch
