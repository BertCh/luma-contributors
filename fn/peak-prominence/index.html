Reading the result

Ranks peaks by how far they rise above the saddle that connects them to higher ground. It builds the upper excursion-set merge tree (elder rule, zero-dimensional persistence).

Parameters

PropTypeDescription
grid*GPURasterMetadataWidth, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBandFloat32 elevation band; invalid or no-data cells are skipped.
output*GPUTerrainPeakProminenceOutputViews for prominence, keySaddle and parentPeak.

Returns

FieldTypeDescription
prominenceGraphDataView<"float32">Prominence at each peak pixel, in elevation units.
keySaddleGraphDataView<"float32">Elevation of the key saddle.
parentPeakGraphDataView<"uint32">Cell index of the parent peak.

Example

import {GPUTerrainPeakProminence} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUTerrainPeakProminence({
  grid, elevation,
  output: {prominence, keySaddle, parentPeak}
}));
