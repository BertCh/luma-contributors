Reading the result

Shows where activity rose or fell between two periods. Both periods are aggregated to the same cells, differenced, classified with your breaks and colored with a diverging ramp.

Parameters

PropTypeDefaultDescription
family*GPUCellAggregationFamily-Cell family shared by both periods.
resolution*number-Cell resolution shared by both periods.
tableCapacity*number-Rows of each period cell table.
before*GPUPeriodRows-Earlier period rows.
after*GPUPeriodRows-Later period rows.
sumScalenumber65536One fixed-point scale shared by both aggregations and the comparison.

Example

import {addPeriodComparisonRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; each period is point positions to be aggregated to cells
const change = addPeriodComparisonRecipe(graph, {
  family: 'h3', resolution: 8, tableCapacity: 8192,
  before: {positions: positionsBefore},
  after: {positions: positionsAfter},
  classBreaksParameters, maximumClassCount: 5,
  palette, colorScaleParameters, maximumPaletteCount: 5
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// change.colors: diverging color per cell present in either period
