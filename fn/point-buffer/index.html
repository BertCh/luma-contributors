Reading the result

Draws radius circles around many points with a per-frame radius. Geographic offsets are degrees you add to float64 centers, so small radii keep precision.

Parameters

PropTypeDescription
points*GraphDataView<'float32x2'>float32x2 centers: degrees or planar units.
parameters*GraphDataView<'float32'>Radius from getGPUPointBufferParameterValues.
offsets*GraphDataView<'float32x2'>float32x2 ring vertex offsets, verticesPerRing per point.
verticesPerRing*numberVertices per ring, at least 3.
coordinateSystem*'geographic' | 'planar''geographic' or 'planar'.

Returns

FieldTypeDescription
offsetsGraphDataView<'float32x2'>Vertex offsets from each center.

Example

import {GPUPointBuffer, getGPUPointBufferParameterValues} from '@luma-contributors/analysis/geospatial-analysis';

// points, parameters, offsets: views on graph
graph.add(new GPUPointBuffer({
  points, parameters, offsets,
  verticesPerRing: 32, coordinateSystem: 'geographic'
}));
// 250 m radius
const radiusValues = getGPUPointBufferParameterValues(250);
