Point density

Bins points into square or hexagon cells and writes a count, sum or mean raster.

Reading the result

Best for fast heat maps of millions of points. This is binned counting, not a kernel estimate, so values change with gridSize. Optional smoothing convolves the field in cell units.

Parameters

PropTypeDefaultDescription
positions*GPUFloat32Positions-Point locations.
bounds*GPUPointDensityBounds-Viewport [minX, minY, maxX, maxY], static or GPU view.
gridSize*readonly [number, number]-Columns and rows of the output grid.
binning'grid' | 'hexagon''grid'Cell shape.
statistic'count' | 'sum' | 'mean''count'What each cell holds.
weightsGraphDataView<'float32'>-Per-point weight for sum and mean.
smoothingGPUPointDensitySmoothing-Convolution kernel applied to the binned field.
output*GPUPointDensityOutput-Destination views.

Returns

FieldTypeDescription
valuesGraphDataView<'float32'>Count, sum or mean per cell.
extentGraphDataView<'float32'>Field [min, max] for color scaling.
histogramGraphDataView<'uint32'>Distribution of cell values.
textureGraphTextureView<'r32float'>Optional field as a texture.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPointDensity} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'heat'});
// positions, values, extent: graph views over caller-owned buffers
graph.add(
  new GPUPointDensity({
    positions,
    bounds: [minX, minY, maxX, maxY],
    gridSize: [256, 256],
    statistic: 'count',
    output: {values, extent}
  })
);
const compiled = graph.compile();
compiled.encode(device.commandEncoder, {parameters: undefined});
