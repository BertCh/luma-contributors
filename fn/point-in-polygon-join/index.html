Point in polygon join

Joins planar points to the polygon features that contain them.

Reading the result

Tags points with the zone they fall in, or to count points per zone. Candidates come from a BVH and an exact test decides each pair. Choose a half-open, closed or open boundary rule for points on an edge.

Parameters

PropTypeDefaultDescription
points*GPUPointGeometryPort-Points to locate.
polygons*GPUPolygonGeometryPort-like-Polygon offsets and positions of the zones.
candidateCapacity*number-Maximum bounding-box candidates.
boundaryRuleGPUPointInPolygonBoundaryRule'half-open''half-open', 'closed' or 'open'.
preparedGPUSpatialJoinPrepared-Reuse a prebuilt polygon index.
edgeSlabsboolean-Speed up very large polygons with edge slabs.
output*GPUPointInPolygonJoinOutput-pointFeatureIds, counts, matches, status.

Returns

FieldTypeDescription
pointFeatureIdsGPUUint32RowsContaining feature id per point.
featureCountsGraphDataView<"uint32">Points inside each feature.
matchesGPUCompactOutputOptional compact list of matched points.
status{count, overflow}overflow, candidateCount and uncertainCount.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPointInPolygonJoin} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'pip'});
const points = {kind: 'points', positions: pointPositions} as const; // views on this graph
const polygons = {kind: 'polygons' as const, featureOffsets, polygonOffsets, ringOffsets, positions: zonePositions};
const {pointFeatureIds, featureCounts, status} = joinViews; // output views

graph.add(new GPUPointInPolygonJoin({
  points, polygons, candidateCapacity: 1 << 18,
  output: {pointFeatureIds, featureCounts, status}
}));
const compiled = await graph.compileAsync();
