Reading the result

Measures erosion, deformation or growth between two aligned scans. For each core point it compares cylindrical neighborhoods along the normal and reports the displacement with a 95 percent detection bound.

Parameters

PropTypeDescription
reference*GraphDataView<'float32x3'>Earlier cloud, float32x3.
comparison*GraphDataView<'float32x3'>Later cloud, float32x3.
cores*GraphDataView<'float32x3'>Core points where change is measured.
normals*GraphDataView<'float32x3'>Unit normal per core point.
alignment*'already-aligned' | { transform: GraphDataView<'float32'>; }'already-aligned' or a comparison-to-reference transform.
radius*numberCylinder radius.
halfDepth*numberCylinder half-length along the normal.
registrationErrornumberRegistration uncertainty added to the bound.

Returns

FieldTypeDescription
changesGraphDataView<'float32x3'>Signed change, lower bound, upper bound.
roughnessGraphDataView<'float32x3'>Reference roughness, comparison roughness, pooled.
countsGraphDataView<'uint32'>Reference and comparison point counts per core.
statusGraphDataView<'uint32'>0 valid, 1 invalid core, 2 low support.

Example

import {GPUPointCloudChange} from '@luma-contributors/analysis/pointcloud-analysis';

// reference, comparison, cores, normals, changes, roughness, counts, status: views on graph
graph.add(new GPUPointCloudChange({
  reference, comparison, cores, normals, alignment: 'already-aligned',
  radius: 1, halfDepth: 2, registrationError: 0.02,
  output: {changes, roughness, counts, status}
}));
