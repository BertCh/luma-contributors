Progressive Ground Filter

Bounded progressive morphological filter that classifies ground points over growing square windows.

0.020
3
drawn

Points colored by height (left of the curtain) and by the ground mask the morphological filter wrote (right: ground orange, removed blue); the squares are its window sizes. In this lidar tile ground and trees are far apart in height, so only initialThreshold above about 0.2 moves the classification; the window count changes few points. slope (0.1) and maximumThreshold (0.8) are fixed.

Reading the result

Best for a quick ground classification from a cell-minimum surface. Each stage opens the surface with a larger window and rejects points that rise above a slope-based threshold; it is a PMF, not SMRF.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x3'>Packed float32x3 positions.
classifications*GraphDataView<'uint32'>Original uint32 classes.
grid*PointCloudRasterGrid{origin, cellSize, width, height} planar grid.
minimumSurface*GraphDataView<'float32'>Minimum elevation per occupied cell.
radii*readonly number[]Strictly increasing window radii in cells, 1 to 32.
initialThreshold*numberStarting elevation threshold.
slope*numberTerrain slope used to grow the threshold.
maximumThreshold*numberUpper limit of the threshold.
and 1 more required: coverage

Returns

FieldTypeDescription
groundMaskGraphDataView<'uint32'>Ground flag per point.
outputClassificationsGraphDataView<'uint32'>Ground becomes LAS class 2; others keep or become 1.
statusGraphDataView<'uint32'>Bit 1 unsupported, bit 2 incomplete window.

Example

import {GPUPointCloudGround} from '@luma-contributors/analysis/pointcloud-analysis';

// positions, classes, minimum, coverage, groundMask, outputClasses, status: views on graph
graph.add(new GPUPointCloudGround({
  positions, classifications: classes,
  grid: {origin: [0, 0], cellSize: 1, width: 256, height: 256},
  minimumSurface: minimum, coverage,
  radii: [1, 2, 4], initialThreshold: 0.2, slope: 0.1, maximumThreshold: 1,
  output: {groundMask, outputClassifications: outputClasses, status}
}));
