Reading the result

Registers one scan onto another. Each iteration matches nearest points within maximumDistance and solves a rigid transform by Horn least squares; history reports inliers and RMSE per step.

Parameters

PropTypeDefaultDescription
source*GraphDataView<'float32x3'>-Packed float32x3 positions to move.
target*GraphDataView<'float32x3'>-Packed float32x3 positions to match.
maximumDistance*number-Correspondences farther than this are rejected.
metric'point-to-point' | 'point-to-plane''point-to-point''point-to-point' or 'point-to-plane'.
targetNormalsGraphDataView<'float32x3'>-Normals of target, for point-to-plane.
robust{ method: 'huber' | 'tukey'; scale: number; }-Huber or Tukey reweighting and its scale.
iterationsnumber-Iteration budget.
output*GPUPointCloudICPOutput-Caller-owned transform, history, inlierMask and status.

Returns

FieldTypeDescription
transformGraphDataView<'float32'>Column-major 4x4 rigid transform, source to target.
historyGraphDataView<'float32x3'>Per iteration: inliers, RMSE, translation step.
inlierMaskGraphDataView<'uint32'>Final correspondence flags per source point.
statusGraphDataView<'uint32'>0 converged, 1 budget exhausted, 2 few matches.

Example

import {GPUPointCloudICP} from '@luma-contributors/analysis/pointcloud-analysis';

// source, target (shared local frame), transform, history, inlierMask, status: views on graph
graph.add(new GPUPointCloudICP({
  source, target, maximumDistance: 1, iterations: 20,
  output: {transform, history, inlierMask, status}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
