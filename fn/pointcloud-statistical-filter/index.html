Reading the result

Drops noise points before surfacing or registration. It consumes neighborhood distances and writes a row-preserving inlier mask, with no compaction.

Parameters

PropTypeDefaultDescription
squaredDistances*GraphDataView<'float32'>-Squared distances from GPUPointCloudNeighborhoods.
counts*GraphDataView<'uint32'>-Neighbor counts from GPUPointCloudNeighborhoods.
capacity*number-Neighbor capacity of the input.
standardDeviationsnumber2Threshold in standard deviations above the mean.
output*GPUPointCloudStatisticalFilterOutput-Caller-owned meanDistances and original-row validity flags.

Returns

FieldTypeDescription
validityGraphDataView<'uint32'>One inlier flag per original row.
meanDistancesGraphDataView<'float32'>Mean neighbor distance per point.

Example

import {GPUPointCloudNeighborhoods, GPUPointCloudStatisticalFilter} from '@luma-contributors/analysis/pointcloud-analysis';

// positions, indices, squaredDistances, counts, meanDistances, validity: views on graph
graph.add(new GPUPointCloudNeighborhoods({
  positions, radius: 2, capacity: 16, output: {indices, squaredDistances, counts}
}));
graph.add(new GPUPointCloudStatisticalFilter({
  squaredDistances, counts, capacity: 16,
  standardDeviations: 2, output: {meanDistances, validity}
}));
