Reading the result

Rasterizes a classified lidar cloud on a planar grid. Terrain is the minimum ground-class elevation per cell, surface the maximum of all points, and coverage tells you which cells are supported.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x3'>-Packed float32x3 positions.
classifications*GraphDataView<'uint32'>-uint32 class per point.
groundClassnumber2Class counted as ground.
grid*PointCloudRasterGrid-{origin, cellSize, width, height} planar grid.
output*GPUPointCloudSurfacesOutput-Caller-owned terrain, surface, canopy and coverage rasters.

Returns

FieldTypeDescription
terrainGraphDataView<'float32'>DTM per cell; zero if unsupported.
surfaceGraphDataView<'float32'>DSM per cell.
canopyGraphDataView<'float32'>Canopy height per cell.
coverageGraphDataView<'uint32'>Support bits per cell.

Example

import {GPUPointCloudSurfaces} from '@luma-contributors/analysis/pointcloud-analysis';

// positions, classes, terrain, surface, canopy, coverage: views on graph
graph.add(new GPUPointCloudSurfaces({
  positions, classifications: classes,
  grid: {origin: [0, 0], cellSize: 1, width: 256, height: 256},
  output: {terrain, surface, canopy, coverage}
}));
