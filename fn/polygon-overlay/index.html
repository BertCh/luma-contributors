Polygon overlay

Intersects, unions, subtracts or dissolves polygon sets over a snap-rounded planar arrangement.

Reading the result

Best for clip, merge and erase workflows on parcels, zones and footprints. Edges are noded and snapped, then faces are kept by a winding rule per operand. Require both overflow and candidateOverflow to be zero before accepting geometry or provenance; candidateOverflow includes uncertifiable noding predicates.

Parameters

PropTypeDefaultDescription
left*PackedPolygons-First operand, packed polygons.
rightPackedPolygons-Second operand; omit for dissolve.
operation*GPUPolygonOverlayOperation-'intersection', 'union', 'difference', 'symmetric-difference' or 'dissolve'.
fillRuleGPUPolygonOverlayFillRule'even-odd'Inside test: 'even-odd', 'positive', 'negative' or 'nonzero'.
vertexTolerance*number-Snap-rounding tolerance in position units.
capacity*GPUPolygonOverlayCapacity-Upper bounds for intersections and noded segments.
spatialContextGPUSpatialContext-Planar or spherical frame of the left operand.
output*GPUPolygonOverlayOutput-Caller-owned views for result polygons and status.

Returns

FieldTypeDescription
geometryGPUPackedGeometryPort<GPUPolygonGeometryPort>Polygons without source IDs; complete only when both status flags are zero.
statusGPUPolygonOverlayOutput['status']Polygon count, requiredRingCount; final overflow and candidate noding loss.
boundaryGPUPolygonOverlayBoundaryPortResult boundary segments with operand ids.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPolygonOverlay} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'overlay'});
// `parcels`, `floodZone` (packed polygons) and `output` are graph views on `graph`.
graph.add(new GPUPolygonOverlay({
  left: parcels,
  right: floodZone,
  operation: 'intersection',
  vertexTolerance: 1e-4,
  capacity: {intersections: 50000, nodedSegments: 100000},
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// then read `output.status.count` and check `output.status.overflow` before using the rings
