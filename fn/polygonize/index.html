Polygonize

Turns arbitrary planar linework into bounded polygons.

Reading the result

Use it to build areas from street, boundary or cut lines. Lines are noded exactly, linked into half-edges, and every bounded face becomes a polygon.

Parameters

PropTypeDescription
lines*GPULineGeometryPortArbitrary finite planar linework.
intersectionCapacity*numberCapacity of the intersection event list.
precision*GPUTopologyPrecisionPolicyExplicit precision and vertex policy.
output*GPUPolygonizeOutputNoding, half-edge, polygon and diagnostic outputs.
groupIdsGraphDataView<"uint32"> | undefinedPolygonization group per input line.
snapRounding{ gridSize: number; lattice: GraphDataView<"float32">; } | undefinedOptional hot-pixel snap rounding.

Returns

FieldTypeDescription
nodedSegmentsGPUNodedSegmentPortNoded input segments.
directedEdgesGPUDirectedEdgePortDirected half-edges built from the noded segments.
polygonsGPUPolygonGeometryPortPolygons assembled from closed rings.
diagnosticsGPUPolygonizeDiagnosticsPortCounts of dangles, cuts and invalid rings.
statusGPUTopologyStatusPortCapacity and completeness flags.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPolygonize} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUPolygonize({
  lines: {kind: 'lines', positions, lineOffsets},
  intersectionCapacity: 4096,
  precision: {vertexTolerance: 1e-6, predicates: 'exact-or-uncertain', storage: 'float32'},
  output // nodedSegments, directedEdges, polygons, diagnostics, status
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
