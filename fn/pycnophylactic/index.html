Reading the result

Turns polygon counts into a surface without sharp zone jumps (Tobler 1979). It alternates neighbor smoothing with a mass correction until the change drops below tolerance. The result sums back to each zone total.

Parameters

PropTypeDescription
grid*GPURasterMetadataOutput raster.
zones*GraphDataView<'uint32'>Zone id per cell.
zoneCount*numberNumber of zones.
totals*GraphDataView<'float32'>Value to preserve per zone.
maximumIterations*numberIteration cap.
toleranceGraphDataView<'float32'>Convergence threshold.
kernel'rook' | 'box'Smoothing neighborhood.
output*GPUPycnophylacticOutputDestination views.

Returns

FieldTypeDescription
massGraphDataView<'float32'>Mass per cell; sums to each zone total.
densityGraphDataView<'float32'>Optional mass per unit area.
status{converged?, iterationCount?}Optional convergence info.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUPycnophylactic} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'pycno'});
// zones, totals, tolerance, outputs: graph views; grid is GPURasterMetadata
graph.add(
  new GPUPycnophylactic({
    grid,
    zones,
    zoneCount: 64,
    totals: populationByZone,
    maximumIterations: 200,
    tolerance,
    kernel: 'rook',
    output: {mass, density, status: {converged, iterationCount}}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
