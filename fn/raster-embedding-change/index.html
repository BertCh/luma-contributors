Embedding change

Year-to-year change of an embedding raster: cosine similarity, angle, change length and a mask.

0.80
0.40
drawn

Point at a pixel: its similarity between years becomes the threshold, and everything that changed as much is marked. The later year is modelled: a clearing scaled by each pixel's vegetation. Six Sentinel-2 bands stand in for a learned embedding.

Reading the result

Compare two years of embeddings pixel by pixel; a low similarity means the place changed. similarityThreshold is per-frame; pair the similarity with a false discovery rate mask for significant change only.

Parameters

PropTypeDescription
pixelCount*numberPixels of each year, row-major.
dimensions*numberVector length, 1 to 128.
before*GraphDataView<"float32">Decoded vectors of the earlier year.
after*GraphDataView<"float32">Decoded vectors of the later year.
beforeMaskGraphDataView<"uint32">QA of the earlier year; zero makes the pixel invalid.
afterMaskGraphDataView<"uint32">QA of the later year.
parametersGraphDataView<"float32">Packed `similarityThreshold`; needed with `changed`.

Returns

FieldTypeDescription
similarityGraphDataView<"float32">Cosine similarity of the two years, -1 to 1.
angleGraphDataView<"float32">Angle between the vectors in radians.
magnitudeGraphDataView<"float32">Length of the change vector `|after - before|`.
changedGraphDataView<"uint32">1 where `similarity < similarityThreshold`.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPURasterEmbeddingChange, getGPURasterEmbeddingChangeParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const pixelCount = 512 * 512; const dimensions = 64;
const values = getGPURasterEmbeddingChangeParameterValues({similarityThreshold: 0.7});
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPURasterEmbeddingChange({
  parameters: parameters.importToGraph(graph),
  pixelCount, dimensions,
  before: view('2023', 'float32', pixelCount * dimensions),
  after: view('2024', 'float32', pixelCount * dimensions),
  output: {similarity: view('similarity', 'float32', pixelCount), changed: view('changed', 'uint32', pixelCount)}
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
