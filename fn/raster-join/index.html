Reading the result

Aggregates millions of points into zones fast. Only points in boundary cells can differ from an exact join, and the output bounds that error.

Parameters

PropTypeDescription
grid*GPURasterMetadataGrid of the zone raster.
points*GraphDataView<"float32x2">Point positions.
valuesGraphDataView<"float32">Per-point values to sum.
zones*GraphDataView<"uint32">Zone raster from GPUPolygonRasterization.
boundaryGraphDataView<"uint32">Boundary-cell flags, to bound the error.
zoneCount*numberNumber of zones.
parameters*GraphDataView<"float32">Packed raster placement.
output*GPURasterJoinOutputRequested counts, sums and bounds.

Returns

FieldTypeDescription
countsGraphDataView<"uint32">Points per zone.
sumsGraphDataView<"float32">Value sums per zone (optional).
boundaryCountsGraphDataView<"uint32">Points per zone that fall in boundary cells.
pointZonesGraphDataView<"uint32">Joined zone per point (optional).

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPURasterJoin, getGPUPolygonRasterizationParameterValues, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `points`, `zones`, `boundary`: graph views; zones from GPUPolygonRasterization.
const values = getGPUPolygonRasterizationParameterValues(grid);
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPURasterJoin({
  parameters: parameters.importToGraph(graph),
  grid,
  points,
  zones,
  boundary,
  zoneCount: 64,
  output: {
    counts: view('counts', 'uint32', 64),
    boundaryCounts: view('boundary-counts', 'uint32', 64)
  }
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
