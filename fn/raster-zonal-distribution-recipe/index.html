Raster zonal distribution

Gives each zone the median, mode and quantiles of a raster band, after nodata and calibration.

Quantiles of WorldCover built-up fraction with adjustable noise in each zone.

Reporting zones are constructed for the overlay.

Reading the result

Best for elevation, canopy or temperature statistics per district. Native nodata and validity are resolved first, then scale and offset. Whole-cell and unweighted: fractional coverage does not weight the quantiles.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height and affine transform.
input*GPURasterBufferBandRaster band with native validity.
zones*GraphDataView<"uint32">Whole-cell zone ID per cell.
zoneCount*numberNumber of zones.
probabilitiesGraphDataView<"float32"> | undefinedPer-frame quantile probabilities in [0, 1].
outputsPartial<Output> | undefinedCaller-owned views to keep; every other result is a graph transient.

Example

import {addRasterZonalDistributionRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; elevationBand is a buffer-backed raster band
const distributions = addRasterZonalDistributionRecipe(graph, {
  grid,
  input: elevationBand,
  zones: zoneIds,
  zoneCount: administrativeAreaCount,
  probabilities: quantileProbabilities, // [0.1, 0.5, 0.9]
  outputs: {medians, quantiles}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
