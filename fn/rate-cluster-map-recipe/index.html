Rate cluster map

Counts and populations in, significant local Moran clusters of smoothed rates out, colored by quadrant.

Reading the result

Maps risk without small-area noise: rates are empirical-Bayes smoothed, neighbors come from polygon contiguity, and local Moran finds clusters. Add permutation for the reference 999-permutation confirmation.

  • Inspect small populations and islands; smoothing changes the rates being compared. Permutation resolution limits attainable significance.

Example

import {addRateClusterMapRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; polygons use the GeoArrow four-level layout
const clusterMap = addRateClusterMapRecipe(graph, {
  events, populations,
  polygons: {kind: 'polygons', featureOffsets, polygonOffsets, ringOffsets, positions},
  criterion: 'queen',
  neighborCapacity: 8 * featureCount,
  parameters: autocorrelationParameters, // GPUParameterBuffer<'float32'>
  permutation: {parameters: permutationParameters, maximumPermutations: 999},
  palette,
  outputs: {quadrants, colors}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
