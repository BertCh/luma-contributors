Reading the result

Outlines clusters more honestly than a convex hull. Delaunay border triangles are eroded while their edges exceed ratio, a fraction of the edge length range.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Packed planar vertex positions.
ratio*numberFraction of the Delaunay edge length range, 0 to 1.
allowHolesboolean | undefinedAllow interior erosion to start holes.
maximumIterationsnumber | undefinedMaximum triangle removals.
output*{boundaryEdges, edgeValidity}Hull edges.

Returns

FieldTypeDescription
boundaryEdgesGraphDataView<"uint32x2">Hull edges as point index pairs.
edgeValidityGraphDataView<"uint32">1 for edges that are on the hull.
trianglesGraphDataView<'uint32x3'>Retained Delaunay triangles.
triangleValidityGraphDataView<'uint32'>1 for each triangle kept in the hull.
status{converged}One row; 0 if tessellation did not finish.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURatioConcaveHull} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPURatioConcaveHull({
  positions, // float32x2 points
  ratio: 0.3,
  output // boundaryEdges, edgeValidity, ...
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
