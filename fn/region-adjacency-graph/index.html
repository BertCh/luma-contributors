Region adjacency graph

Builds four-neighbor region adjacency and merges similar regions by mean difference.

0.06

Reading the result

Turns over-segmented imagery into coherent objects. Fixed or adaptive thresholds merge neighbors in bounded rounds.

Parameters

PropTypeDescription
grid*GPURasterMetadataGrid of the label raster.
labels*GraphDataView<"uint32">Region label per pixel.
values*GraphDataView<"float32">Pixel values to average per region.
regionCount*numberNumber of regions.
mergeMode"fixed" | "adaptive"Threshold rule for merging.
mergeThreshold*numberMean-difference threshold.
maximumIterations*numberBounded merge rounds.
output*{adjacency}adjacency, weights, mapping, status.

Returns

FieldTypeDescription
adjacencyGraphDataView<"uint32">Region pairs that touch.
weightsGraphDataView<"float32">Mean difference per adjacent pair.
mappingGraphDataView<"uint32">Final merged region for each region.
status{iterationLimitReached}iterationLimitReached: 1 when a further round would change the mapping.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterRegionGraph, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `labels` (uint32) and `values` (float32) are graph views; 256 regions.
graph.add(new GPURasterRegionGraph({
  grid,
  labels,
  values,
  regionCount: 256,
  mergeMode: 'adaptive',
  mergeThreshold: 0.05,
  maximumIterations: 8,
  output: {adjacency: view('adjacency', 'uint32', 2048), weights: view('weights', 'float32', 1024), mapping: view('mapping', 'uint32', 256), status: view('status', 'uint32', 1)}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
