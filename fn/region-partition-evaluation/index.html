Reading the result

Compares candidate partitions from different methods or parameters. Lower within-region sum of squares means more homogeneous regions. Pass weights to also check that every region is connected.

Parameters

PropTypeDescription
values*GraphDataView<'float32'>Attribute columns, row-major.
labels*GraphDataView<'uint32'>Region id per place.
columnCountnumberAttribute columns per place.
labelCapacitynumberCompile-time label cap.
weightsGPUSpatialWeights | GPUChunkedSpatialWeightsContiguity graph for connectivity checks.
output*GPURegionPartitionEvaluationOutputDestination views.

Returns

FieldTypeDescription
summaryGraphDataView<'float32'>Total sum of squares, within, between, region count.
regionSizesGraphDataView<'uint32'>Places per region.
regionWithinSumOfSquaresGraphDataView<'float32'>Spread inside each region.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURegionPartitionEvaluation} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'evaluate'});
// values, labels (from any regionalization), weights, outputs: graph views
graph.add(
  new GPURegionPartitionEvaluation({
    values,
    columnCount: 3,
    labels,
    weights,
    output: {summary, regionSizes, regionWithinSumOfSquares}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
