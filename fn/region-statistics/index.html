Reading the result

Best for live brush-and-summarize interaction on huge point sets. The region is a per-frame view, so dragging never recompiles. An optional grid index avoids testing every row.

Parameters

PropTypeDescription
region*GPURegionSelectionRectangle, polygon, radius, pick or mask.
positionsGPUFloat32PositionsPoint locations.
valuesGraphDataView<'float32'>Values to summarize.
sourceIdsGPUUint32RowsIds reported for selected rows.
histogramGPURegionHistogramPropsBin count and range.
spatialIndexGPURegionStatisticsGridIndexGrid index to skip distant rows.
spatialContextGPUSpatialContextPlanar or geographic frame.
output*GPURegionStatisticsOutputDestination views.

Returns

FieldTypeDescription
summaryGraphDataView<'uint32'>Packed count, sum, mean, min, max, flags, histogram.
maskGraphDataView<'uint32'>Optional selected-row mask.
selectedRowsGPUCompactOutputOptional compacted ids.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURegionStatistics} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'brush'});
const bounds = new GPUParameterBuffer(device, {id: 'bounds', format: 'float32', length: 4});
// positions, values, sourceIds, summary, selectedRows: graph views
graph.add(new GPURegionStatistics({
  region: {kind: 'rectangle', bounds: bounds.importToGraph(graph)},
  positions, values, sourceIds,
  histogram: {binCount: 16},
  output: {summary, selectedRows}
}));
const compiled = graph.compile();
bounds.write(new Float32Array([minX, minY, maxX, maxY])); // every pointer move
compiled.encode(device.commandEncoder, {parameters: undefined});
