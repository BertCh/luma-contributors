Reading the result

Best for greening, burn or land-cover change by district. The difference is after minus before on cells valid in both; changed area uses a live threshold, and coverage is reported separately.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height and affine transform.
change*GPUChangeDetectionPropsAligned, calibrated slices; missing samples are NaN.
zones*GraphDataView<"uint32">Whole-cell zone ID per cell.
zoneCount*numberNumber of zones.
cellAreas*GraphDataView<"float32">Positive finite area per cell.
threshold*GraphDataView<"float32">One-row absolute change threshold.

Returns

FieldTypeDescription
outputs.differenceGraphDataView<"float32">After minus before, per cell.
outputs.meanChangesGraphDataView<"float32">Unweighted mean difference per zone.
outputs.validCountsGraphDataView<"uint32">Finite comparisons per zone.
outputs.coverageGraphDataView<"float32">Share of zone area compared.
contributorsGPUCommandNodeProducer<Parameters>[]Graph nodes the recipe added, in execution order.
intermediates{ grid: GPURasterMetadata; zones: GraphDataView<"uint32">; }Named stage ports; graph-owned, not for readback.
status{count, overflow}GPU status words; zero means complete.

Example

import {addRegionalRasterChangeRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; before/after slices are aligned, calibrated, NaN for missing
const change = addRegionalRasterChangeRecipe(graph, {
  grid,
  change: {slices: ndviStack, sliceCount: 2, parameters: changeParameters},
  zones: districtPerCell,
  zoneCount: districtCount,
  cellAreas,
  threshold: thresholdView // absolute change, one float32 row
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// change.outputs.meanChanges per zone, change.outputs.coverage beside it
