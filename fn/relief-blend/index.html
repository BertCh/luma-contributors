Relief blend (VAT)

Blends up to five single-band visualizations into one greyscale image.

Reading the result

Combines hillshade, sky-view, openness and local relief into the Visualization for Archaeological Topography. Each layer is stretched, optionally inverted, and blended with a mode and opacity.

Parameters

PropTypeDescription
grid*GPURasterMetadataWidth, height, cell size and origin from makeGPURasterMetadata.
layers*readonly GraphDataView<"float32">[]Up to five layers, bottom to top.
parameters*GraphDataView<"float32">Per-frame settings, packed by the matching getGPU...ParameterValues.
output*GPUReliefBlendOutputViews for blend, packed color and validity.

Returns

FieldTypeDescription
blendGraphDataView<"float32">Blended greyscale in 0..1.
colorGraphDataView<"uint32">Packed RGBA of the blend.
outputValidityGraphDataView<"uint32">Nonzero where the cell has a valid result.

Example

import {
  GPUReliefBlend,
  GPU_RELIEF_BLEND_VAT_ARCHAEOLOGICAL,
  getGPUReliefBlendParameterValues
} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
// layers: hillshade, sky-view, openness, local relief views
graph.add(new GPUReliefBlend({
  grid, layers,
  parameters: parameters.importToGraph(graph),
  output: {blend}
}));
parameters.write(getGPUReliefBlendParameterValues(
  GPU_RELIEF_BLEND_VAT_ARCHAEOLOGICAL
));
