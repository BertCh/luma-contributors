Rolling mean

Trailing rolling mean over a chunked raster stream, with window state kept between chunks.

Reading the result

Use it for the aggregation that SPI and SPEI apply before fitting, such as a 3-month total. A missing sample in the window makes that output missing. ring and seenCount are caller-owned buffers carried from chunk to chunk.

Parameters

PropTypeDescription
cellCount*numberNumber of pixels.
chunkSliceCount*numberSlices of each chunk, 1 to 256.
windowLength*numberTrailing window in slices, 2 to 128.
values*GraphDataView<"float32">Chunk, cell-major; non-finite is missing.
parameters*GraphDataView<"float32">Packed reset flag and active slice count.
ring*GraphDataView<"float32">Caller-owned last windowLength samples per pixel.
seenCount*GraphDataView<"uint32">Caller-owned samples seen so far per pixel.
maskGraphDataView<"uint32">Per-observation QA; zero makes the sample missing.

Returns

FieldTypeDescription
outputGraphDataView<"float32">Rolling mean per chunk slice; NaN until the window is full.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPURasterRollingMean, getGPURasterStreamingAccumulatorParameterValues} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'uint32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const cellCount = 256 * 256;
const chunkSliceCount = 12;
const windowLength = 3;
const values = getGPURasterStreamingAccumulatorParameterValues({reset: true, maximumValueMagnitude: 1000}, chunkSliceCount);
const parameters = new GPUParameterBuffer(device, {id: 'p', format: 'float32', length: values.length});
graph.add(new GPURasterRollingMean({
  parameters: parameters.importToGraph(graph),
  cellCount,
  chunkSliceCount,
  windowLength,
  values: view('chunk', 'float32', cellCount * chunkSliceCount),
  ring: view('ring', 'float32', cellCount * windowLength),
  seenCount: view('seen', 'uint32', cellCount),
  output: view('rolling', 'float32', cellCount * chunkSliceCount)
}));
const compiled = await graph.compileAsync();
parameters.write(values);
compiled.encode(device.commandEncoder, {parameters: undefined});
