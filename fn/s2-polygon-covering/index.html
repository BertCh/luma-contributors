S2 polygon covering

Builds an adaptive mixed-level S2 interior or exterior cover of spherical polygons.

Adaptive S2 cover: coarse cells inside, fine cells on the boundary.

Lake shorelines are sampled radially and placed in constructed geometry.

Reading the result

Indexes polygons on the sphere with the fewest cells, large inside and fine at the edge. The traversal is bounded and runs entirely on the GPU, up to level 15. Set complement to cover the outside instead.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x3">-Unit xyz ring vertices.
ringOffsets*GraphDataView<"uint32">-Vertex range per ring.
maximumLevel*number-Finest S2 level to refine to.
minimumLevelnumber0Coarsest level allowed.
mode"exterior" | "interior"'exterior'Cells touching the polygon, or inside it.
capacity*number-Maximum cells written.
complementboolean-Cover the region outside the polygon.
output*{cells, counts, status, visitedCount?}-Cells, counts and status.

Returns

FieldTypeDescription
cellsGraphDataView<"uint32x2">Mixed-level covering cells.
countsGraphDataView<"uint32x2">(written, required) cell counts.
statusGraphDataView<"uint32">Nonzero when invalid or capacity-limited.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUS2PolygonCovering} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 's2-cover'});
const positions = graph.importGPUData('positions', xyzData); // GPUData<'float32x3'>
const ringOffsets = graph.importGPUData('rings', ringData); // GPUData<'uint32'>
const cells = graph.importGPUData('cells', cellData); // GPUData<'uint32x2'>, 512 rows
const counts = graph.importGPUData('counts', countData); // GPUData<'uint32x2'>
const status = graph.importGPUData('status', statusData); // GPUData<'uint32'>

graph.add(new GPUS2PolygonCovering({
  positions, ringOffsets, maximumLevel: 12, capacity: 512, output: {cells, counts, status}
}));
const compiled = await graph.compileAsync();
