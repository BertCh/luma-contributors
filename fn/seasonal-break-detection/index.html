Seasonal break detection

Fits a trend plus seasonal harmonic per cell and finds at most one level shift.

Props
10
Sample data
1.0
0.08
drawn

A seasonal series per cell in; the strength of its level shift out.

A monthly seasonal cycle is modeled from observed pre- and post-fire vegetation levels.

Reading the result

Use it to date disturbances such as clearing, fire or flooding in a long time series. A BIC gain test decides whether a break is real; monitoring can flag new observations.

Parameters

PropTypeDescription
cellCount*numberNumber of cells.
sliceCount*numberObservations per cell.
values*GraphDataView<"float32">Series per cell, cell-major.
maskGraphDataView<"uint32">Per-observation validity flags.
period*numberSeasonal period in slices.
minimumSegmentLength*numberFewest observations on each side.
minimumBICGainnumberRequired BIC improvement for a break.
seasonality"harmonic" | "dummy"Seasonal model.

Returns

FieldTypeDescription
breakIndexGraphDataView<"uint32">Slice of the detected break per cell.
improvementGraphDataView<"float32">BIC improvement from adding the break.
coefficientsGraphDataView<"float32">Fitted coefficients per cell.
componentsGraphDataView<"float32">Model components per cell.
statusGraphDataView<"uint32">0 fit, 1 insufficient support, 2 rank failure.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterSeasonalBreak} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const cellCount = 256 * 256;
const sliceCount = 120; // monthly observations
graph.add(new GPURasterSeasonalBreak({
  cellCount,
  sliceCount,
  values: view('series', 'float32', cellCount * sliceCount),
  period: 12,
  minimumSegmentLength: 12,
  output // coefficients, components, breakIndex, improvement, status
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
