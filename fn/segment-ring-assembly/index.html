Reading the result

The last step of overlays, dissolves and cell outlines, where you end up with unordered edges. Endpoints are matched within a tolerance and walked into rings. Optional outputs give winding, area and hole ownership.

Parameters

PropTypeDescription
endpoints*GraphDataView<'float32x4'>Directed segments as (x0, y0, x1, y1).
countGraphDataView<'uint32'>One-row count of live segments.
groupsGraphDataView<'uint32'>Group id per segment; rings never cross groups.
vertexTolerancenumberEndpoint matching tolerance.
cancelOpposingSegmentsbooleanDrop segment pairs that run in opposite directions.
normalizeWindingbooleanRewind rings to a canonical orientation.
splitTouchingRingsbooleanSplit rings that touch at a single vertex.
output*GPUSegmentRingAssemblyOutputCaller-owned ring views and status.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x2'>Ring vertices; each ring repeats its first vertex.
ringOffsetsGraphDataView<'uint32'>Vertex range of every ring.
ringIsHoleGraphDataView<'uint32'>Optional hole flag per ring.
statusGPUCardinalityPort & GPUOverflowStatusPort & {openSegmentCount?}Ring count, overflow and open segment count.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSegmentRingAssembly} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'rings'});
// `edges` (float32x4 segments), `segmentCount` and `output` are graph views on `graph`.
graph.add(new GPUSegmentRingAssembly({
  endpoints: edges,
  count: segmentCount,
  vertexTolerance: 1e-6,
  cancelOpposingSegments: true,
  normalizeWinding: true,
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
