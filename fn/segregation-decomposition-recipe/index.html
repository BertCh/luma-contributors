Reading the result

Tests whether segregation changed because the population mix changed or because people moved. Supply four common-support tables: baseline, composition-only, spatial-only and final. Each row holds a focal and a complement count.

Parameters

PropTypeDescription
populations*readonly GraphDataView<"float32x2">[]Four tables: baseline, composition-only, spatial-only, final.
supportId*stringNames the shared boundary support.
counterfactualMethod*stringRecords how the counterfactuals were made.
randomization{replicates, seed, swaps?} | undefinedPaired label-exchange inference.
idstring | undefinedPrefix for every node and transient ID; set it when composing recipes.

Returns

FieldTypeDescription
outputs.indicesGraphDataView<"float32">Dissimilarity of each of the four tables.
outputs.decompositionGraphDataView<"float32">Composition and spatial shares of the change.
outputs.validityGraphDataView<"uint32">Validity flags per input.
randomization{seed, permutations}Randomization distribution and inference.
provenance{seed, permutations}Stage ports that show how the result was built.

Example

import {addSegregationDecompositionRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; each table is float32x2 [focal, complement] per unit
const decomposition = addSegregationDecompositionRecipe(graph, {
  populations: [baseline, compositionOnly, spatialOnly, final],
  supportId: 'tracts-2010',
  counterfactualMethod: 'composition'
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// decomposition.outputs.decomposition: how much of the change is mix versus place
