Reading the result

Best for radius rings, coverage wedges and error ellipses (turf circle, sector, ellipse). Each feature has its own radius, bearings and rotation. Segment count and radius scale are per-frame parameters.

Parameters

PropTypeDescription
shape*GPUShapeType'circle', 'sector' or 'ellipse'.
centers*GraphDataView<'float32x2'>Center of every shape.
radii*GraphDataView<'float32'> | GraphDataView<'float32x2'>Radius, or x and y radii for ellipses.
bearingsGraphDataView<'float32x2'>Start and end bearing for sectors.
rotationsGraphDataView<'float32'>Ellipse rotation per feature.
maximumSegmentsnumberCap on segments per shape.
parameters*GraphDataView<'float32'>Packed segment count and radius scale.
output*GPUShapeGeneratorOutputCaller-owned ring views.

Returns

FieldTypeDescription
positionsGraphDataView<'float32x2'>Ring vertices of every shape.
offsetsGraphDataView<'uint32'>Vertex range of every shape.
vertexCountGraphDataView<'uint32'> | undefinedOptional one-row total vertex count.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUShapeGenerator, getGPUShapeGeneratorParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'shapes'});
const parameters = new GPUParameterBuffer(device, {id: 'shape-parameters', format: 'float32', length: 2});
// `centers`, `radii` and `output` are graph views imported on `graph`.
graph.add(new GPUShapeGenerator({
  shape: 'circle',
  centers,
  radii,
  maximumSegments: 64,
  parameters: parameters.importToGraph(graph),
  output
}));
const compiled = await graph.compileAsync();
parameters.write(getGPUShapeGeneratorParameterValues({segmentCount: 48}));
compiled.encode(device.commandEncoder, {parameters: undefined});
