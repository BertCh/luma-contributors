Shared paths

Finds the stretches that two sets of lines have in common.

5 vertices
0.050

Stretches shared exactly by two line sets, one color per shared run.

River reaches are resampled and rotated into local comparison panels.

Reading the result

Finds shared walls between buildings, duplicate road geometry or overlapping routes (Shapely shared_paths). Each run reports both source lines and its direction on each. Results feed adjacency analyses.

Parameters

PropTypeDescription
left*GPULineGeometryPortFirst packed line set.
right*GPULineGeometryPortSecond packed line set.
intersectionCapacity*numberUpper bound on found intersections.
spatialSortbooleanSort segments spatially; speeds large inputs.
leafCapacitynumberSegments per BVH leaf.
output*GPUSharedPathsOutputCaller-owned run views and status.

Returns

FieldTypeDescription
runsGPUSharedPathsRunsShared runs with source lines on both sides.
status{count}Run count, overflow and required counts.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSharedPaths} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'shared-paths'});
// `wallsA`, `wallsB` (packed line ports) and `output` are graph views on `graph`.
graph.add(new GPUSharedPaths({
  left: wallsA,
  right: wallsB,
  intersectionCapacity: 20000,
  output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// `output.runs` lists each shared stretch; `output.status.count` says how many
