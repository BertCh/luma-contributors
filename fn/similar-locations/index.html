Reading the result

Best for site selection and "find places like this one". Attributes are standardized, then ranked by weighted Euclidean distance to the reference rows.

Parameters

PropTypeDescription
values*GraphDataView<"float32">Row-major rows x columnCount attributes.
columnCount*numberNumber of attributes per row.
referenceMask*GraphDataView<"uint32">Nonzero marks the reference rows.
parameters*GraphDataView<"float32">Result count, direction and attribute weights.
standardizationGPUSimilarLocationsStandardization | undefined'zscore' or 'rank'.
resultCapacitynumber | undefinedCompile-time size of topIds.
maskGraphDataView<"uint32"> | undefinedNonzero rows take part in the analysis.
output*GPUSimilarLocationsOutputRanks, distances and top ids.

Returns

FieldTypeDescription
ranksGraphDataView<"uint32">Similarity rank per row; 0 is most similar.
distancesGraphDataView<"float32">Weighted distance to the reference.
topIdsGraphDataView<"uint32">Row ids of the best matches in rank order.
statusPick<GPUCardinalityPort, "count">count is the number of valid topIds.

Example

import {GPUSimilarLocations, getGPUSimilarLocationsParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const values = getGPUSimilarLocationsParameterValues({resultCount: 10}, 4);
const parameters = new GPUParameterBuffer(device, {
  id: 'similar', format: 'float32', length: values.length, values
});
graph.add(new GPUSimilarLocations({
  values: attributes, columnCount: 4, referenceMask,
  parameters: parameters.importToGraph(graph), resultCapacity: 10,
  output: {ranks, distances, topIds, status: {count}}
}));
