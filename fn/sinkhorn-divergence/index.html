Sinkhorn divergence

Measures how far mass must move between two grid fields, as a debiased transport cost.

12 cell²

Honshu earthquake counts per cell and the same field moved by the pointer. Upper bars: plain difference (total variation) and sqrt(S) in cells (of 16); lower bars: OT(a,b), OT(a,a), OT(b,b), S. Mass moved off the grid is dropped and the target renormalized, and total mass is ignored.

Reading the result

Use it to compare density maps or a forecast and an observation without the double penalty of cell by cell error. It is zero for equal fields and grows with distance, in squared position units.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Only its width and height are used.
source*GraphDataView<"float32">-Source masses in raster row order.
target*GraphDataView<"float32">-Target masses in raster row order.
parameters*GraphDataView<"float32">-Per-frame cell size, epsilon and tolerance.
maximumIterationsnumber100Unrolled Sinkhorn iterations, at most 1000.
blurRadiusnumber-Radius in cells of each 1D blur window.
output*GPUSinkhornDivergenceOutput-Divergence and optional components and status.

Returns

FieldTypeDescription
divergenceGraphDataView<"float32">The debiased divergence S.
componentsGraphDataView<"float32">Optional OT(a, b), OT(a, a) and OT(b, b).
marginalErrorGraphDataView<"float32">Optional L1 marginal error of the last iteration.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {
  getGPUSinkhornDivergenceParameterValues,
  GPUSinkhornDivergence
} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'sinkhorn'});
graph.add(
  new GPUSinkhornDivergence({
    grid: makeGPURasterMetadata({width: 32, height: 18}),
    source, target, parameters, // masses per cell; parameters has 6 values
    maximumIterations: 40,
    output: {divergence, components}
  })
);
parametersBuffer.write(
  getGPUSinkhornDivergenceParameterValues({cellWidth: 1, cellHeight: 1, epsilon: 12})
);
