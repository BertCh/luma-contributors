Partitions places into contiguous, homogeneous regions by cutting a spanning tree.

Reading the result

Builds regions that stay connected and similar inside. It repeatedly cuts the tree edge that most reduces within-region variance until regionCount is reached. A minimum region size guards against slivers.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsContiguity graph.
treeEdgeFlags*GraphDataView<'uint32'>Tree edges from the spanning tree step.
componentLabels*GraphDataView<'uint32'>Components from the spanning tree step.
values*GraphDataView<'float32'>Attribute columns, row-major.
maximumRegionCount*numberCompile-time region cap.
parameters*GraphDataView<'uint32'>regionCount and minimumRegionSize.
columnCountnumberAttribute columns per place.
output*GPUSkaterRegionsOutputDestination views.

Returns

FieldTypeDescription
labelsGraphDataView<'uint32'>Region id per place.
regionCountGraphDataView<'uint32'>Regions produced.
cutEdgesGraphDataView<'uint32'>Tree edges cut, in order.
cutGainsGraphDataView<'float32'>Variance reduction of each cut.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSkaterRegions, getGPUSkaterRegionsParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'skater'});
const settings = {regionCount: 8, minimumRegionSize: 5};
const parameters = new GPUParameterBuffer(device, {
  id: 'skater-parameters', format: 'uint32', length: 2,
  values: getGPUSkaterRegionsParameterValues(settings)
});
// weights, tree flags, components, values, outputs: graph views
graph.add(new GPUSkaterRegions({
  weights, treeEdgeFlags, componentLabels, values, columnCount: 3,
  maximumRegionCount: 8, parameters: parameters.importToGraph(graph),
  output: {labels, regionCount, cutEdges, cutGains}
}));
graph.compile().encode(device.commandEncoder, {parameters: undefined});
