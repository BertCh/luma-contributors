Skeleton

Thins a binary mask to a one-pixel centerline with Zhang-Suen thinning.

Props
40
Sample data
0.40
drawn

A binary shape in; its one-pixel skeleton out.

The scenario includes a generated spatial field.

Reading the result

Extracts road, river or crack centerlines from a mask. Iteration is bounded, and status.converged tells you whether it finished.

Parameters

PropTypeDescription
grid*GPURasterMetadataGrid of the mask.
input*GraphDataView<"uint32">Binary mask; nonzero is foreground.
maximumIterationsnumberBounded number of thinning rounds.
output*{skeleton}skeleton and a converged status.

Returns

FieldTypeDescription
skeletonGraphDataView<"uint32">One-pixel-wide centerline mask.
status.convergedGraphDataView<"uint32">1 when thinning reached a fixpoint.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterSkeleton, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
// `mask` is a uint32 graph view, one row per pixel.
graph.add(new GPURasterSkeleton({
  grid,
  input: mask,
  maximumIterations: 64,
  output: {skeleton: view('skeleton', 'uint32', 512 * 512), status: {converged: view('converged', 'uint32', 1)}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
