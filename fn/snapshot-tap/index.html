Reading the result

Watches a value evolve across iterations, such as a residual. Place it after a node, give it views, and each encoding adds one frame to the arena.

Parameters

PropTypeDefaultDescription
id*string-Node id; also the default frame label.
arena*GPUSnapshotArena-Arena receiving one frame per encoding.
views*Readonly<Record<string, GraphDataView | GraphBufferHandle>>-Views/buffers keyed by arena slots; slots in range and offsets 4-byte aligned.
afterNodestring-Node the observation follows.
labelstring-Frame description.
iterationnumberframe indexFrame iteration coordinate.
recorderGPUComputationRecorder-Records the tap in a computation record.

Returns

FieldTypeDescription
frameGPUSnapshotFrameOne frame per encoding, in the arena.

Example

import {GPUSnapshotArena, GPUSnapshotTap} from '@luma-contributors/analysis/computation-record';

// arena: GPUSnapshotArena; residualView: view on graph
graph.add(new GPUSnapshotTap({
  id: 'tap-residual',
  arena,
  views: {residual: residualView},
  afterNode: 'relax',
  label: 'residual after relax',
  recorder
}));
