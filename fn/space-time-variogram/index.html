Space-Time Variogram

Semivariance across both spatial and temporal lags of timestamped point values.

0.40
12 h
drawn

Semivariance per distance (rows, near at top) and time lag (columns), on a range of twice the field variance (the first row and column are the exact zero lags); the inset is the flash map.

Reading the result

Checks whether similarity decays with distance and with time before space-time kriging. Output is a spatial by temporal lag grid.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Packed float32x2 point positions.
values*GraphDataView<'float32'>Observed value per row.
times*GraphDataView<'float32'>Observation time per row.
maskGraphDataView<'uint32'>Nonzero rows take part.
parameters*GraphDataView<'float32'>[maximumDistance, maximumTimeLag], positive and finite.
lagCount*numberSpatial lag bins.
temporalLagCount*numberTemporal lag bins.
and 1 more required: gridSize

Returns

FieldTypeDescription
semivariancesGraphDataView<'float32'>Semivariance per spatial and temporal lag.
pairCountsGraphDataView<'uint32'>Pairs per spatial and temporal lag.
statusGraphDataView<'uint32'>Per lag: 0 valid, 1 empty, 2 nonfinite.

Example

import {GPUSpaceTimeVariogram} from '@luma-contributors/analysis/dataframe-analysis';

// positions, values, times, parameters, semivariances, pairCounts, status: views on graph
graph.add(new GPUSpaceTimeVariogram({
  positions, values, times, parameters,
  lagCount: 16, temporalLagCount: 8,
  output: {semivariances, pairCounts, status}
}));
