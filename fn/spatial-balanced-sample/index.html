Spatially balanced sample

Selects units from a finite frame so the sample is spread across space within each stratum.

60
100
5
drawn

Selected units (dark or white) are evenly spread inside each stratum; each stratum is sampled at its own rate.

Reading the result

Samples parcels, plots or addresses with an even footprint. Allocations set the sample size per stratum, and inclusion probabilities are returned for design-based estimates. A seed and replicate index make draws reproducible.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Frame unit locations.
frameIds*GraphDataView<'uint32'>-Stable id per frame unit.
allocations*readonly GPUSpatialSampleAllocation[]-Sample count per stratum.
bounds*readonly [number, number, number, number]-Extent used for spatial ordering.
seed*number-Random seed.
strataGraphDataView<'uint32'>-Stratum id per unit.
replicatenumber0Independent replicate index.
output*{frameIds}-Destination views.

Returns

FieldTypeDescription
frameIdsGraphDataView<'uint32'>Selected unit ids.
inclusionProbabilitiesGraphDataView<'float32'>Chance each unit was selected.
designWeightsGraphDataView<'float32'>Inverse inclusion probability.
statusGraphDataView<'uint32'>Selection status.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialBalancedSample} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'balanced-sample'});
// positions, frameIds, strata, outputs: graph views
graph.add(
  new GPUSpatialBalancedSample({
    positions,
    frameIds,
    strata,
    allocations: [
      {stratumId: 0, sampleCount: 30},
      {stratumId: 1, sampleCount: 20}
    ],
    bounds: [x0, y0, x1, y1],
    seed: 5,
    output: {frameIds: selected, inclusionProbabilities, designWeights, status}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
