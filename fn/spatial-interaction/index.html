Reading the result

Use it to predict flows between places and see which origins or destinations are over or under-served. Production, attraction or both constraints are balanced on the GPU while the distance decay is calibrated.

Parameters

PropTypeDefaultDescription
origins*GraphDataView<"uint32">-Origin index per flow pair.
destinations*GraphDataView<"uint32">-Destination index per flow pair.
flows*GraphDataView<"float32">-Observed flow per pair.
covariate*GraphDataView<"float32">-Distance or cost per pair.
constraint*"unconstrained" | "origin" | "destination" | "doubly"-Which margins the model preserves.
coefficients*readonly number[]-Candidate distance-decay coefficients.
calibration"grid" | "bounded" | undefined'grid'Search the candidates or a bounded interval.
output*{predictions, summary}-Predictions, summary, status and candidate scores.
and 2 more required: originCount, destinationCount

Returns

FieldTypeDescription
predictionsGraphDataView<"float32">Modeled flow per pair.
summaryGraphDataView<"float32">Selected coefficient, deviance and balance error.
statusGraphDataView<"uint32">0 converged; 1 no mass; 2 invalid input; 3 no candidate.
candidatesGraphDataView<"float32">Per candidate: deviance, marginal error, iterations, code.
originResidualsGraphDataView<"float32">Residual per origin.

Example

import {GPUSpatialInteraction} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph, weights and views are set up as in the Local Moran example
graph.add(new GPUSpatialInteraction({
  origins, destinations, originCount: 120, destinationCount: 120,
  flows, covariate: distances,
  constraint: 'doubly',
  coefficients: [0.5, 1, 1.5, 2],
  output: {predictions, summary, status, candidates}
}));
