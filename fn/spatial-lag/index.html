Spatial lag

Replaces each value with the weighted sum of its neighbors, the building block of spatial models.

Reading the result

The lag is sum_j w_ij y_j (PySAL lag_spatial). With row-standardized weights it is the neighbor average, which smooths local extremes. Lag several columns at once with columnCount.

Parameters

PropTypeDefaultDescription
values*GPUFloat32OrUint32Values-Per-source values, row-major.
weights*GPUSpatialWeights | GPUChunkedSpatialWeights-Weights whose neighbor ids index values.
output*GraphDataView<'float32'>-Lag output, rows * columnCount.
columnCountnumber | undefined1Value columns lagged at once.
normalizeboolean | undefined-Divide by the included weight sum.
maskGraphDataView<'uint32'> | undefined-Zero rows output 0 and are skipped.

Returns

FieldTypeDescription
outputGraphDataView<'float32'>Lag per row, rows * columnCount.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialLag} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialLag({
    weights, // row-standardized
    values: graph.importGPUData('poverty', povertyData),
    output: output('lag', 'float32', rowCount)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
