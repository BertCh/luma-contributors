Spatial panel regression

Pooled spatial-lag 2SLS on a balanced panel, with optional unit effects.

Panel 2SLS: estimates (bars) against the true coefficients (dots).

Panel periods and responses are simulated from tract covariates. Responses are simulated from tract covariates and specified coefficients.

Reading the result

Best for places observed repeatedly over time. Weights are time-invariant across the entity axis; rows are period-major. unit effects absorb a separate intercept per entity.

Parameters

PropTypeDefaultDescription
weights*GPUSpatialWeights-Time-invariant weights over entities.
periodCount*number-Periods in the balanced panel.
predictors*GraphDataView<'float32'>-Rows are period * entityCount + entity.
predictorCount*number-Predictor columns.
response*GraphDataView<'float32'>-Response, same row order.
effects'pooled' | 'unit' | undefined'pooled'Unit effects absorb entity intercepts.
instrumentOrder2 | 1 | undefined-Order of the lagged instruments.
output*GPUSpatialTwoStageLeastSquaresOutput-Caller-owned outputs.

Returns

FieldTypeDescription
tableGraphDataView<'float32'>Per coefficient: estimate, SE, z, p; rho last.
summaryGraphDataView<'float32'>Fit statistics.
status.codeGraphDataView<'uint32'>Solver code; 0 on success.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialPanelRegression} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
const predictors = graph.importGPUData<'float32'>('predictors', predictorData); // row-major, no intercept
const response = graph.importGPUData<'float32'>('response', responseData);
graph.add(
  new GPUSpatialPanelRegression({
    weights, // entity weights, not panel-sized
    periodCount: 10,
    effects: 'unit',
    predictors, response, predictorCount: 2,
    output: {
      table: output('table', 'float32', 16),
      summary: output('summary', 'float32', 16),
      status: {code: output('status', 'uint32', 1)}
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
