Tests OLS residuals for spatial lag and error dependence, including robust LM tests.

Reading the result

Run after OLS to decide between lag and error models. Computes LM-lag, LM-error, their robust versions, SARMA and Moran's I of residuals, as spreg does. Pass the OLS residuals and the same mask.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsSquare weights over the regression rows.
predictors*GraphDataView<'float32'>Predictors used in the OLS fit.
response*GraphDataView<'float32'>Response used in the OLS fit.
residuals*GraphDataView<'float32'>Residuals of the OLS fit.
predictorCount*numberPredictor columns, 1 to 15.
maskGraphDataView<'uint32'> | undefinedSame mask as the OLS fit.
restandardizeRowsboolean | undefinedRe-standardize rows after masking.
output*GPUSpatialRegressionDiagnosticsOutputCaller-owned outputs.

Returns

FieldTypeDescription
testsGraphDataView<'float32'>Six tests: statistic, degrees of freedom, p-value.
summaryGraphDataView<'float32'>n, sigma squared, traces, S0, Moran's I.
status.codeGraphDataView<'uint32'>Diagnostics status code.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialRegressionDiagnostics} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialRegressionDiagnostics({
    weights, predictors, response,
    residuals, // from GPUOrdinaryLeastSquares
    predictorCount: 2,
    restandardizeRows: true,
    output: {
      tests: output('tests', 'float32', 18),
      summary: output('summary', 'float32', 13),
      status: {code: output('status', 'uint32', 1)}
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
