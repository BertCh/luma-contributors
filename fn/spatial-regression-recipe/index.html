Local fit quality of a modeled response on Chicago census tracts, by kernel bandwidth.

Observed poverty and age 65+ shares are predictors. The response and spatial error dependence are modeled.

Reading the result

Fits a model and learn whether space still matters in its residuals. It runs OLS, spatial diagnostics, Anselin's decision rule and a residual local Moran; local fits (GWR) are optional. Change settings per frame without rebuilding.

  • Inspect residual dependence and model diagnostics. Association does not establish causation.

Example

import {addSpatialRegressionRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; predictors are row-major, weights are square CSR
const regression = addSpatialRegressionRecipe(graph, {
  predictors, response, predictorCount: 3,
  weights,
  parameters: autocorrelationParameters, // GPUParameterBuffer, filled from settings
  settings: {significanceLevel: 0.05}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// regression.specification.decision: which model the diagnostics point to
