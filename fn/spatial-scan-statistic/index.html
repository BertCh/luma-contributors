Reading the result

Best for disease or crime surveillance with a population baseline. It scans circular windows or cylinders for the highest likelihood ratio and tests each by Monte Carlo replicates.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Planar point coordinates, one float32x2 per point.
cases*GraphDataView<"uint32">-Case count per zone.
baselineGraphDataView<"float32"> | undefined-Expected population or at-risk baseline per zone.
modelGPUSpatialScanModel | undefined'poisson''poisson', 'bernoulli' or 'space-time-permutation'.
timeBucketsnumber | undefined-Time slices; more than 1 scans cylinders.
maximumPermutations*number-Compile-time cap on Monte Carlo replicates.
parameters*GraphDataView<"uint32">-Seed, replicate count and window limits.
output*GPUSpatialScanStatisticOutput-Cluster indices and statistics.

Returns

FieldTypeDescription
clusterStatisticsGraphDataView<"float32">Log likelihood ratio, relative risk and p-value per cluster.
clusterIndicesGraphDataView<"uint32">Zones and time range of each cluster.
statisticsGraphDataView<"float32">Observed statistic then one per permutation.
summaryGraphDataView<"uint32">Cluster count and status.

Example

import {GPUSpatialScanStatistic, getGPUSpatialScanStatisticParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const values = getGPUSpatialScanStatisticParameterValues({seed: 7, permutationCount: 999});
const parameters = new GPUParameterBuffer(device, {
  id: 'scan', format: 'uint32', length: values.length, values
});
// positions: zone centroids; cases and baseline: per-zone columns
graph.add(new GPUSpatialScanStatistic({
  positions, cases, baseline, model: 'poisson',
  maximumPermutations: 999,
  parameters: parameters.importToGraph(graph),
  output: {clusterIndices, clusterStatistics, statistics, summary}
}));
