Reading the result

Build the neighborhood you want from the ones you have, such as queen union kNN, or neighbors of neighbors. Mirrors PySAL w_union, higher_order, w_subset and block_weights. Output is a fresh CSR.

Parameters

PropTypeDescription
operation*'intersection' | 'union' | 'difference' | 'symmetricDifference' | 'higherOrder' | 'selfWeight' | 'subgraph' | 'block'What to compute.
output*GPUSpatialWeightsOutputDestination CSR with capacity and overflow flag.
leftGPUSpatialWeightsLeft operand of a set operation.
rightGPUSpatialWeightsRight operand, same row count.
weightRuleGPUSpatialWeightsCombineRule | undefinedHow to weight shared neighbors.
weightsGPUSpatialWeightsBase weights for higher order, self, subgraph.
ordernumberStep count of a higher-order operation.
cumulativeboolean | undefinedInclude all lower orders too.

status.requiredCountGraphDataView<'uint32'>Slots the result needs.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialWeightsAlgebra} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialWeightsAlgebra({
    operation: 'union',
    left: queen,
    right: knn,
    weightRule: 'binary',
    output: csr(featureCount, 12 * featureCount)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
