Reading the result

The first step of SKATER regionalization. Edges join neighbors and cost their attribute distance; the tree keeps the cheapest connected set. Disconnected islands get separate component labels.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsContiguity graph.
values*GraphDataView<'float32'>Attribute columns, row-major.
columnCountnumberAttribute columns per place.
standardizebooleanZ-score columns first.
output*GPUSpatialWeightsMinimumSpanningTreeOutputDestination views.

Returns

FieldTypeDescription
treeEdgeFlagsGraphDataView<'uint32'>1 for edges kept in the tree.
componentLabelsGraphDataView<'uint32'>Connected component per place.
edgeDissimilaritiesGraphDataView<'float32'>Optional cost of each tree edge.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialWeightsMinimumSpanningTree} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'mst'});
// weights: contiguity from GPUContiguityWeights; values, outputs: graph views
graph.add(
  new GPUSpatialWeightsMinimumSpanningTree({
    weights,
    values,
    columnCount: 3,
    standardize: true,
    output: {treeEdgeFlags, componentLabels}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
