Reading the result

The ingredients of spatial-lag log-determinants and impacts. exact runs one unit probe per row; stochastic uses Hutchinson probes for large matrices. Values are scaled by the infinity norm.

Parameters

PropTypeDescription
weights*GPUSpatialWeights | GPUChunkedSpatialWeightsSquare weights W.
maximumPower*numberHighest power Q, 1 to 256.
modeGPUSpatialWeightsTracesMode | undefined'exact' or 'stochastic'.
probeCountnumber | undefinedProbes of the stochastic mode.
includeGramTracesboolean | undefinedAlso compute gramTraces.
output*GPUSpatialWeightsTracesOutputCaller-owned trace outputs.

Returns

FieldTypeDescription
powerTracesGraphDataView<'float32'>tr((W/s)^q) at index q - 1.
powerSumsGraphDataView<'float32'>1'(W/s)^q 1 at index q - 1.
infinityNormGraphDataView<'float32'> | undefinedScale s, the largest absolute row sum.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialWeightsTraces} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialWeightsTraces({
    weights,
    maximumPower: 30,
    output: {
      powerTraces: output('traces', 'float32', 30),
      powerSums: output('sums', 'float32', 30),
      infinityNorm: output('norm', 'float32', 1)
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
