Reading the result

Do this once after building weights and before any statistic. row makes each row sum to 1; kernel applies a distance profile at a bandwidth, fixed or adaptive. Results carry the transform state, so consumers know what they got.

Parameters

PropTypeDefaultDescription
operation*GPUSpatialWeightsTransformOperation-row, binary, kernel, symmetrize, double or variance.
weights*GPUSpatialWeights-Weights to transform.
outputGraphDataView<'float32'> | undefined-Destination for the new weights, one per slot.
kernelGPUSpatialWeightsKernel | undefined-Kernel profile for the kernel operation.
bandwidthnumber | 'adaptive' | undefined-Bandwidth of the kernel operation.
doubleSum'one' | 'rows' | undefined'one'Total of the double transform.
spatialContextGPUSpatialContext | undefined-Context of a numeric bandwidth.

Returns

FieldTypeDescription
weightsGraphDataView<'float32'>Transformed weights, same pattern as the input.
outputWeightsGPUSpatialWeightsInput CSR with the new weights and transform state.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialWeightsTransform} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialWeightsTransform({
    operation: 'row',
    weights, // from GPUContiguityWeights
    output: output('row-weights', 'float32', slotCount)
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
