Weights transpose

Flips who points at whom: the sparse transpose of a weights matrix.

Reading the result

Derives incoming links from outgoing ones, or tests symmetry. Works for square and rectangular weights; output rows are sorted. An optional count tells how many slots are asymmetric.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsWeights W to transpose.
output*GPUSpatialWeightsTransposeOutputCaller-owned CSR of the transpose.
columnCountnumber | undefinedColumns of W (rows of the result).
symmetryTolerancenumber | undefinedAbsolute tolerance of the symmetry check.

Returns

FieldTypeDescription
offsetsGraphDataView<'uint32'>CSR row offsets, columnCount + 1.
neighborsGraphDataView<'uint32'>Source rows now acting as neighbors.
weightsGraphDataView<'float32'>Transposed weights.
asymmetricSlotsGraphDataView<'uint32'> | undefined0 when W equals its transpose.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSpatialWeightsTranspose} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// output(id, format, length) and csr(rows, capacity): caller-owned storage views
graph.add(
  new GPUSpatialWeightsTranspose({
    weights, // row-standardized W
    output: {
      ...csr(rowCount, slotCount),
      asymmetricSlots: output('asymmetric', 'uint32', 1)
    }
  })
);
const encoder = device.createCommandEncoder();
(await graph.compileAsync()).encode(encoder, {parameters: undefined});
device.submit(encoder.finish());
