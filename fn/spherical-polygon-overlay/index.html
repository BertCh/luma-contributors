Reading the result

Combines regions with holes on the globe. Operands are projected into a hemisphere chart around chartCenter, so keep both inside it. Capacity is bounded and overflow is reported, not hidden.

Parameters

PropTypeDescription
left*GPUSphericalPolygonOperandFirst operand: xyz positions plus offsets.
right*GPUSphericalPolygonOperandSecond operand.
operation*"intersection" | "union" | "difference" | "symmetric-difference"Boolean operation.
chartCenter*readonly [number, number, number]Unit xyz center of the hemisphere chart.
vertexTolerance*numberVertex merge distance.
capacity*GPUPolygonOverlayCapacityBounds for intersections and output sizes.
leftComplementbooleanUse the outside of the left operand.
output*GPUSphericalPolygonOverlayOutputGeometry views and complement flags.

Returns

FieldTypeDescription
geometryRecord<string, GraphDataView>Result positions (xyz) and ring, polygon offsets.
complementGraphDataView<"uint32">1 when a result is the complement region.
boundaryRecord<string, GraphDataView>Boundary edges, operand and source ids, and status.
status{count, overflow}Overflow and uncertainty flags.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSphericalPolygonOverlay} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'spherical-overlay'});
// Operands: {positions (xyz), ringOffsets, polygonOffsets, ...} views on this graph.
const {left, right, capacity, output} = overlayViews;

graph.add(new GPUSphericalPolygonOverlay({
  left, right, operation: 'intersection',
  chartCenter: [0, 1, 0], vertexTolerance: 1e-5,
  capacity, output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
