Evenly spaced streamlines

Draws evenly spaced streamlines through a 2D vector field, independent of GPU thread order.

Reading the result

Shows wind, currents or flow direction as a clean line map. Jobard-Lefer seeding prunes crowded lines, so the same field always gives the same lines.

Parameters

PropTypeDescription
velocities*GraphDataView<"float32x2">Row-major (u, v) vector field, fieldWidth x fieldHeight rows.
fieldWidth*numberVector field width in cells; fieldHeight is the height.
gridWidth*numberOutput grid width; gridHeight is the height.
seedColumns*numberSeed lattice columns; seedRows is the row count.
stepsPerDirection*numberIntegration steps each way from a seed.
parameters*GraphDataView<"float32">Extents and step length from getGPUStreamlinesParameterValues.
uint32Parameters*GraphDataView<"uint32">Per-frame counts from getGPUStreamlinesUint32ParameterValues.
output*GPUStreamlinesOutputCaller-owned line and position views.
and 3 more required: fieldHeight, gridHeight, seedRows

Returns

FieldTypeDescription
linesGPUCompactOutputSeed index of each published line, with a count.
lineOffsetsGraphDataView<"uint32">CSR offsets of each line into positions.
positionsGraphDataView<"float32x2">Polyline points, backward end to forward end.
positionCountGraphDataView<"uint32">One-row count of published positions.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUStreamlines, getGPUStreamlinesParameterValues, getGPUStreamlinesUint32ParameterValues}
  from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'streamlines'});
// parameters and uint32Parameters: GPUParameterBuffer views imported into graph
graph.add(new GPUStreamlines({
  velocities, fieldWidth: 128, fieldHeight: 128, gridWidth: 256, gridHeight: 256,
  seedColumns: 32, seedRows: 32, stepsPerDirection: 64,
  parameters, uint32Parameters,
  output: {lines, lineOffsets, positions, positionCount}
}));
const compiled = await graph.compileAsync();
// then write both packers with fieldExtent, gridExtent and stepLength, and encode
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
