Street profiles

Measures distance and height of the first building on each side of every street sample.

Reading the result

Best for canyon width, height-to-width ratio and frontage studies. Rays cast left and right of each sample along its normal. A side with no building stays range-censored and is never reported as open space.

Parameters

PropTypeDescription
positions*GraphDataView<'float32x2'>Street sample points.
normals*GraphDataView<'float32x2'>Unit normal at every sample.
segments*GraphDataView<'float32x4'>Facade segments as (x0, y0, x1, y1).
segmentBuildingIds*GraphDataView<'uint32'>Building id of every facade segment.
buildingHeights*GraphDataView<'float32'>Height of every building.
maximumDistance*numberLongest ray length.
sampleSpacing*numberSpacing used for frontage sampling.
streetSegmentGraphDataView<'float32x4'>Optional street segment per sample.

Returns

FieldTypeDescription
outputs{profiles, buildings, canyon, validity}Side distances, building ids, canyon measures and validity.
facades{lengths, frontage}Facade lengths and frontage per sample.
provenance{positions, normals}Sample positions and normals along each street.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {addStreetProfilesRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'street-profiles'});
// Samples, facade `segments` and building columns are graph views on `graph`.
const {outputs} = addStreetProfilesRecipe(graph, {
  positions: samples,
  normals,
  segments,
  segmentBuildingIds,
  buildingHeights,
  maximumDistance: 60,
  sampleSpacing: 5
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// outputs.profiles: distance to the building on each side
