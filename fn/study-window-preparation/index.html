Study window preparation

Prepares one polygon as an analysis window: oriented edges, area, perimeter, bounds and mask.

Reading the result

Gives point-pattern and density operators a shared boundary. It orients edges with the interior on the left and rasterizes a sampling grid for fast inside tests.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Packed planar vertex positions.
featureOffsets*GraphDataView<"uint32">-Feature-to-polygon offsets with one terminal entry.
polygonOffsets*GraphDataView<"uint32">-Polygon-to-ring offsets with one terminal entry.
ringOffsets*GraphDataView<"uint32">-Ring-to-vertex offsets with one terminal entry.
samplingGridreadonly [number, number] | undefined[256, 256]Columns and rows of the mask.
crossingCapacitynumber | undefined4 * samplingGrid[1] * ringCountRaster crossing capacity.
output{ summary?: GraphDataView<"float32"> | undefined; } | undefined-Optional summary copy.

Returns

FieldTypeDescription
summaryGraphDataView<'float32'> | undefinedEight floats: area, perimeter, bounds and more.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUStudyWindowPreparation} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUStudyWindowPreparation({
  positions, featureOffsets, polygonOffsets, ringOffsets,
  samplingGrid: [256, 256],
  output: {summary}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
