Subdivide polygons

Splits complex polygons into small convex or rectilinear pieces.

Reading the result

Speeds up joins, clipping and rendering of huge polygons. Interiors are triangulated with holes, then edge-adjacent triangles merge while the union stays convex.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<"float32x2">-Packed planar vertex positions.
featureOffsets*GraphDataView<"uint32">-Feature-to-polygon offsets with one terminal entry.
polygonOffsets*GraphDataView<"uint32">-Polygon-to-ring offsets with one terminal entry.
ringOffsets*GraphDataView<"uint32">-Ring-to-vertex offsets with one terminal entry.
method"convex" | "rectilinear" | undefined'convex'Piece shape.
maximumVerticesnumber | undefined-Vertices per convex piece, 3 to 128.
output*{positions, pieces}-Pieces and offsets.

Returns

FieldTypeDescription
positionsGraphDataView<"float32x2">Vertices of all pieces.
piecesGraphDataView<"uint32">Piece offsets with source feature ids.
statusGraphDataView<'uint32x4'>Written pieces, required pieces and overflow flags.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUSubdividePolygons} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
// Views are graph views on `graph`; ports need `kind` ('polygons' or 'lines'); polygons add featureOffsets, polygonOffsets, ringOffsets.
graph.add(new GPUSubdividePolygons({
  positions, featureOffsets, polygonOffsets, ringOffsets,
  method: 'convex', maximumVertices: 16,
  output // positions, pieces, ...
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
