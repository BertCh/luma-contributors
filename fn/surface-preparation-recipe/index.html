Reading the result

Repairs a DEM or temperature grid before slope, flow or interpolation. Fill takes the nearest donor or inverse-distance weighting within maximumDistance pixels, and original values are never overwritten. Masks say what was filled and filtered.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height and affine transform.
input*GPURasterBufferBandContinuous band with nodata gaps.
maximumDistance*numberFill search distance in pixels, a positive integer.
method"nearest" | "inverse-distance" | "gdal-four-quadrant" | undefinedDonor selection for the fill.
filterGPURasterRankFilterProps | "radius" | >Optional rank filter after the fill.
outputsPartial<Output> | undefinedCaller-owned views to keep; every other result is a graph transient.

Returns

FieldTypeDescription
outputs.valuesGraphDataView<"float32">Repaired surface.
outputs.originalValidityGraphDataView<"uint32">Which cells were valid at the start.
outputs.filledGraphDataView<"uint32">Cells whose value was interpolated.
outputs.unresolvedCountGraphDataView<"uint32">Gaps left after fill and filter.
contributorsreadonly GPUCommandNodeProducer<never>[]Graph nodes the recipe added, in execution order.
intermediatesRecord<string, unknown>Named stage ports; graph-owned, not for readback.
statusGPURecipeStatusPortGPU status words; zero means complete.
bandGPURasterBandMetadata<"float32">Prepared band with its storage.

Example

import {addSurfacePreparationRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; demBand is a buffer-backed float band with nodata
const prepared = addSurfacePreparationRecipe(graph, {
  grid,
  input: demBand,
  maximumDistance: 8,
  method: 'inverse-distance',
  filter: {quantile: 0.5, radius: 1} // 3 x 3 median
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// prepared.outputs.values, prepared.outputs.filled
