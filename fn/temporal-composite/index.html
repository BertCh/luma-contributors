Reading the result

Builds cloud-free composites or to smooth noisy index series. Composites write one row per cell; smoothing writes one per cell and slice.

Parameters

PropTypeDescription
cellCount*numberNumber of cells.
sliceCount*numberObservations per cell.
values*GraphDataView<"float32">Series per cell, cell-major.
maskGraphDataView<"uint32">Per-observation validity flags.
operation*"mean" | "median" | "minimum" | "maximum" | "savitzky-golay"Reduction or filter.
windowLengthnumberSavitzky-Golay window, odd 3 to 15.
polynomialOrdernumberSavitzky-Golay polynomial order.
output*{values}values, counts, chosenSlice, status.

Returns

FieldTypeDescription
valuesGraphDataView<"float32">Composite or smoothed values.
countsGraphDataView<"uint32">Valid observations used.
chosenSliceGraphDataView<"uint32">Slice that supplied an extreme or median.
statusGraphDataView<"uint32">Per-cell status word.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterTemporal} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const cellCount = 512 * 512;
const sliceCount = 8;
graph.add(new GPURasterTemporal({
  cellCount,
  sliceCount,
  values: view('scenes', 'float32', cellCount * sliceCount),
  mask: view('clear', 'uint32', cellCount * sliceCount),
  operation: 'median',
  output: {
    values: view('composite', 'float32', cellCount), counts: view('counts', 'uint32', cellCount),
    chosenSlice: view('chosen', 'uint32', cellCount), status: view('status', 'uint32', cellCount)
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
