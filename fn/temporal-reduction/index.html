Temporal Reduction

Reduces timestamped rows to per-cell, per-time-bucket minimum, maximum, first, last and count.

Reading the result

Use it so a scrubbing view draws one feature per cell and bucket rather than every event. Bucket origin and width are per-frame parameters.

Parameters

PropTypeDefaultDescription
cellIds*GraphDataView<'uint32'>-uint32 cell index per row.
timestamps*GraphDataView<'float32'> | GraphDataView<'uint32x2'>-Relative float32 times, or exact Int64 words.
values*GraphDataView<'float32'>-Float32 value per row.
maskGraphDataView<'uint32'>-Nonzero rows take part.
parameters*GraphDataView<'uint32'> | GraphDataView<'float32'>-Bucket origin and width.
cellCount*number-Number of cells, compile-time.
bucketCount*number-Coarse time buckets per cell, compile-time.
sortedbooleanfalseRows are sorted by time.

Returns

FieldTypeDescription
countsGraphDataView<'uint32'>Rows per cell and bucket.
minimumsGraphDataView<'float32'>Minimum value per cell and bucket.
maximumsGraphDataView<'float32'>Maximum value per cell and bucket.
firstGraphDataView<'float32'>First value per cell and bucket.
lastGraphDataView<'float32'>Last value per cell and bucket.
occupiedSlotsGPUCompactOutputOccupied slot ids (cell * bucketCount + bucket) and count.

Example

import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';
import {GPUTemporalReduction, getGPUTemporalReductionParameterValues, GPU_TEMPORAL_REDUCTION_PARAMETER_LENGTH} from '@luma-contributors/analysis/dataframe-analysis';

// cellIds, timestamps, values, counts, minimums, maximums, first, last, occupiedSlots: views on graph
const buckets = new GPUParameterBuffer(device, {id: 'buckets', format: 'float32',
  length: GPU_TEMPORAL_REDUCTION_PARAMETER_LENGTH});
graph.add(new GPUTemporalReduction({
  cellIds, timestamps, values, cellCount: 500, bucketCount: 24,
  parameters: buckets.importToGraph(graph),
  output: {counts, minimums, maximums, first, last, occupiedSlots}
}));
buckets.write(getGPUTemporalReductionParameterValues(originTime, 3600));
