Depression breaching

Cuts the cheapest bounded channel from each pit to an outlet, with optional explicit stream burning.

0.050

Cut depth along the channel from each pit (dots) to its outlet.

Reading the result

Best instead of filling when you want to preserve terrain: it minimizes total excavation depth for the pits you name. Simultaneous edits take the minimum elevation, so results do not depend on thread order.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height, cell size and extent.
elevation*GraphDataView<"float32">Canonical float32 elevation surface.
pitCells*GraphDataView<"uint32">Explicit pit cell indices; nothing is filled or burned implicitly.
maximumSteps*numberLongest D8 breach path per pit.
maximumCutDepth*numberDeepest excavation allowed along a path.
elevationDecrement*numberPositive drop per path step, in elevation units.
burnDepthGraphDataView<"float32"> | undefinedExplicit burn depth per cell, applied after breaching.

Returns

FieldTypeDescription
elevationGraphDataView<"float32">Edited elevation surface.
cutDepthGraphDataView<"float32">Depth removed from each cell.
modificationMaskGraphDataView<"uint32">Bit 1 breach, 2 burn, 4 invalid burn depth.
pathCellsGraphDataView<"uint32">Breach path cells per pit, pit first.
pathLengthsGraphDataView<"uint32">Path length per pit.
pitStatusGraphDataView<"uint32">0 invalid, 1 breached, 2 no outlet within bounds.
unresolvedCountGraphDataView<"uint32">Pits left unresolved.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTerrainBreach} from '@luma-contributors/analysis/gpu-terrain';

const graph = new GPUCommandGraph(device, {id: 'breach'});

// pitCells: uint32 cell indices of the depressions to open
graph.add(new GPUTerrainBreach({
  grid, elevation, pitCells,
  maximumSteps: 32, maximumCutDepth: 5, elevationDecrement: 0.001,
  output: {
    elevation: breached, cutDepth, modificationMask,
    pathCells, pathLengths, pitStatus, unresolvedCount
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
