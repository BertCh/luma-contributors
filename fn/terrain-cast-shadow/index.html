Reading the result

Best for one live sun position. Each cell marches toward the sun and reports soft sun visibility; it is cheaper than a horizon map when the sun moves every frame.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Width, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBand-Float32 elevation band; invalid or no-data cells are skipped.
parameters*GraphDataView<"float32">-Per-frame settings, packed by the matching getGPU...ParameterValues.
maximumRadiusnumber | undefined-Longest march toward the sun, in cells.
cellSizeModeGPURasterCellSizeMode | undefined'uniform'Ground cell size: 'uniform' meters, 'geographic' degrees or 'web-mercator'.
rowDirectionGPURasterRowDirection | undefinedfrom grid.affine[4]Row direction from the grid affine; a contradicting value throws.
output*GPUTerrainCastShadowOutput-Views for sunVisibility, horizonAngle and validity.

Returns

FieldTypeDescription
sunVisibilityGraphDataView<"float32">1 lit, 0 shadowed, soft at the edge.
horizonAngleGraphDataView<"float32">Horizon angle toward the sun.
outputValidityGraphDataView<"uint32">Nonzero where the cell has a valid result.

Example

import {
  GPUTerrainCastShadow,
  getGPUTerrainCastShadowParameterValues
} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUTerrainCastShadow({
  grid, elevation, maximumRadius: 200,
  parameters: parameters.importToGraph(graph),
  output: {sunVisibility}
}));
parameters.write(getGPUTerrainCastShadowParameterValues(
  {azimuthDegrees: 250, altitudeDegrees: 12}, grid
));
