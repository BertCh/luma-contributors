Terrain contours

Marching-squares contour segments for several elevation levels into bounded buffers.

750 m
drawn

Elevation in; one contour line set per level out, written straight to GPU buffers.

Reading the result

Best for live contour lines drawn straight from GPU buffers. Each level owns a vertex buffer and a count; one flag reports overflow.

Parameters

PropTypeDescription
grid*GPURasterMetadataWidth, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBandFloat32 elevation band; invalid or no-data cells are skipped.
levels*readonly GPUTerrainContourLevel[]Per level: elevation (number or view), vertices, status, optional draw.
output*GPUTerrainContoursOutputHolds status.overflow, one aggregate flag.

Returns

FieldTypeDescription
statusGPUTerrainContoursStatusOverflow flag; nonzero if any level exceeded capacity.

Example

import {GPUTerrainContours} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
// vertices*, status*: views sized for the segments you expect
graph.add(new GPUTerrainContours({
  grid, elevation,
  levels: [
    {level: 500, vertices: vertices500, status: status500},
    {level: 600, vertices: vertices600, status: status600}
  ],
  output: {status: {overflow}}
}));
