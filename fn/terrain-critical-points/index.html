Reading the result

Finds the topological skeleton of a surface. Counting sign changes of the height difference around each pixel ring separates peaks, pits and saddles.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Width, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBand-Float32 elevation band; invalid or no-data cells are skipped.
connectivity8 | 6 | undefined8Ring: 8 (Peucker-Douglas) or 6 (Freudenthal triangulation).
output*GPUTerrainCriticalPointsOutput-Views for classes, signChanges and counts.

Returns

FieldTypeDescription
classesGraphDataView<"uint32">Class code 0..5 (GPU_TERRAIN_CRITICAL_POINT).
signChangesGraphDataView<"uint32">Ring sign changes per pixel.
countsGraphDataView<"uint32">Pixels per class.

Example

import {GPUTerrainCriticalPoints} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUTerrainCriticalPoints({
  grid, elevation, connectivity: 8,
  output: {classes, counts}
}));
