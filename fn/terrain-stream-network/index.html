Stream network reaches

Extracts directed stream reaches between headwaters, confluences and terminals as compact polylines.

Reading the result

Turns a stream mask into vector lines you can draw or analyze as a network. Each reach keeps its source and target cell ids so attributes can be joined back to the raster.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height, cell size and extent.
flowDirections*GraphDataView<"uint32">ESRI D8 codes per cell, from GPUTerrainFlow.
streams*GraphDataView<"uint32">Stream mask per cell; nonzero marks a stream cell.
maximumStepsnumber | undefinedBound on each downstream traversal.
output*{sourceCells, targetCells}Reach, vertex and count views you own.

Returns

FieldTypeDescription
sourceCellsGraphDataView<"uint32">Raster cell where each reach starts.
targetCellsGraphDataView<"uint32">Raster cell where each reach ends.
vertexOffsetsGraphDataView<"uint32">CSR offsets into positions, one line per reach.
positionsGraphDataView<"float32x2">Reach polyline vertices.
lengthsGraphDataView<"float32">Length of each reach.
reachCountGraphDataView<"uint32">Number of reaches.
vertexCountGraphDataView<"uint32">Number of polyline vertices.
status, unresolvedCountmixed viewsFurther result fields; see the reference.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTerrainStreamNetwork} from '@luma-contributors/analysis/gpu-terrain';

const graph = new GPUCommandGraph(device, {id: 'stream-network'});

// capacities of the output views bound how many reaches and vertices are kept
graph.add(new GPUTerrainStreamNetwork({
  grid, flowDirections, streams,
  output: {
    sourceCells, targetCells, vertexOffsets, positions, lengths,
    reachCount, vertexCount, status: {overflow}, unresolvedCount
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
