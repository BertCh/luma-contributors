Reading the result

Ranks rivers by branching hierarchy. It reads D8 directions and a stream mask, then ranks the receiver forest on the GPU with an Euler tour.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height, cell size and extent.
flowDirections*GraphDataView<"uint32">ESRI D8 codes per cell, from GPUTerrainFlow.
streams*GraphDataView<"uint32">Stream mask per cell; nonzero marks a stream cell.
maximumIterationsnumber | undefinedCap on gated pointer-jumping rounds, 1 to 1024.

Returns

FieldTypeDescription
streamOrderGraphDataView<"uint32">0 for non-stream cells, at least 1 on streams.
status.convergedGraphDataView<"uint32">Optional one-row flag: 1 when the GPU loop reached its fixpoint.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTerrainStreamOrder} from '@luma-contributors/analysis/gpu-terrain';

const graph = new GPUCommandGraph(device, {id: 'stream-order'});

// flowDirections and streams come from GPUTerrainFlow
graph.add(new GPUTerrainStreamOrder({
  grid, flowDirections, streams,
  output: {streamOrder, status: {converged}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
