Tiled flow accumulation

Accumulates flow across tiles of a large DEM by exchanging owned cells in one resident global graph.

Reading the result

Best when the DEM arrives as tiles with halos and flow must cross tile seams. Owned rectangles keep accumulation and reach ids exact across seams.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Raster grid: width, height, cell size and extent.
tiles*readonly GPUTerrainFlowTile[]-Disjoint owned rectangles with their views; must cover the grid.
routing"d8" | "branching" | undefined'd8'D8, or branching with prepared fractions.
maximumIterationsnumber | undefined-GPU DAG sweep budget, 1 to 1024.

Returns

FieldTypeDescription
tiles[].output.accumulationGraphDataView<"float32">Global upstream weight for each tile.
tiles[].output.statusGraphDataView<"uint32">0 halo, 1 resolved, 2 cycle or budget exhausted.
tiles[].output.reachIdsGraphDataView<"uint32">Source cell of each stream chain; 0xffffffff otherwise.
status{invalidCount?, converged?, iterationLimitReached?}Optional aggregate diagnostics over global owned cells, excluding halos.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTerrainTiledFlow} from '@luma-contributors/analysis/gpu-terrain';

const graph = new GPUCommandGraph(device, {id: 'tiled-flow'});

// one entry per tile: its buffer origin and size, owned rectangle and views
const tiles = tileViews.map(tile => ({
  column: tile.column, row: tile.row, width: tile.width, height: tile.height,
  owned: tile.owned, flowDirections: tile.flowDirections, runoff: tile.runoff,
  streams: tile.streams,
  output: {accumulation: tile.accumulation, status: tile.status, reachIds: tile.reachIds}
}));
graph.add(new GPUTerrainTiledFlow({grid, routing: 'd8', tiles}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
