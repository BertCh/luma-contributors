Watershed delineation

Labels every cell with the outlet or pour point its D8 flow path drains to.

6
drawn

Each color is the area draining to one pour point; the pointer adds one.

Reading the result

Carves a DEM into catchments, either by natural outlets or by your own pour points.

Parameters

PropTypeDescription
grid*GPURasterMetadataRaster grid: width, height, cell size and extent.
flowDirections*GraphDataView<"uint32">ESRI D8 codes per cell, from GPUTerrainFlow.
pourPointsGraphDataView<"uint32"> | undefinedPour point cell indices (row * width + column).
maximumIterationsnumber | undefinedCap on gated pointer-jumping rounds, 1 to 1024.

Returns

FieldTypeDescription
labelsGraphDataView<"uint32">Pour point index or terminal cell id; 0xffffffff for none.
status.convergedGraphDataView<"uint32">Optional one-row flag: 1 when the GPU loop reached its fixpoint.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTerrainWatersheds} from '@luma-contributors/analysis/gpu-terrain';

const graph = new GPUCommandGraph(device, {id: 'watersheds'});

// flowDirections: GPUTerrainFlow output; pourPoints: uint32 cell indices
graph.add(new GPUTerrainWatersheds({
  grid, flowDirections, pourPoints,
  output: {labels, status: {converged}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
