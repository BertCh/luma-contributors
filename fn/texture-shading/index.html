Texture shading

Leland Brown's texture shading: crisp ridge and valley detail at every scale.

Reading the result

Reveals fine structure that hillshade flattens. A fractional Laplacian is approximated by a multi-scale Gaussian cascade; detail trades small and large features.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Width, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBand-Float32 elevation band; invalid or no-data cells are skipped.
parameters*GraphDataView<"float32">-Per-frame settings, packed by the matching getGPU...ParameterValues.
levelCountnumber | undefined6Band-pass levels, 1 to 8.
baseSigmanumber | undefined1Finest Gaussian sigma, in pixels.
hasNodataboolean | undefinedtrueSet false when the DEM has no no-data to skip masking.
downsampleLevelsboolean | undefinedtrueDownsample coarse levels; false is exact but slower.
output*GPUTextureShadingOutput-Views for textureShade and validity.

Returns

FieldTypeDescription
textureShadeGraphDataView<"float32">Signed texture value, ridges up and valleys down.
outputValidityGraphDataView<"uint32">Nonzero where the cell has a valid result.
textureShadeTextureGraphTextureView<"r32float" | "rgba32float">Optional storage texture receiving textureShade.

Example

import {
  GPUTextureShading,
  getGPUTextureShadingParameterValues
} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUTextureShading({
  grid, elevation, levelCount: 6,
  parameters: parameters.importToGraph(graph),
  output: {textureShade}
}));
parameters.write(getGPUTextureShadingParameterValues({detail: 0.5, gain: 1}));
