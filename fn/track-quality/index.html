Track quality

Flags bad GPS fixes by speed and gap, and optionally adds track similarity and map-match completeness.

Simulated tracks with injected speed spikes and time gaps; fixes are colored by the quality flag the operation sets.

Reading the result

Screens tracks before analysis. It computes step speeds, lengths and durations, then flags jumps and gaps against two thresholds. Add similarity or mapMatching for route distances and completeness.

Parameters

PropTypeDescription
trajectory*Omit<GPUTrajectoryMetricsProps, "id" | "output">Positions, track offsets and timestamps.
thresholds*GraphDataView<"float32">Two rows: maximum speed and maximum time gap.
similarityGPUTrackSimilarityProps | "output"Optional track-similarity settings.
mapMatchingGPUMapMatchingProps | "output"Optional map-matching settings for completeness.

Returns

FieldTypeDescription
outputs{metrics, flags, flaggedCounts}Per-fix flag bits, flagged counts and speed and length metrics.
contributorsGPUCommandNodeProducer[]Graph nodes the recipe added, in execution order.
intermediates{positions, trackOffsets}Projected positions and track offsets.
status{stages}Per-stage completeness views.

Example

import {addTrackQualityRecipe} from '@luma-contributors/analysis/gpu-network';

const recipe = addTrackQualityRecipe(graph, {
  trajectory: {
    positions: fixes.importToGraph(graph),
    trackOffsets: trackOffsets.importToGraph(graph),
    timestamps: times.importToGraph(graph)
  },
  thresholds: thresholds.importToGraph(graph)   // [maximum speed, maximum gap]
});
// the recipe's return value exposes its flags and metrics views
