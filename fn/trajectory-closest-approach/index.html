Trajectory closest approach

Exact encounters between raw tracks: when and how close they came, with durations.

Reading the result

Best when resampling would miss a brief pass. Tracks move linearly between fixes, a space-time grid prunes pairs, and each hit gets its closest time, minimum distance and duration within range. Same question as MobilityDB tdwithin and nearestApproachDistance.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar sample positions, one float32x2 per observation.
timestamps*GraphDataView<"float32"> | GraphDataView<"uint32x2">Sample times: float32, or Int64 epoch-millisecond words.
trackOffsets*GraphDataView<"uint32">Track-to-position offsets with one terminal entry.
distance*GraphDataView<"float32">Per-frame distance in position units.
cellSize*numberSpatial cell width of the space-time grid.
timeCellSize*numberTime cell length, in the declared timestamp unit.
entryCapacity*numberMaximum (cell, segment) entries.
hitCapacity*numberMaximum (segment, segment) hits.

Returns

FieldTypeDescription
pairsGPUTrajectoryClosestApproachPairsPairs with closestTimes, minimumDistances, durations.
status{count, overflow}GPU status words; zero means complete.

Example

import {GPUTrajectoryClosestApproach} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; raw tracks, no resampling needed
graph.add(new GPUTrajectoryClosestApproach({
  positions, timestamps, trackOffsets, distance,
  cellSize: 50, timeCellSize: 60,
  entryCapacity: 1 << 20, hitCapacity: 1 << 18,
  output: {
    pairs: {ids, status: {count, overflow}, partners, minimumDistances, closestTimes, firstTimes, durations},
    status: {entryOverflow, hitOverflow}
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
