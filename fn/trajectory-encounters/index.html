Finds pairs of tracks within a distance of each other in the same time bucket.

Reading the result

Best for contact tracing, convoys and near-misses on tracks already resampled to one clock. A grid hashes each bucket, so cost scales with hits, not with all pairs. The pair list is bounded and reports overflow.

Parameters

PropTypeDescription
samples*GraphDataView<"float32x2">Dense trackCount * bucketCount positions.
trackCount*numberNumber of tracks.
bucketCount*numberTime buckets per track.
distance*GraphDataView<"float32">Per-frame encounter distance, one row.
cellSize*numberCompile-time grid cell width.
bounds*readonly [number, number, number, number]Domain [minX, minY, maxX, maxY].
hitCapacity*numberMaximum (track, partner, bucket) hits.
output*GPUTrajectoryEncounterOutputCaller-owned pair list and status.

Returns

FieldTypeDescription
pairsGPUTrajectoryEncounterPairsPairs with partners, minimumDistances, firstBuckets.
status{ candidateOverflow: GraphDataView<"uint32">; }GPU status words; zero means complete.

Example

import {GPUTrajectoryEncounters} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; samples come from GPUTrajectoryResample on a shared clock
graph.add(new GPUTrajectoryEncounters({
  samples, trackCount: 1000, bucketCount: 96,
  distance, cellSize: 50, bounds: [0, 0, 1000, 1000],
  hitCapacity: 1 << 16,
  output: {
    pairs: {ids, status: {count, overflow}, partners, firstBuckets, minimumDistances},
    status: {candidateOverflow}
  }
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
