Trajectory Hampel filter

Replaces spikes in a per-row column by the median of a window that never crosses a track.

3.00
7 rows
drawn

Step speed along six Bay vessel tracks with 12 synthetic speed spikes added (the first fix of a track takes the speed of its second). Speeds are approximate: the frame stretches x and y differently. Grey: raw. Line: filtered. Dots: values replaced by the window median.

Reading the result

A value is a spike when it is more than numberOfSigmas scaled median absolute deviations from the median of its window. Use it on a coordinate or speed column; rows within half a window of a track end pass through unchanged.

Parameters

PropTypeDescription
values*GraphDataView<"float32">One value per row, for example a speed or a coordinate.
trackOffsets*GraphDataView<"uint32">Track-to-row offsets with one terminal entry.
windowSize*numberFull window in rows (compile-time, at most 129).
parameters*GraphDataView<"float32">Per-frame settings, [numberOfSigmas, 0, 0, 0].
and 1 more required: output

Returns

FieldTypeDescription
filteredGraphDataView<"float32">The window median at a spike, else the input.
flagsGraphDataView<"uint32"> | undefinedPer-row 1 when the value was replaced.
outlierCountGraphDataView<"uint32"> | undefinedOne row: the number of replaced values.

Example

import {GPUTrajectoryHampel, GPU_TRAJECTORY_HAMPEL_PARAMETER_LENGTH, getGPUTrajectoryHampelParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

// graph: GPUCommandGraph; speeds: one float32 per fix
const hampelParameters = new GPUParameterBuffer(device, {
  id: 'hampel', format: 'float32', length: GPU_TRAJECTORY_HAMPEL_PARAMETER_LENGTH
});
graph.add(new GPUTrajectoryHampel({
  values: speeds,
  trackOffsets,
  windowSize: 7,
  parameters: hampelParameters.importToGraph(graph),
  output: {filtered, flags, outlierCount}
}));
hampelParameters.write(getGPUTrajectoryHampelParameterValues({numberOfSigmas: 3}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
