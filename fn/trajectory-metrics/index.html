Reading the result

Profiles GPS tracks: how far, how fast, where they stopped and for how long. A stop is a run slower than a speed threshold for at least a minimum duration; both are live parameters.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar sample positions, one float32x2 per observation.
timestamps*GraphDataView<"float32"> | GraphDataView<"uint32x2">Sample times: float32, or Int64 epoch-millisecond words.
trackOffsets*GraphDataView<"uint32">Track-to-position offsets with one terminal entry.
parametersGraphDataView<"float32"> | undefined[stopSpeedThreshold, stopMinimumDuration, 0, 0], per frame.
spatialContextGPUSpatialContext | undefinedCoordinate space and metric; planar when omitted.
timestampsLowGraphDataView<"float32"> | undefinedOptional low parts for double-single timestamps.
output*GPUTrajectoryMetricsOutputCaller-owned output views.

Returns

FieldTypeDescription
trackLengthsGraphDataView<"float32"> | undefinedPath length per track.
averageSpeedsGraphDataView<"float32"> | undefinedMean speed per track.
trackStopCountsGraphDataView<"uint32"> | undefinedStops per track.
stopsGPUTrajectoryStopOutput | undefinedStop list: centroids, durations, rows.

Example

import {GPUTrajectoryMetrics, getGPUTrajectoryMetricsParameterValues}
  from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; stopParameters is a GPUParameterBuffer of 4 float32
graph.add(new GPUTrajectoryMetrics({
  positions, timestamps, trackOffsets,
  parameters: stopParameters.importToGraph(graph),
  output: {
    trackLengths, averageSpeeds, maximumSpeeds, trackStopCounts,
    stops: {ids: stopTracks, status: {count, overflow}, startRows, endRows, centroids, durations}
  }
}));
stopParameters.write(getGPUTrajectoryMetricsParameterValues({stopSpeedThreshold: 0.5, stopMinimumDuration: 300}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
