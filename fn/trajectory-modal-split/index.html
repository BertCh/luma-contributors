Modal split

Totals triplegs per track and mode by count, distance or duration; modes may come from speed.

0.012
0.030

Eight Bay vessel tracks. Triplegs are colored by the mode their average speed falls in; bars (slow, medium, fast) add up the metric per track. Distances and speeds are approximate: the frame stretches x and y differently.

Reading the result

The trackintel calculate_modal_split. Give each tripleg a mode, or give ascending modeSpeedBreaks and the mode is the speed class of its average speed. One thread per track accumulates the chosen metric.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar fix positions, one float32x2 per row, sorted by track then time.
timestamps*GraphDataView<"float32"> | GraphDataView<"uint32x2">Fix times: float32, or Int64 epoch-millisecond words.
trackOffsets*GraphDataView<"uint32">Track-to-row offsets with one terminal entry.
triplegs*GPUModalSplitTriplegsTripleg tracks, start rows, end rows and count.
modesGraphDataView<"uint32"> | undefinedMode of each tripleg, unless modeSpeedBreaks is given.
modeSpeedBreaksreadonly number[] | undefinedStrictly ascending upper speed bounds per class (compile-time).
modeCount*numberNumber of modes; the length of modeSpeedBreaks when given.
metric*"count" | "distance" | "duration"What is added up per track and mode (compile-time).
and 1 more required: output

Returns

FieldTypeDescription
modalSplitGraphDataView<"float32">Metric per track and mode, track-major.
predictedModesGraphDataView<"uint32"> | undefinedSpeed class of each tripleg.

Example

import {GPUModalSplit} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; tripleg columns come from GPUTrajectorySegments
graph.add(new GPUModalSplit({
  positions, timestamps, trackOffsets,
  triplegs: {tracks: legTracks, startRows: legStarts, endRows: legEnds,
    status: {count: legCount, overflow: legOverflow, candidateOverflow: legCandidateOverflow}},
  modeSpeedBreaks: [15 / 3.6, 100 / 3.6, Infinity],
  modeCount: 3,
  metric: 'distance',
  output: {modalSplit, predictedModes}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
