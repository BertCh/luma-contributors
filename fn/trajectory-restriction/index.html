Reading the result

Finds when each track was inside an area during a period (MobilityDB atTime and atGeometry). Movement is linearly interpolated, endpoint rules are explicit, and pairwise mode gives within-distance intervals for chosen track pairs.

Parameters

PropTypeDescription
positions*GraphDataView<"float32x2">Planar observations.
times*GraphDataView<"float32">Finite relative timestamps.
offsets*GraphDataView<"uint32">Track offsets with one terminal entry.
parameters*GraphDataView<"float32">[minTime, maxTime, minX, minY, maxX, maxY, maxGap, ...ring].
timeBoundary"closed" | "open" | "left-closed" | "right-closed" | undefinedWhether window endpoints are included.
polygonRingVertexCountsreadonly number[] | undefinedRing sizes for polygon restriction; at most 128 vertices.
pairwiseTracksreadonly (readonly [number, number])[] | undefinedTrack pairs for within-distance intervals.
mergeIntervalsboolean | undefinedMerge touching intervals.

Returns

FieldTypeDescription
intervalsGraphDataView<"float32x2">[start, end] slots; NaN where absent.
positionsGraphDataView<"float32x4">Start and end point of each interval.
relationshipsGraphDataView<"uint32x4">Per track [ever, always, support, unknown].
compactIntervalsGraphDataView<"float32x2"> | undefinedWritten intervals only.
statusGraphDataView<"uint32">GPU status words; zero means complete.

Example

import {GPUTrajectoryRestriction} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; parameters = [minTime, maxTime, minX, minY, maxX, maxY, maxGap]
graph.add(new GPUTrajectoryRestriction({
  positions, times, offsets,
  parameters: windowParameters,
  timeBoundary: 'left-closed',
  geometryBoundary: 'closed',
  mergeIntervals: true,
  output: {intervals, positions: intervalPositions, status, relationships}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// relationships: per track [ever inside, always inside, support rows, unknown rows]
