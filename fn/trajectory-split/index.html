Trajectory split

Splits tracks into segments at time gaps, at staypoints or where a per-row value changes.

Reading the result

Mode gap cuts after any step longer than maximumGap, stop keeps the runs outside staypoints, and value-change cuts where a label changes and repeats the boundary row. Segments of one row are dropped. The output lists source rows, so the next operation needs no readback.

Parameters

PropTypeDescription
mode*"gap" | "stop" | "value-change"How tracks are split (compile-time).
positions*GraphDataView<"float32x2">Planar fix positions, one float32x2 per row, sorted by track then time.
timestamps*GraphDataView<"float32"> | GraphDataView<"uint32x2">Fix times: float32, or Int64 epoch-millisecond words.
trackOffsets*GraphDataView<"uint32">Track-to-row offsets with one terminal entry.
parametersGraphDataView<"float32"> | undefinedMode 'gap': [maximumGap, 0, 0, 0], per frame.
staypointIdsGraphDataView<"uint32"> | undefinedMode 'stop': per-row staypoint index.
valuesGraphDataView<"uint32"> | undefinedMode 'value-change': one label per row.
and 1 more required: output

Returns

FieldTypeDescription
segmentOffsetsGraphDataView<"uint32">New offsets into rowIds, one more than segments.
segmentTracksGraphDataView<"uint32">Source track of each segment.
rowIdsGraphDataView<"uint32">Source row of each output row.
statusGPUCardinalityPort & GPUOverflowStatusPortSegment count and overflow.
positionsGraphDataView<"float32x2"> | undefinedOptional copied positions of the output rows.

Example

import {GPUTrajectorySplit, GPU_TRAJECTORY_SPLIT_PARAMETER_LENGTH, getGPUTrajectorySplitParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

// graph: GPUCommandGraph; capacities are row counts
const gapParameters = new GPUParameterBuffer(device, {
  id: 'gap', format: 'float32', length: GPU_TRAJECTORY_SPLIT_PARAMETER_LENGTH
});
graph.add(new GPUTrajectorySplit({
  mode: 'gap',
  positions, timestamps, trackOffsets,
  parameters: gapParameters.importToGraph(graph),
  output: {segmentOffsets, segmentTracks, rowIds, status: {count, overflow}}
}));
gapParameters.write(getGPUTrajectorySplitParameterValues({maximumGap: 1800}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
