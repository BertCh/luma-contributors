Trajectory thinning

Keeps the first fix, then the first later fix at least a tolerance away, in distance or time.

0.040
drawn

The four longest Bay vessel tracks thinned with mode minimum-distance. Small dots are the raw fixes, large dots the fixes kept. Distances and speeds are approximate: the frame stretches x and y differently.

Reading the result

The MovingPandas minimum-distance and minimum-time generalization: each kept fix is followed by the first later fix at or beyond the tolerance, and the last fix is always kept. The sequential rule runs in a bounded forward search per row plus pointer doubling.

Parameters

PropTypeDefaultDescription
mode*"minimum-distance" | "minimum-time"-What the tolerance measures.
positions*GraphDataView<"float32x2">-Planar fix positions, one float32x2 per row, sorted by track then time.
timestamps*GraphDataView<"float32"> | GraphDataView<"uint32x2">-Fix times: float32, or Int64 epoch-millisecond words.
trackOffsets*GraphDataView<"uint32">-Track-to-row offsets with one terminal entry.
parameters*GraphDataView<"float32">-Per-frame settings, [tolerance, 0, 0, 0].
maximumSearchRowsnumber | undefined4096Forward-search cap per row (compile-time).
spatialContextGPUSpatialContext | undefined-Planar (default) or longitude/latitude great-circle.
and 1 more required: output

Returns

FieldTypeDescription
rowIdsGraphDataView<"uint32">Kept source rows in order.
trackOffsetsGraphDataView<"uint32">New per-track offsets into rowIds.
statusGPUCardinalityPort & GPUOverflowStatusPort & GPUCandidateStatusPortKept count and overflow flags.
validityGraphDataView<"uint32"> | undefinedOptional 1/0 validity of the rows: 1 for a kept row.

Example

import {GPUTrajectoryThinning, GPU_TRAJECTORY_THINNING_PARAMETER_LENGTH, getGPUTrajectoryThinningParameterValues} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

// graph: GPUCommandGraph
const toleranceParameters = new GPUParameterBuffer(device, {
  id: 'tolerance', format: 'float32', length: GPU_TRAJECTORY_THINNING_PARAMETER_LENGTH
});
graph.add(new GPUTrajectoryThinning({
  mode: 'minimum-distance',
  positions, timestamps, trackOffsets,
  parameters: toleranceParameters.importToGraph(graph),
  output: {rowIds, trackOffsets: keptOffsets, status: {count, overflow, candidateOverflow}}
}));
toleranceParameters.write(getGPUTrajectoryThinningParameterValues({tolerance: 500}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
