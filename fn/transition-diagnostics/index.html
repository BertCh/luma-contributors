Reading the result

Judges whether conditional transition matrices differ and where the process settles. Homogeneity is a chi-square across conditions; steady states come from iterating the normalized matrix. Sparse rows are flagged.

Parameters

PropTypeDescription
counts*GraphDataView<'uint32'>Transition counts, one matrix per condition.
classCount*numberNumber of classes.
conditionCountnumberNumber of conditions.
minimumTransitionsnumberRow total below which a row is sparse.
output*GPUTransitionDiagnosticsOutputDestination views.

Returns

FieldTypeDescription
homogeneityGraphDataView<'float32'>Chi-square test of equal matrices.
steadyStatesGraphDataView<'float32'>Long-run distribution per condition.
stateSparsityGraphDataView<'uint32'>Sparse rows per condition.
status{converged?}Steady-state convergence flag.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUTransitionDiagnostics} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'diagnostics'});
// counts from GPUTransitionMatrix or GPUSpatialMarkov, outputs: graph views
graph.add(
  new GPUTransitionDiagnostics({
    counts,
    classCount: 5,
    conditionCount: 5,
    minimumTransitions: 5,
    output: {homogeneity, steadyStates, stateSparsity, status: {converged}}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
