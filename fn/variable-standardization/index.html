Reading the result

Puts variables on a common scale before clustering, scoring or regression. Reductions span the whole column; masked and non-finite rows become NaN.

Parameters

PropTypeDefaultDescription
values*Column<'float32'>-Packed scalar float32 column, a single chunk.
maskColumn<'uint32'>-Nonzero includes the row.
method*GPUVariableStandardizationMethod-z-score, deviation-from-mean, mad, range-adjust or range-standardize.
variance'sample' | 'population''sample'Z-score convention.
output*Column<'float32'>-Caller-owned float32 output of the same length.

Returns

FieldTypeDescription
outputColumn<'float32'>Standardized value per row; excluded rows are NaN.

Example

import {GPUVariableStandardization} from '@luma-contributors/analysis/dataframe-analysis';

// values, output: float32 columns of the same length
graph.add(new GPUVariableStandardization({
  values, method: 'z-score', variance: 'sample', output
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
device.submit();
