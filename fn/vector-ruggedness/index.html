Vector ruggedness (VRM)

Vector ruggedness measure: how much surface normals disagree in a window.

3
1.00
drawn

Elevation in; the vector ruggedness measure out: orientation scatter, not height.

Data · Grand Canyon elevation
  • U.S. Geological Survey, 3D Elevation Program · Public domain · Grand Canyon elevation

Reading the result

Best for roughness that ignores plain steepness (Sappington et al. 2007). The window radius is read per frame, so changing it never recompiles.

Parameters

PropTypeDefaultDescription
grid*GPURasterMetadata-Width, height, cell size and origin from makeGPURasterMetadata.
elevation*GPURasterBand-Float32 elevation band; invalid or no-data cells are skipped.
parameters*GraphDataView<"float32">-Per-frame settings, packed by the matching getGPU...ParameterValues.
maximumRadiusnumber | undefined-Largest window half-width in cells; fixed at compile time.
output*GPUTerrainVectorRuggednessOutput-Views for vectorRuggedness and validity.
cellSizeModeGPURasterCellSizeMode | undefined'uniform'Ground cell size: 'uniform' meters, 'geographic' degrees or 'web-mercator'.
borderModeGPURasterBorderMode | undefined-Window treatment at the tile border.

Returns

FieldTypeDescription
vectorRuggednessGraphDataView<"float32">VRM in 0..1; 0 is smooth, near 1 is very rugged.
outputValidityGraphDataView<"uint32">Nonzero where the cell has a valid result.

Example

import {
  GPUTerrainVectorRuggedness,
  getGPUTerrainVectorRuggednessParameterValues
} from '@luma-contributors/analysis/gpu-terrain';

// graph, grid, elevation, parameters and the output views are set up as in the Terrain quick start
graph.add(new GPUTerrainVectorRuggedness({
  grid, elevation, maximumRadius: 7,
  parameters: parameters.importToGraph(graph),
  output: {vectorRuggedness}
}));
parameters.write(getGPUTerrainVectorRuggednessParameterValues({radius: 3}, grid));
