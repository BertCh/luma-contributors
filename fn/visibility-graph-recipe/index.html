Reading the result

Best for space syntax: integration, choice and depth over a plaza or building plan. Closed obstacles block sightlines, and visible pairs become edges within maximumDistance. Edge capacity bounds the result.

Parameters

PropTypeDefaultDescription
positions*GraphDataView<'float32x2'>-Candidate viewpoints.
segments*GraphDataView<'float32x4'>-Obstacle walls as (x0, y0, x1, y1).
maximumDistance*number-Longest sightline.
edgeCapacity*number-Upper bound on visible pairs.
tolerancenumber-Geometric tolerance.
regionUrbanFreeSpaceRegion-Restrict viewpoints to free space.
idstring'visibility-graph'Prefix for graph resources.

Returns

FieldTypeDescription
outputs{edges, adjacency, metrics, integration, choice}Visible pairs, adjacency lists and per-viewpoint graph measures.
statusGraphDataView<'uint32x4'>Completeness and overflow words.
provenance{positions, obstacles}Resolved viewpoints and obstacle inputs.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {addVisibilityGraphRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'visibility'});
// `grid` (float32x2 points) and wall `segments` (float32x4) are graph views on `graph`.
const {outputs, status} = addVisibilityGraphRecipe(graph, {
  positions: grid,
  segments,
  maximumDistance: 120,
  edgeCapacity: 500000
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// outputs.edges lists visible pairs; outputs.integration scores each point
