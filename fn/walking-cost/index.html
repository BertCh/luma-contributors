Reading the result

Best for hiking time, emergency access and wildlife movement. The model is Tobler or a GRASS-style energy model; costs relax to a fixpoint from the source cells.

Parameters

PropTypeDescription
grid*GPURasterMetadataShared grid.
elevation*GPURasterBufferBandElevation band.
friction*GPURasterBufferBandSurface friction band.
sources*GraphDataView<"uint32">Source cell indices.
parameters*GraphDataView<"float32">Friction weight, GRASS terms and georeference, packed by a helper.
model{kind: "tobler"} | {kind: "grass", coefficients, downhillSlopeThreshold}Energy model.
maximumIterationsnumberBounded relaxation rounds.
output*{costs}costs, validity and a converged status.

Returns

FieldTypeDescription
costsGraphDataView<"float32">Accumulated cost from the nearest source.
validityGraphDataView<"uint32">1 where a cost was found.
status.convergedGraphDataView<"uint32">1 when relaxation reached a fixpoint.

Example

import {createTransientView, GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPURasterWalkingCost, makeGPURasterBand, makeGPURasterMetadata} from '@luma-contributors/analysis/raster-analysis';

const graph = new GPUCommandGraph(device, {id: 'demo'});
const view = <Format extends 'float32' | 'uint32' | 'float32x2'>(id: string, format: Format, length: number) => createTransientView(graph, id, format, length);
const grid = makeGPURasterMetadata({width: 512, height: 512, cellSize: 30});
const n = grid.width * grid.height;
const band = (id: string) => makeGPURasterBand(view(id, 'float32', n), grid, {id, validity: view(`${id}-valid`, 'uint32', n)});
// `sources` is a uint32 view of start cell indices.
graph.add(new GPURasterWalkingCost({
  grid,
  elevation: band('dem'),
  friction: band('land-cover-friction'),
  sources,
  parameters, // getGPURasterWalkingCostParameterValues({frictionWeight: 1}, grid)
  model: {kind: 'tobler'},
  maximumIterations: 256,
  output: {costs: view('costs', 'float32', n), validity: view('valid', 'uint32', n), status: {converged: view('converged', 'uint32', 1)}}
}));
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
