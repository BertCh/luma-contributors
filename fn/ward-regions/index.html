Reading the result

Best for hierarchical regions that merge the pair raising variance least. Only adjacent regions merge, so every region stays connected. mutual-nearest merges many pairs per round for speed.

Parameters

PropTypeDescription
weights*GPUSpatialWeightsLoss suppresses labels (0xffffffff), objective (NaN) and convergence.
values*GraphDataView<'float32'>Attribute columns, row-major.
targetRegionCount*numberRegions to stop at.
maximumIterations*numberMerge round cap.
parameters*GraphDataView<'uint32'>Seed, from getGPUWardRegionsParameterValues.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUWardRegions, getGPUWardRegionsParameterValues, GPU_WARD_REGIONS_PARAMETER_LENGTH} from '@luma-contributors/analysis/gpu-spatial-analysis';
import {GPUParameterBuffer} from '@luma-contributors/analysis/analysis-core';

const graph = new GPUCommandGraph(device, {id: 'ward'});
const parameters = new GPUParameterBuffer(device, {
  id: 'ward-parameters', format: 'uint32', length: GPU_WARD_REGIONS_PARAMETER_LENGTH,
  values: getGPUWardRegionsParameterValues({seed: 1})
});
// weights, values, outputs: graph views
graph.add(new GPUWardRegions({
  weights, values, columnCount: 3, standardize: true,
  targetRegionCount: 8, maximumIterations: 512, mergeSchedule: 'mutual-nearest',
  parameters: parameters.importToGraph(graph),
  output: {labels, objective, status}
}));
graph.compile().encode(device.commandEncoder, {parameters: undefined});
