Zonal distribution

Gives each zone its median, mode, unique count and quantiles, from zone IDs or points in polygons.

Reading the result

Describes the whole distribution of values inside each zone, not just the mean. Points are assigned to one owning feature; empty zones stay in the output with zero counts and NaN order statistics.

  • Zone boundaries determine membership; a summary can hide variation within each zone.

Parameters

PropTypeDescription
source*GPUZonalDistributionSourceDense zone IDs, or points joined to polygons.
values*GraphDataView<"float32">Calibrated values aligned with zone rows or points.
probabilitiesGraphDataView<"float32"> | undefinedPer-frame quantile probabilities in [0, 1].
outputsPartial<Output> | undefinedCaller-owned views to keep; every other result is a graph transient.

Returns

FieldTypeDescription
outputs.zoneIdsGraphDataView<"uint32">Zone ID per output row.
outputs.mediansGraphDataView<"float32">Median per zone.
outputs.modesGraphDataView<"float32">Mode per zone; ties go to the lowest.
outputs.uniqueCountsGraphDataView<"uint32">Distinct values per zone.
outputs.quantilesGraphDataView<"float32"> | undefinedOne column per probability.
spatialContextGPUSpatialContext | undefinedResolved coordinate space and metric.
contributorsreadonly GPUCommandNodeProducer<never>[]Graph nodes the recipe added, in execution order.
intermediates, statusmixed viewsFurther result fields; see the reference.

Example

import {addZonalDistributionRecipe} from '@luma-contributors/analysis/gpu-spatial-analysis';

// graph: GPUCommandGraph; zoneIds and values are aligned graph views
const distribution = addZonalDistributionRecipe(graph, {
  source: {kind: 'zones', zones: zoneIds, zoneCount: 40},
  values,
  probabilities, // e.g. [0.1, 0.5, 0.9]
  outputs: {medians, quantiles}
});
const compiled = await graph.compileAsync();
compiled.encode(device.commandEncoder, {parameters: undefined});
// distribution.status.stages keeps grouping overflow and join status
