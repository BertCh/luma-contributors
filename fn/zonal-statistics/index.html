Reading the result

Rolls point events or raster cells up to zones such as tracts or parcels. Polygons are indexed and tested on the GPU, then reduced per zone. sumOrder: 'sorted' makes sums bit-reproducible.

Parameters

PropTypeDescription
features*GPUZonalStatisticsFeaturesPolygons, or precomputed point-to-feature rows.
positionsGPUFloat32PositionsPoint locations.
valuesGraphDataView<'float32'>Values to aggregate.
weightsGraphDataView<'float32'>Per-point weight.
areasGraphDataView<'float32'>Feature areas for density outputs.
sumOrder'atomic' | 'sorted'Reproducibility of float sums.
spatialContextGPUSpatialContextFrame of the points.
output*GPUZonalStatisticsOutputAny subset of statistics.

Returns

FieldTypeDescription
countsGraphDataView<'uint32'>Points per zone.
sums / meansGraphDataView<'float32'>Value sum and mean per zone.
minima / maximaGraphDataView<'float32'>Extremes per zone.
standardDeviationsGraphDataView<'float32'>Spread per zone.
densitiesGraphDataView<'float32'>Count per unit area.

Example

import {GPUCommandGraph} from '@luma.gl/graph/gpu-core';
import {GPUZonalStatistics} from '@luma-contributors/analysis/gpu-spatial-analysis';

const graph = new GPUCommandGraph(device, {id: 'zonal'});
// tract geometry views, point positions and values, outputs: graph views
graph.add(
  new GPUZonalStatistics({
    features: {kind: 'polygons', positions: tractPositions,
      featureOffsets, polygonOffsets, ringOffsets, candidateCapacity: 1 << 20},
    positions: pointPositions,
    values,
    sumOrder: 'sorted',
    output: {counts, means, standardDeviations}
  })
);
graph.compile().encode(device.commandEncoder, {parameters: undefined});
