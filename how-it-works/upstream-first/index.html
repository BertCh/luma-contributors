Upstream first

Gridlight adds no GPU runtime; it stacks on published luma.gl.

In short
  • This library imports published luma.gl through public entry points only.
  • When luma.gl lacks something, it uses the public API, adapts, drops the feature, or writes a small helper, in that order.
  • Recording a command graph needs no luma.gl hook.

An example

Recording needed no hook. The compiled graph already publishes its order, buffers and usage, and describeGPUCommandGraph reads only those.

yarn check-upstream-first runs in CI. It fails on any non-public @luma.gl import, any re-export of a luma.gl API and any source directory outside the analysis-owned list.
