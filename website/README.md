# Website

A static documentation site built with [TanStack Start](https://tanstack.com/start) (React + Vite).
Every route is prerendered to HTML at build time, so `dist/client` can be served by any static host.

```bash
yarn website-dev     # http://localhost:3000
yarn website-build   # writes website/dist/client
```

## How it works

- `build/markdown-plugin.ts` is a Vite plugin that compiles each `docs/**/*.md` file to HTML at build
  time (GitHub-flavored markdown, heading anchors, Shiki highlighting with light and dark themes).
  Links to `.md` files and `/docs/...` paths are rewritten to site routes. No markdown parser ships to
  the browser; each page is a small lazily loaded chunk.
- `virtual:docs-index` lists every page's slug and title. The sidebar is built from
  `docs/table-of-contents.json`.
- `vite.config.ts` lists every docs page in `pages`, and prerendering fails the build if any page
  fails to render.
- Routes: `src/routes/index.tsx` (home), `src/routes/docs/$.tsx` (all docs pages, `/docs` shows
  `docs/api/README.md`), and `src/routes/__root.tsx` (HTML shell, header and 404 page).
- `src/routeTree.gen.ts` is generated by the TanStack router plugin. Commit it, but don't edit it.
